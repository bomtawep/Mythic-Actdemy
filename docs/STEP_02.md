# Step 02 — ควบคุมแรงลอยตัวและลองใหม่

อัปเดต: ความก้าวหน้า session-only ในบันทึกขั้นนี้ถูกขยายด้วย [Step 03](STEP_03.md) แล้ว Studio ยังจำเฉพาะเซิร์ฟเวอร์ทดสอบ แต่โค้ด server จริงมี DataStore (ยังไม่ผ่านการทดสอบบริการจริง)

ขยาย Step 01 จาก prompt ให้ผ่านทันที เป็นเริ่มฝึก → ยก/ลดระดับผลึก → วางตรงเป้าหมาย บทฝึกเป้า 9 และกลไกเป้า 12 studs (ค่าเริ่ม 6, สูงสุด 14) เป็นค่าทดลอง ยังไม่ใช่ระบบลาก/หมุน/วางอิสระ

## สิ่งที่เพิ่ม

- เซิร์ฟเวอร์เก็บ session และระดับผลึกของแต่ละคน รับเฉพาะคำสั่ง Raise/Lower/Place/Cancel ไม่รับตำแหน่งหรือผลสำเร็จจาก client
- ตรวจระยะ 15 studs ผู้เล่นยังมีชีวิต ขั้นบทเรียน และเวลาฝึก 60 วินาที จำกัดคำสั่งทุก 0.15 วินาที
- วางผิดเริ่มระดับใหม่ในขั้นเดิม ยกเลิก/ตาย/ออกนอกระยะ/หมดเวลาจะจบการฝึก แต่ไม่ล้างขั้นที่ผ่านแล้ว
- ภาพผลึกและกรอบเป้าหมายสร้างเฉพาะ client ของคนฝึก ความก้าวหน้า/รางวัลตัดสินที่ server ยังไม่บันทึกข้ามรอบเล่น
- ปุ่มสัมผัสและแป้น R ยก / F ลด / G วาง / X ยกเลิก รองรับการกดทีละครั้ง ยังไม่รองรับ gamepad โดยเฉพาะ

## ตรวจรับใน Studio ที่ยังค้าง

1. เริ่มแท่นม่วง ยก 3 ครั้งแล้ววาง → ขั้น 1; แท่นฟ้ายก 6 ครั้งแล้ววาง → ขั้น 2; รับบันทึก → ขั้น 3
2. วางผิดต้องไม่ผ่านและระดับกลับ 6; ลดต่ำกว่า 6/ยกเกิน 14 ไม่ได้
3. ยกเลิก/ตาย/เดินออกระยะ/รอเกิน 60 วินาที: ภาพและปุ่มหาย เริ่มใหม่ได้
4. ข้ามขั้น/รับซ้ำ/ยิง remote โดยไม่มี session/ส่งชนิดข้อมูลผิด/ส่งถี่: ไม่ได้รางวัลหรือข้ามขั้น
5. สองผู้เล่นฝึกแท่นเดียวกัน: ระดับและขั้นไม่เปลี่ยนตามกัน ภาพส่วนตัวถูกเก็บเมื่อจบ
6. ตรวจข้อความไทยบนมือถือแนวตั้งและแนวนอน ปุ่มไม่ชนปุ่มเดิน/กระโดด; ตรวจภาพผลึกและกรอบที่ระดับเป้า
7. เกิดใหม่ยังเก็บขั้นในรอบเดิม; ออกจากเกมแล้วเข้าใหม่เริ่มขั้น 0 ตามขอบเขตปัจจุบัน

## หลักฐานและข้อจำกัด

Rojo build/sourcemap และตรวจโครงสร้าง XML ผ่าน; ยังไม่ได้ตรวจไวยากรณ์ด้วย Luau compiler, runtime, ภาพ, หลายคน หรือมือถือ Computer Use เคยไม่อนุญาตใน session นี้ จึงยังไม่ถือว่า game-tested และไม่ติ๊ก QA ผ่าน

ขั้นต่อไป: ตรวจ Studio ตามรายการนี้ แก้ปัญหาที่พบ แล้วแยกบริการความก้าวหน้าและบันทึก/โหลดพร้อมกรณีล้มเหลว ก่อนเพิ่มสัตว์หรือดันเจียน

อ้างอิงการออกแบบขอบเขตคำสั่ง: [Roblox client-server boundary](https://create.roblox.com/docs/scripting/security/client-server-boundary)
