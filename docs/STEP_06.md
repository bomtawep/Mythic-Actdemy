# Step 06 — สัตว์คู่หูต้นแบบหนึ่งตัว

ปลดล็อกเมื่อจบบทเรียน Stage 3 เปิด/เก็บด้วย P หรือปุ่มบนจอ Server ตรวจสิทธิ์และชนิดคำสั่ง จำกัดคำสั่งทุก 0.4 วินาที ไม่ให้ค่าพลังหรือรางวัลเพิ่ม

ตัวต้นแบบเป็นก้อนทรงรีสีเขียวมีตา ลอยตามข้างหลังผู้เล่น เป็นดัมมี่ทดสอบระบบ ไม่ใช่โมเดลธรรมชาติฉบับผลิต ไม่เพิ่ม Aura/ประกาย/เสียงหรือใช้โมเดลพ่อมด

## การทำงานและขอบเขต

- PetService เป็นเจ้าของ PetEquipped; client ส่งได้เฉพาะ boolean เรียก/เก็บ ไม่มีการเลือกเจ้าของหรือส่งตำแหน่ง
- PetPolicy ตรวจ ProgressReady และ Stage 3 สิทธิ์คืนจากข้อมูลบทเรียนเดิมโดยไม่เปลี่ยน schema; สถานะเรียก/เก็บไม่บันทึกข้ามรอบเล่น เริ่มเก็บทุกครั้งที่เข้าใหม่
- แต่ละ client สร้างภาพคู่หูให้ทุกผู้เล่นที่มี attribute เรียกอยู่ ไม่ส่งตำแหน่งตามรายเฟรมผ่าน remote
- ลอยตามพร้อม smoothing; ระยะห่างมากกว่า 24 studs ย้ายกลับใกล้เจ้าของ ไม่มี collision/touch/query ไม่ขวางทางเดิน
- ตาย/ไม่มี character/ข้อมูลไม่พร้อมจะเก็บภาพ เมื่อเกิดใหม่และยังเรียกอยู่จะแสดงใหม่ ผู้เล่นออกจะลบภาพ
- ซ่อนปุ่มตอนฝึกเพื่อไม่บังการควบคุม ไม่มีระบบเดินบนพื้น pathfinding, ตรวจผนัง, rig, animation หรือความผูกพัน รุ่นนี้อาจลอยผ่านสิ่งกีดขวาง ต้องพัฒนาการนำทางตามฉากภายหลัง

## ผลตรวจ

- Luau compiler ผ่าน 16 ไฟล์
- progress 84 + journal 28 + pet entitlement 28 = 140 assertions ผ่าน
- Rojo build/sourcemap ผ่าน ตรวจ export พบ remote และ modules ตามตำแหน่ง
- PetService/render loop ยังไม่ได้ทดสอบ runtime ใน Roblox; ไม่ตรวจภาพ หลายคน กล้อง การผ่านประตูหรือประสิทธิภาพจริง ไม่เปิด Studio ตาม D16

## งานต่อไป

เพิ่มดันเจียนสั้นแบบปริศนาที่ใช้เวทเดิมและทางกลับก่อนขยายศัตรู/บอส โดยแยกขอบเขตรันและรางวัลจากข้อมูลบทเรียนที่ใช้ปัจจุบัน ห้ามเติม currency ลงในวิธี merge Stage โดยตรง
