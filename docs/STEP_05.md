# Step 05 — สมุดนักเรียนต้นแบบ

เพิ่มสมุดอ่านความก้าวหน้าจากข้อมูลบทเรียนเดิม ไม่เปลี่ยน schema บันทึกและไม่เพิ่ม remote หรือวิธีรับรางวัลจาก client

- เปิด/ปิดด้วย B หรือปุ่มบนหน้าจอ มีปุ่มปิดและเนื้อหาเลื่อนได้
- แสดงขั้น 0–3, สถานะเวทแรงลอยตัว, บันทึกที่ได้รับ 1 รายการเมื่อขั้น 3, เป้าหมายถัดไป และสถานะบันทึกข้อมูล
- โหลดไม่สำเร็จหรือข้อมูลขั้นผิดรูป: ไม่แสดงว่าได้รับของแล้ว
- ระหว่างฝึกสมุดจะปิดและซ่อนปุ่มเปิด คืนปุ่มเมื่อจบ/ยกเลิกการฝึก
- เป็นหน้าความก้าวหน้าบทเรียนชุดแรก ยังไม่ใช่สมุดสะสมครบสี่หมวด สัตว์/การ์ด/บันทึกโลกยังไม่ได้เพิ่ม

## ไฟล์

`src/client/JournalModel.luau` สร้างข้อความจากขั้นที่ server ส่งมา; `JournalController.luau` สร้าง UI และฟัง attributes เปิดโดย Main.client.luau สมุดเป็น read-only การแก้ UI ฝั่ง client ไม่ให้สิทธิ์รางวัลที่ server

## ผลตรวจ

- Luau compiler ผ่าน 11 ไฟล์
- Progress mocks เดิมผ่าน 84 assertions; JournalModel ผ่าน 28 assertions ครอบคลุมขั้น/เงื่อนไขปลดล็อก/ข้อมูลเสีย/ยังไม่พร้อม
- Rojo build/sourcemap ผ่าน ตรวจ XML พบ JournalController/JournalModel เป็น ModuleScript ใน StarterPlayerScripts
- ไม่เปิด Roblox Studio ตามคำสั่งผู้ใช้ล่าสุด ยังไม่ตรวจภาพ การตัดคำไทย การเลื่อน/ปุ่มมือถือ หรือ runtime Roblox จึงระบุสถานะ script/export-tested เท่านั้น

UI และข้อความเป็นงานชั่วคราวใน PH-UI-002 ต้องแทน/เก็บงานและตรวจภาพก่อนเผยแพร่ ไม่มีรูป ไอคอน เสียง หรือ asset ภายนอกเพิ่ม

ขั้นถัดไปตามแผน: สัตว์คู่หูหนึ่งตัวแบบต้นแบบ โดยใช้สิทธิ์จากบทเรียนเดิมก่อน ยังไม่เพิ่มการซื้อ/สุ่มหรือแก้ระบบบันทึกให้เก็บของใช้หมด
