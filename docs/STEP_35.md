# Step 35 — ม่านคุ้มกัน เวททดลองที่สาม

เพิ่มแท่น ShieldLesson ฝั่งขวาใกล้จุดเกิด หลัง Stage 3 และผ่านเวทแสง เริ่มฝึกแล้วกด Q/ปุ่มคุ้มกันให้ใกล้การโจมตีสามครั้ง กันอย่างน้อยสองครั้งจึงผ่าน

- server เป็นเจ้าของ clock/strike/cast/ผลสำเร็จ ส่งเวลา GetServerTimeNow ให้ client นับถอยหลังเพื่อการแสดงผลเท่านั้น ไม่รับเวลา cast จาก client
- เตือนครั้งแรก 2 วินาที รอบถัดไป 3 วินาที ช่วงคุ้มกัน 0.6 วินาที cooldown 1 วินาที พลาดเสีย 10 HP ต่อครั้ง
- ออกระยะ 22 studs ตาย/profile ไม่พร้อม หรือเริ่มกิจกรรมอื่นหยุดฝึก กลับแท่นเริ่มใหม่ได้ ความสำเร็จที่เคยผ่านคงเฉพาะ session
- ไม่มีโล่ที่ใช้กับ combat ทุกระบบหรือเอฟเฟกต์ผลิตจริง ไม่มีรางวัลถาวร/การขายพลัง/การเปลี่ยน ProgressSchema
- ShieldAction รับเฉพาะ Cast มี throttle ฝั่ง server/UI เริ่ม session ได้ผ่าน prompt ที่ server ตรวจระยะ/ชีวิต/สิทธิ์
