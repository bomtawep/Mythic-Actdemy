# Step 52 — ตรวจใน Roblox Studio จริง

ผู้ใช้สั่งเปิด Studio และให้ผู้ช่วยกดเอง (D61) ใช้ Roblox Studio 0.745 บนเครื่องผู้ใช้ เปิด `build/MythicAcademy.rbxlx` ขณะ `rojo serve` ของผู้ใช้เชื่อมอยู่ วิธีตรวจ: ภาพหน้าจอ, คำสั่งใน command bar (กล้อง, วางตัวละคร, ตั้ง attribute เฉพาะ session Play), ปุ่ม Play/E จริง และอ่าน Output จาก log ใน `~/Library/Logs/Roblox`

## ผล

| เรื่อง | ผล |
|---|---|
| ผังจากมุมบน (render ของ Studio) | ตรงผัง SCENE_DESIGN_SLICE |
| Play | ตัวละครเกิดที่จุดเกิดใต้ลาน HUD/ปุ่มขึ้น ไม่มี error/warning จากสคริปต์ของเกม (error ใน log เป็นของ Studio/ปลั๊กอินอื่น) |
| เวลาเดินจริง (Humanoid:MoveTo เส้นตรง WalkSpeed 16) | จุดเกิด→ห้องเรียนแรก 20.5 วิ; →กลไก 6.8 →แท่นบันทึก 6.5; →ห้องเรียนแสง 3.9; →สวน 15.2 →ประตูดันเจียน 23.2; จากกลางลาน: หอพัก 15.4, สนามฝึก 18.0, สวน 16.2 |
| ห้อง 2 | แถบเตือนแนวยิงสีม่วงพาดจากผู้ยิงถึงผนังใต้ชัดเจน; ยืนนิ่งในแนวโดนทุกรอบ (พลังชีวิตลดตามคาด); โซนส้มของผู้เฝ้าแสดง และผู้ยิงหยุดยิงในโซน |
| ตาย | เกิดใหม่ที่จุดเกิดโรงเรียน HP 100 รันพัก (Encounter, paused) พร้อมคำใบ้ |
| กลับรัน | prompt ที่ซากวิหารขึ้นจริง กด E ค้าง → กลับจุดเริ่มห้อง 2 รันไม่พัก |

## พบและแก้

1. ข้อความรันพักใน HUD/สมุดยังบอก "ประตูข้างแท่นบันทึก" ซึ่งเป็นผังเก่า → "กลับไปประตูดันเจียนที่ซากวิหาร (ผ่านสวนอักขระ)" พร้อม test กันถอยหลัง; คำใบ้ server ที่พูด "ห้องทดลอง" เปลี่ยนเป็นดันเจียน/ซากวิหาร
2. prompt ดันเจียนยังชื่อ "ห้องทดลองแรงลอยตัว" → "เรือนกระจกแห่งเสียงสะท้อน / เข้าดันเจียน" และ "เรือนกระจก • ห้อง N/3" ที่ทางออก/ปริศนา/แท่นจบ
3. แถบเตือนแนวยิงจมใต้แผ่นจุดเกิดห้อง 2 (สูงกว่า) → ยกเป็น y=0.36

check_luau ผ่าน 90 ไฟล์ 1228 assertions; Rojo build/sourcemap ผ่าน; ยืนยันใน Studio ว่า prompt ใหม่ sync เข้าแล้ว

## ข้อสังเกตที่ยังไม่แก้

- เสาแกนแสงอยู่ตรงหน้าจุดเกิดบนทางหลัก มองเป็นจุดสังเกตได้ดี แต่เดินตรงไปโถงจะชน เส้นไปห้องเรียนแรกไม่ชน — รอดูกับผู้เล่นจริง
- ไอคอนปุ่มบน prompt แสดงอักษรไทยเมื่อคีย์บอร์ดเครื่องเป็นภาษาไทย (พฤติกรรมของ Roblox)
- ห้องเปิดหลังคา มองเห็นท้องฟ้า เหมาะกับ blockout แต่ธีม "ใต้ดิน" ต้องมีเพดาน/แสงตอนทำภาพจริง
- เวลาเดินวัดแบบเส้นตรง คนเล่นจริงจะช้ากว่า

## ยังไม่ได้ตรวจ

หน้าจอมือถือ/อุปกรณ์อ้างอิง, ผู้เล่นหลายคน, ห้อง 1 และ 3 ในภาพ, หอพักและคู่หูในภาพ, เวลาเดินของคนจริง
