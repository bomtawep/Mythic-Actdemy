# Step 32 — ใช้เวทแสงกับจุดสำรวจในสวน

เพิ่มลานอักขระฝั่งขวาใน Academy หลังผ่านเวทแสง เริ่มที่ LightExploreStart แล้วร่าย ExploreRune1/2/3 ตามกลุ่มสลับเดิมเพื่อเป้าใหม่ 1ดับ 2สว่าง 3ดับ (ต้องใช้ทั้งสามแท่นจากสถานะเริ่ม)

- server ตรวจ LightCompleted, Stage 3, profile/ระยะ/ชีวิต/บริบท ก่อนเริ่มหรือร่าย สถานะแยกรายคน ไม่เพิ่ม RemoteEvent
- เริ่มใหม่และเดินออกได้ ตาย/ข้อมูลไม่พร้อม/เปลี่ยนกิจกรรมหยุด trial บทฝึกเดิมและสำรวจแสงไม่ทำพร้อมกัน
- เป้าสำเร็จตั้ง LightDiscovery เฉพาะ session แสดงในสมุด ไม่แก้ Stage, LightCompleted เดิมหรือแจกเงิน/ไอเทมถาวร
- แสงและป้ายแยกจากชุดบทเรียน ยังเป็นแท่น primitive ไม่ใช่ฉากสวนผลิตจริง ไม่มีประตูล็อกหรือทางตกใหม่

## ผลตรวจ

compiler 73 ไฟล์ผ่าน; tests เดิม 708 + exploration service 12 + journal 3 = 723 assertions ผ่าน รวมล็อกก่อนเรียน เป้าใหม่ เริ่มใหม่ เดินออก ตาย สถานะแยกคนและไม่ทับบทเดิม Build หลัก/experimental, sourcemap และ XML ผ่าน

ไม่เปิด Studio ตาม D16 client exploration ใหม่ยังไม่ทดสอบ flow ครบตัว/ภาพจริง/ระยะ/มือถือ และไม่มีผล DataStore จริง การค้นพบไม่บันทึกหลังออกเกม

ขั้นถัดไปลดโค้ดซ้ำของบทแสง/สำรวจด้วยบริการปริศนาร่วม พร้อมทดสอบทั้งสอง config ไม่ให้การแก้ lifecycle ฝั่งหนึ่งหลุดอีกฝั่ง ก่อนขยายปริศนาแสงหลายจุด
