# Step 10 — ผู้เฝ้าฝึกหนึ่งพฤติกรรม

เพิ่ม encounter ทางเลือกด้านข้างห้องทดลอง (x=180, z=-10) ไม่ล็อกเส้นทางหลัก ไม่เพิ่มจำนวนศัตรูทั้งหมดของ MVP โดยอัตโนมัติ

- ยืนประจำจุด เมื่อผู้เล่นเข้าเขตสี่เหลี่ยมครึ่งกว้าง 8 studs จะเตือน 1.5 วินาที โจมตีคนที่ยังอยู่ในเขต 15 HP ครั้งเดียว แล้วพัก 3 วินาที
- Server ตรวจสถานะ/ตำแหน่ง/ชีวิตและความเสียหายเอง สถานะเตือนแยกต่อคน ไม่เพิ่ม remote
- มีข้อความและพื้นสี่เหลี่ยมเตือน ไม่พึ่งสีอย่างเดียว ไม่มีวงแหวน/ประกาย/Aura
- หยุดเมื่อไม่อยู่ DungeonState=Puzzle, รันพัก, ข้อมูลไม่พร้อม, ตาย หรือกำลังควบคุมเวท เพื่อไม่ให้โจมตีซ้อนช่วงฝึก
- เดินอ้อมหรือออกประตูกลับได้ ไม่มีการกำจัดศัตรู HP ศัตรู เวทโจมตี AI ไล่ล่า ดรอป หรือรางวัลจาก encounter รุ่นนี้เป็นต้นแบบการอ่านท่าและหลบเท่านั้น
- ใช้ชิ้น primitive เป็นตัวผู้เฝ้า ไม่ใช่โมเดลสำเร็จหรือ rig

## ผลตรวจ

Luau compiler 26 ไฟล์ผ่าน; tests เดิม 192 + encounter 18 = 210 assertions ผ่าน ตรวจเตือนก่อน hit, hit ครั้งเดียว, พัก, ออกเขตหลบ, ยกเลิกและขอบเขตพื้นที่ Rojo build/sourcemap/XML ผ่าน

ไม่เปิด Studio ตาม D16 ยังไม่ตรวจภาพ/ข้อความ/ระยะ/TakeDamage/latency จริง จึงยังไม่รับรองว่าคำเตือนอ่านได้หรือจังหวะหลบบนมือถือผ่าน ผลทดสอบเป็นกฎล้วนและ mock เดิม ไม่ใช่ integration ของ EncounterService
