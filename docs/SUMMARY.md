# สรุปโครงการและสถานะปัจจุบัน

## แกนเกม

Mythic Academy เป็นเกม Roblox โรงเรียนเวทมนตร์ ผสมชีวิตนักเรียน ผจญภัยร่วมกัน สะสมเวทและสัตว์เลี้ยง แต่งตัว เข้าสังคม และตกแต่งหอพัก จุดเชื่อมของทุกระบบคือ “เรียนเวทแล้วนำไปใช้จริงนอกห้องเรียน” รายได้ที่เสนอเน้นการแสดงตัวตนและของตกแต่ง [S13]

โลกตั้งต้นเป็นหมู่เกาะลอยฟ้าที่มีปัญหาแกนเวท แยก Academy, Dorm และ Dungeon เพื่อรองรับกิจกรรมต่างกัน ต่อมามีข้อเสนอให้เน้นสถานีวิจัย ระบบนิเวศเวท และชมรมที่เลือกได้เพื่อสร้างเอกลักษณ์ แต่ยังไม่มีการยืนยัน canon ทั้งหมด [S04–S07, S13]

## ระบบที่ออกแบบแล้วในระดับแผน

- เรียนแบบลงมือทำ: ยก/ย้ายวัตถุ ธาตุ ปรุงยา สัตว์เวท อักขระ และป้องกันตัว ผ่านขั้นต่ำได้เวทจำเป็น ความชำนาญปลดโจทย์และของตกแต่ง [S12]
- สะสม 4 สาย: คัมภีร์สำหรับทดลองความรู้ สัตว์เลี้ยงสำหรับความผูกพัน การ์ดภาพเก็บช่วงเวลา บันทึกโลกสำหรับค้นความจริง [S10]
- แต่งตัวและสังคม: ชุดและสีที่จัดเอง กิจกรรมโรงเรียน ชมรม ห้องพักและการแสดงผลงาน พร้อมสิทธิ์การเข้าถึงและทางเลือกเล่นคนเดียว [S09]
- สำรวจ: ห้องลับ ทางลัด เกาะลับ และปริศนาที่ใช้เวทเรียนมา มีคำใบ้และกลับออกได้ [S08]
- Academy: พื้นที่สูง–กลาง–ฐานราก แต่ละโซนมีสิ่งให้เล่นและเหตุผลกลับมา ไม่ใช่ฉากโชว์อย่างเดียว [S07]
- Dorm: พื้นที่พัก แต่งห้อง จัดของสะสม เล่นกับสัตว์ เชิญเพื่อน พร้อมบันทึก/โหลดห้อง [S06]
- Dungeon: Hub เตรียมทีม แล้วเล่นรอบที่ใช้เวท ปริศนา ศัตรู บอส และรางวัล มี checkpoint/recovery ป้องกันรับรางวัลซ้ำ [S05]
- Aura: ผู้ใช้แก้ให้ลดความรก จึงใช้ขอบแสงเล็ก ๆ และลวดลายบนวัตถุแทนวงแหวน/ดาวล้อมตัวจากข้อเสนอแรก [S03]
- ดัมมี่: ทำ blockout ทดสอบวงจร แล้วแทนทีละระบบและทีละโซน มีรายการติดตามก่อนเปิดใช้งาน [S02]

## งานที่มีหลักฐานใน codebase ปัจจุบัน

Workspace นี้เป็น Rojo codebase แล้วตั้งแต่ Step 01–28 ไม่ใช่โฟลเดอร์เอกสารอย่างเดียว:

- บทเรียนแรงลอยตัว → กลไก → บันทึก และเวทแสงนำทางสลับอักขระเป็นบททดลองที่สอง (แสง session-only) ตรวจเงื่อนไขฝั่ง server
- สมุดนักเรียนและคู่หู cosmetic แบบลอยตามหนึ่งตัว
- ดันเจียนหนึ่งห้อง สถานะรายคน ห้องกายภาพร่วม ผู้เฝ้าทางเลือก ปริศนา checkpoint/recovery เฉพาะ server
- หอพัก v2 แบบห้องแยกตำแหน่ง วาง/หมุน/เก็บ/preview/select ตาม inventory และ migration/lease สำหรับข้อมูลห้อง
- compiler 86 ไฟล์ tests 808 assertions บน API doubles และ Rojo builds ผ่าน ยังไม่ตรวจภาพ/เกมจริง/มือถือ/DataStore จริง ไม่เปิด Studio ตามคำสั่งผู้ใช้

ทั้งหมดเป็นต้นแบบ ยังไม่ครบขอบเขต MVP เช่นสามวิชา/12 เวท บอส party หอพักสังคม ร้าน และภาพผลิตจริง ดู [สถานะล่าสุด](STATUS.md), [coverage Step 28](STEP_28.md) และ [ประวัติ](STEP_INDEX.md)

งานพ่อมด v1–v4 เป็นงาน asset ตามหลักฐานย้อนหลังใน STATUS ไม่ได้นำเข้าระบบเกมนี้ และคำสั่งไม่ต้องนำเข้า Roblox ยังใช้กับงานนั้น

## สิ่งที่ต้องตัดสินใจต่อ

codebase หลักและบทเรียนทดลองแรกมีแล้ว ต้อง audit โค้ดเก่าก่อนรวม ล็อก MVP ที่ไม่ขัดกับแผนย่อยและ canon ของโลก กำหนดอุปกรณ์ทดสอบและงบภาพ ตรวจชื่อและสิทธิ์สินทรัพย์ แล้วพัฒนาวงจรต้นแบบที่มีอยู่ให้ครบ vertical slice ก่อนขยายทั้งโลก

แผนละเอียดทั้งหมดเก็บไว้ใน sources/chats เพื่อไม่ทำตัวเลข ตัวอย่าง และข้อยกเว้นจากต้นทางหายไป ดู sources/INDEX.md
