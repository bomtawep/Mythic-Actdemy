# Step 11 — ใช้แรงลอยตัวหยุดผู้เฝ้า

เพิ่มจุดจบของ encounter ทางเลือก: หลบการโจมตี → รอช่วง Rest → ใช้แท่น SentinelControl → ยกผลึกระดับ 10 แล้ววาง → ผู้เฝ้าหยุดสำหรับรันนั้น

- เริ่มใช้แท่นได้เฉพาะช่วงพัก ตรวจที่ server ทั้งสิทธิ์ Stage 3 ข้อมูลพร้อม DungeonState=Puzzle ไม่พักรัน และยังไม่หยุดผู้เฝ้า
- ระหว่างควบคุมเวทระบบ encounter หยุดตามกฎเดิม ไม่มีการโจมตีซ้อน วางผิดลองใหม่ ยกเลิกต้องรอช่วงพักรอบใหม่
- ใช้ LevitationAction เดิมและกฎ session/range/timeout เดิม ไม่เพิ่ม remote รับผลสำเร็จจาก client
- Server ตั้ง EncounterCleared ภายหลังวางสำเร็จเท่านั้น หยุดความเสียหายซ้ำ แสดงตัวผู้เฝ้าจางลงและข้อความรายคน
- ผลหยุดคงอยู่เมื่อพักรันหลังตาย/กู้คืน ล้างเมื่อเข้ารันใหม่ ไม่บันทึกหลังออกเกม ไม่มีไอเทมหรือเงินเพิ่ม ไม่เปลี่ยน ProgressSchema
- ยังเดินอ้อมและจบปริศนาหลักได้โดยไม่ต้องหยุดผู้เฝ้า ไม่มีระบบ HP/ฆ่า/ดรอปหรือเวทโจมตีเต็มรูปแบบ
