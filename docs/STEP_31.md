# Step 31 — client เวทแสงร่วม HUD และสมุด

เพิ่มการทดสอบ HudController, LightLessonController และ JournalController ตัวจริงร่วมกันบน Instance/event doubles ตรวจเริ่มเรียน pattern 101 ผ่านแล้วแสดงผลในสมุด เปลี่ยนกิจกรรม/ข้อมูลไม่พร้อม และ cleanup เมื่อ HUD ถูกทำลาย

ปรับการแสดงไฟ/ป้ายให้ซ่อนเมื่อเข้าหอพัก ดันเจียน เริ่มแรงลอยตัว หรือ profile ไม่พร้อม กลับบริบทเดิมแสดง pattern ล่าสุด ไม่มีการล้างความสำเร็จ session หรือเพิ่มข้อมูลถาวร

## ผลตรวจ

compiler 70 ไฟล์ผ่าน; tests เดิม 691 + client flow 17 = 708 assertions ผ่าน Rojo builds/sourcemap และ whitespace ผ่าน ไม่มี asset ใหม่

ไม่เปิด Studio ตาม D16 Instance doubles ไม่เรนเดอร์ภาพ ไม่ตรวจ clipping/ความสว่าง/ภาษาไทย/อินพุตจริง/มือถือหรือ DataStore จริง ไม่ยกระดับเป็น game-tested
