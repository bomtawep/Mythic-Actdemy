# Step 16 — ห้องพักและม้านั่งหนึ่งชิ้น

เข้า DormEntry ด้านซ้ายแท่นบันทึกเมื่อข้อมูลพร้อม ไม่อยู่รันดันเจียน/ใช้เวทอยู่ ห้องส่วนตัวต้นแบบ 28×32 studs เพดานอ้างอิง 16 (ยังไม่มีหลังคา) สร้างจาก template ใน ServerStorage แยกตำแหน่งต่อผู้เล่น

- หนึ่งม้านั่ง 4×2×2 studs เริ่มเก็บ ปุ่มบนจอวาง/เก็บ/ย้ายทีละ 2 studs/หมุนทีละ 90 องศา
- Server ตรวจ room mapping, OwnerUserId, InDorm, ข้อมูลพร้อม, ผู้เล่นมีชีวิตและอยู่ในขอบเขตห้อง ก่อนรับคำสั่ง ไม่รับตำแหน่ง/เจ้าของจาก client
- ตรวจขนาดชิ้นงานตามการหมุนในพื้นที่วาง ±12/±10 studs เว้นแนวหน้าประตูไว้ ม้านั่งไม่ชนเพื่อไม่ปิดทางผู้เล่น รุ่นนี้ยังไม่ใช่เฟอร์นิเจอร์นั่งได้
- กลับโรงเรียนด้วย prompt ในห้องได้ ผู้ที่เข้ามาทางอื่นใช้ทางออกได้ แต่แก้ห้องคนอื่นไม่ได้ ยังไม่มี guest/invite/ระบบกันเข้าห้องทางกายภาพ
- ตายเกิดที่โรงเรียน สถานะวางคงในหน่วยความจำจนออก server; ออกแล้วทำลายห้อง/คืน slot ไม่เปลี่ยน ProgressSchema หรือใช้ DataStore ห้อง
- ยังไม่มี preview ลากวาง gamepad ประสิทธิภาพจำนวนห้องมาก หรือรายการเฟอร์นิเจอร์เพิ่ม ไม่ใช่หอพัก MVP เต็ม
