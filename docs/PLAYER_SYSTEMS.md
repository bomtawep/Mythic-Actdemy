# ระบบผู้เล่น

## ต้นแบบต่อสู้และความชำนาญที่เพิ่มจริง (Step 56 / D64)

หลังผ่านม่านคุ้มกันใช้ C หรือปุ่มคลื่นเวทโจมตีผู้เฝ้าในห้อง 2 ได้ HP 100 ครั้งละ 25 ระยะ 24 studs คูลดาวน์ 0.9 วินาที เป็นการประยุกต์จากบทเรียนเดิม ไม่มีเวทที่ต้องซื้อ เป้าหมายยังมีเพียงผู้เฝ้า ผู้ยิงยังใช้หลบ/โล่ เงายังใช้แสง/ทางอ้อม ทางเลือกผ่านห้องด้วยแท่นหรือโล่เดิมยังอยู่

ขั้นความชำนาญในสมุด: ผู้ฝึกหัด (ยังไม่ผ่านม่านคุ้มกัน) → พร้อมภาคสนาม (ผ่านม่านคุ้มกัน) → ผ่านภาคสนาม (ผ่านม่านคุ้มกันและเคยจบดันเจียน) ใช้ข้อมูลถาวรเดิม การจบซ้ำยังไม่เพิ่มพลัง/EXP/ของดรอป และขั้นนี้ไม่ให้ค่าสถานะเพิ่ม ยังต้องพิสูจน์ความสนุกในเกมจริงก่อนออกแบบระบบฟาร์มเต็มรูปแบบ

สรุปฐานข้อเสนอเดิม; รายละเอียดตัวอย่างและตารางที่เรียกได้เก็บใน sources/chats ตามรหัสท้ายหัวข้อ

## บทเรียน [S12]

Step 35 มีม่านคุ้มกันเป็นเวททดลองที่สาม กดตามจังหวะกัน 2/3 ครั้งหลังผ่านแสง ผล session-only ยังไม่ครอบคลุม combat shield/วิชาป้องกันเต็ม ดู STEP_35.md

Step 29 เพิ่มแสงนำทางเป็นบททดลองที่สองหลัง Stage 3 ร่ายที่อักขระสลับกลุ่มสว่าง/ดับให้ตรงเป้าหมาย ผล session-only ยังไม่ใช่ระบบวิชา/เวทครบ MVP ดู STEP_29.md

สาธิต → ฝึกพร้อมคำใบ้ → เปลี่ยนโจทย์ → ท้าทาย → สรุปผล → ชี้พื้นที่ภายนอกให้ใช้เวท ผ่านขั้นต่ำได้เวทหลัก ส่วนคะแนนสูงให้ความชำนาญ/ของแต่ง ไม่กีดกันผู้เล่นที่ควบคุมยังไม่คล่อง

วิชาต้องเล่นต่างกัน: ควบคุมเวท (ยกหมุนวาง), ธาตุ (ตอบสนองสิ่งแวดล้อม), ปรุงยา (ลำดับและอุณหภูมิ), สัตว์เวท (อ่านท่าทางและความไว้ใจ), อักขระ (รูปแบบ/สัญลักษณ์), ป้องกัน (หลบ/โล่/จังหวะ)

ต้นแบบแรงลอยตัว: ยกขนนก → คืนหนังสือ → พาผลึกผ่านวง → เลือกสัญลักษณ์ → ซ่อมเครื่อง มีคำใบ้เมื่อพลาดและย้อนเฉพาะส่วนที่พลาด เพิ่มโจทย์แปรผันและเล่นคู่หลังจบวงจรพื้นฐาน

## สะสม [S10]

Implementation Step 50 (D59): คู่หู "ละอองหูใบ" ชื่อเลือกจาก 6 ชื่อ ความผูกพัน รู้จัก→คุ้นเคย→ไว้ใจ จากกิจกรรมร่วมครั้งแรก 4 อย่าง บันทึกถาวร ไม่ลดเมื่อออฟไลน์ ไม่มีค่าพลัง ภาพยังเป็นดัมมี่ ดู STEP_50.md

Implementation Step 06: คู่หูต้นแบบหนึ่งตัวปลดล็อกด้วยการจบบทเรียน เรียก/เก็บ ไม่มีค่าพลังเพิ่ม ยังไม่มีระบบสายพันธุ์/ความผูกพัน และใช้ภาพลอยตามดัมมี่ ดู STEP_06.md

Implementation Step 05: สมุดนักเรียนชุดแรกแสดงเวทแรงลอยตัว บันทึกจากบทเรียน และเป้าหมายถัดไปจาก Stage เดิมเท่านั้น ยังไม่ใช่ระบบสะสมครบสี่สายด้านล่าง รายละเอียดและผลตรวจใน STEP_05.md

| สาย | คุณค่าหลัก | หลักควบคุม |
|---|---|---|
| คัมภีร์ | ความรู้และรูปแบบทดลอง | หน้าทักษะหลักได้แน่นอน ของซ้ำมีทางแลก |
| สัตว์เลี้ยง | สายพันธุ์ บุคลิก ความผูกพัน | สีแรร์ไม่เพิ่มพลัง ไม่บังคับให้อาหารตามเวลา |
| การ์ดภาพ | เหตุการณ์และความทรงจำ | เงื่อนไขค้นพบมีความหมาย ไม่เป็นเพียงเปิดซอง |
| บันทึกโลก | ประวัติและการสืบค้น | แยกข้อเท็จจริงกับคำเล่า เชื่อมหลักฐาน |

จัดผ่านสมุดนักเรียน 4 หมวด ลดความรกมือถือ แสดงของสะสมในห้องพัก มีความก้าวหน้าและรางวัลที่ไม่ขายความได้เปรียบ ชุดเนื้อหาตัวอย่าง “เรือนกระจกที่ลืมฤดู” เชื่อมทั้งสี่ระบบ ยังไม่รวมผสมพันธุ์สัตว์ ตลาดผู้เล่น หรือการ์ดต่อสู้ในรุ่นแรกที่เสนอ

## แต่งตัวและสังคม [S09]

แยกช่องเครื่องแต่งกาย จัดสีและชุดโปรด ของที่ได้จากเรียน สำรวจ ดันเจียน สัตว์ และเทศกาลเล่าเรื่องผู้เล่นได้ ส่วนร้านขายรสนิยม ไม่ขายสิทธิ์เข้าร่วมสังคม

พื้นที่กิจกรรมมีลาน คาเฟ่ ห้องสมุด เรือนกระจก สัตว์ หอดูดาว หอพัก และเวที ผู้เล่นเลือกพร้อมทำกิจกรรม หาเพื่อนเรียน/สำรวจ แต่งตัว หรือขอเล่นคนเดียวได้

เสนอทั้งกลุ่มชั่วคราว เพื่อนร่วมกิจกรรม และชมรม ห้องมีโหมดส่วนตัว เชิญ เพื่อน ชมรม เปิดบ้าน ต้องมีการจัดการคำเชิญและสิทธิ์แขก ไม่มีการบังคับยอดไลก์เพื่อความก้าวหน้า

## สำรวจและปริศนา [S08]

Step 32 มีจุดสำรวจแสงในสวนหนึ่งจุด เปิดหลังผ่านบทแสง เป้าหมายใหม่ 010 ได้สถานะค้นพบในสมุดเฉพาะ session ไม่ใช่ระบบบันทึกโลกเต็มหรือรางวัลถาวร ดู STEP_32.md

สร้างเบาะแสในพื้นที่ให้สังเกต ใช้เวทที่เรียนมาแก้กลไก เชื่อมห้องลับ ทางลัด เกาะ และบันทึกโลก รางวัลรองรับการค้นพบมากกว่ากดตามคู่มืออย่างเดียว ต้องมีคำใบ้ ทางออก และกรณีทำคนเดียว/เพื่อนออก ไม่ล็อกรางวัลจำเป็นไว้หลังของจ่ายเงิน

## ดันเจียนและรางวัล [S05]

เตรียมตัว → เข้าเป็นรอบ → ห้องต่อสู้/ปริศนา/ทางเลือก → บอส → สรุปผลและกลับ มีเป้าหมายหลักและเสริม ท่าบอสอ่านออก ร่วมมือได้โดยไม่บังคับอาชีพจากเงิน

สัตว์แสดงบุคลิกหรือช่วยสังเกตโดยไม่เป็นตัวคูณพลังจากการซื้อ รางวัลแยกความก้าวหน้า ของสะสม และของตกแต่ง มีทางจัดการของซ้ำและความก้าวหน้าแน่นอน ทดสอบ checkpoint การล้ม การออกจากทีม การหลุด และป้องกันรับรางวัลซ้ำ
