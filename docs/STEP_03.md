# Step 03 — ความก้าวหน้าและบันทึกข้อมูล

อัปเดตหลังขั้นนี้: [Step 04](STEP_04.md) รันตรวจไวยากรณ์และทดสอบโมดูลข้อมูลด้วยบริการจำลองแล้ว รายการ Studio/บริการจริงยังค้าง

เพิ่ม `ProgressService` แยกจากบทเรียนและ `ProgressSchema` รุ่น 1 เก็บเฉพาะ `Stage` 0–3; เวทปลดล็อกจากขั้น >=1 และบันทึกนักเรียนจากขั้น 3 จึงไม่มีการบวกรางวัลซ้ำเมื่อ retry

## พฤติกรรม

- โหลดสำเร็จก่อนเปิด prompt/รับรางวัล ถ้า API ล้มเหลวลองสูงสุด 3 ครั้ง ถ้าข้อมูลผิดรูปหรือไม่รู้จัก Version จะไม่เริ่ม profile ใหม่และไม่เขียนทับ ผู้เล่นต้องออกเข้าใหม่
- เซิร์ฟเวอร์จริงใช้ DataStore `MythicAcademy_LessonProgress_v1`, key `player_<UserId>`; ยังไม่ได้เผยแพร่หรือเรียก API จริงในงานนี้
- Studio ใช้หน่วยความจำเท่านั้น ไม่เปิด store จริง แม้เปิด Studio API access แล้ว ข้อมูลอยู่ได้ใน server ทดสอบเดียวกันและหายเมื่อ Stop
- บันทึกหลังผ่านแต่ละขั้น ทุก 30 วินาทีเมื่อมีข้อมูลค้าง ตอนออก และตอนปิดเซิร์ฟเวอร์; HUD บอกสถานะจริง ไม่แสดงว่าบันทึกสำเร็จเพียงเพราะผ่านบทเรียน
- ใช้ UpdateAsync รวมขั้นที่มากกว่า ป้องกันข้อมูลจากเซิร์ฟเวอร์เก่าย้อนขั้นและรองรับ retry ซ้ำ ไม่มี session lock เพราะข้อมูลรุ่นนี้เพิ่มได้อย่างเดียว ห้ามนำวิธีนี้ไปใช้กับเงิน ของใช้หมด การรีเซ็ต หรือสิทธิ์ซื้อ ต้องออกแบบ transaction/session ownership ใหม่ก่อน
- ถ้าเซฟทุกครั้งล้มเหลวหรือ server crash ก่อนเซฟสำเร็จ ความก้าวหน้าที่ยังไม่บันทึกอาจหาย การปิด server รอได้สูงสุด 25 วินาที ไม่รับรองว่าบริการภายนอกจะเซฟสำเร็จเสมอ

## ตรวจรับที่ยังค้าง

1. Studio Play ทำบทเรียน ตรวจ ProgressReady/ProgressStatus/ขั้นและรางวัล; ทดลองสองคนและเกิดใหม่ตาม Step 02
2. รัน `require(game.ServerScriptService.MythicAcademy.ProgressSchemaTests)()` ใน Server Command Bar เพื่อตรวจข้อมูลผิดรูป version ใหม่ merge เซฟเก่า และ retry ซ้ำ
3. ใน experience ทดสอบแยกที่เผยแพร่แล้ว: ผ่านขั้น 1/2/3 ออกเข้าใหม่ ต้องคืนขั้นและไม่แจกบันทึกซ้ำ
4. จำลองโหลดล้มเหลว/ข้อมูลเสีย/Version ไม่รองรับ: prompt ไม่ทำงาน ไม่มีการเขียนทับ
5. จำลองเซฟล้มเหลว: HUD แจ้งปัญหา เซฟซ้ำภายหลังได้โดยไม่ย้อนขั้น และตรวจ PlayerRemoving/BindToClose
6. ตรวจเซฟพร้อมกันและ reconnect ต่าง server: ขั้นที่สูงกว่าคงอยู่; ยังไม่มีการซิงก์ข้าม server ระหว่างเล่นทันที

## ผลตรวจในงานนี้
