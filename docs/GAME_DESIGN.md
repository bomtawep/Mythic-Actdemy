# ภาพรวมและขอบเขตเกม

แหล่งหลัก: S13; รายละเอียดระบบใน S05–S12 สถานะทั้งหมดในส่วนนี้เป็นข้อเสนอเดิม เว้นที่ระบุว่าเป็นคำสั่งผู้ใช้

## วงจรที่ต้องพิสูจน์

เข้าโรงเรียน → เรียนทักษะ → ใช้กับโลก/ปริศนา/ดันเจียน → รับความก้าวหน้าและของสะสม → แต่งตัว/ห้อง/คู่หู → กลับมาลองโจทย์ใหม่กับเพื่อน

ความก้าวหน้าไม่ควรเป็นการซื้อพลัง เวทพื้นฐานต้องเข้าถึงได้แน่นอน มีการลองชุดเวทและการประยุกต์มากกว่าตัวเลขใหญ่ขึ้นอย่างเดียว

## MVP จากแผนหลัก S13

| หมวด | ขอบเขตตั้งต้น |
|---|---|
| โลก | โรงเรียนส่วนกลาง ป่า 1 พื้นที่ ดันเจียน 1 แห่ง |
| วิชา | เวทธาตุ อักขระ สัตว์วิเศษ |
| เวท | 12 แบบรวมพื้นฐานและเสริม |
| สัตว์เลี้ยง | 4 ชนิด ใช้งานพร้อมกัน 1 ตัว |
| ศัตรู | 4 พฤติกรรม และบอส 1 ตัว |
| เล่นร่วมกัน | Solo / กลุ่ม 1–4 คน |
| หอพัก | ห้อง 1 แบบ วางของพื้นฐาน เฟอร์นิเจอร์ประมาณ 15 ชิ้น |
| ร้าน | ของแต่งขายตรง 8–12 รายการ |
| สะสม | คัมภีร์ดรอปและระบบแลกเป้าหมาย |
| เลื่อนออก | PvP จัดอันดับ เทรด ตลาดกลาง บินเต็มรูปแบบ กาชาเสียเงิน |

## Vertical slice ที่ล็อกแล้ว (D55)

ผู้ใช้ล็อกเมื่อ 2026-11-02 ตาราง MVP ด้านบนยังเป็นเพดานที่ปรับได้หลังทดสอบ slice

| หมวด | slice | สถานะโค้ดตอนล็อก |
|---|---|---|
| เวท | แรงลอยตัว, แสงนำทาง, ม่านคุ้มกัน (จัดวิชาทีหลัง) | เล่นได้ทั้งสาม บันทึกผ่านถาวร (D54) |
| ดันเจียน | 3 ห้องต่อรัน ตายตัว: ปริศนา → ศัตรู → ห้องจบ | มี 1 ห้อง (ปริศนา + ผู้เฝ้า) |
| ศัตรู | 3 บทบาทตาม S05 ผู้เฝ้าฝึกเป็นบทบาทแรก บอส 3 ช่วงหลัง slice | มี 1 บทบาท |
| สะสม | คัมภีร์สายเดียว | มีบันทึกแรงลอยตัว 1 ชิ้น |
| สัตว์เลี้ยง | 1 ชนิด + ความผูกพันพื้นฐานที่บันทึกได้ ไม่บังคับเช็กอิน สีแรร์ไม่เพิ่มพลัง | คู่หูดัมมี่ เรียก/เก็บได้ ไม่มีความผูกพัน |
| ผู้เล่น | 12 คน/เซิร์ฟเวอร์ (ตั้งใน Game Settings) กลุ่มสูงสุด 4 | slot หอพักไม่จำกัด รองรับได้ |
| อุปกรณ์อ้างอิง | Android กลางอายุ ~3 ปี + PC | ยังไม่ระบุรุ่นจริง ยังไม่ทดสอบ |
| หอพัก/ร้าน | ห้องตัวอย่างและเฟอร์นิเจอร์ที่มี; ร้านไม่อยู่ใน slice | v2 หลายชิ้นใช้งานแล้ว |

ยังไม่ควรรวมขอบเขตจากทุกแผนย่อยเข้าด้วยกันโดยอัตโนมัติ แผน Dungeon ใช้ศัตรู 3 บทบาท ขณะที่แผนหลักมี 4; ต้องตัดสินใจชุดแรกก่อนผลิต ดู DECISIONS.md

## รายได้และเศรษฐกิจ

ฐานแผนคือซื้อของที่เห็นชัด: ชุด ไม้เท้า/อุปกรณ์แบบ cosmetic อีโมต ท่าโพส เฟอร์นิเจอร์ รูปลักษณ์สมุดเวท และการนำเสนอความสำเร็จ แอนิเมชันแบบซื้อไม่เปลี่ยนเวลาที่มีผลต่อการต่อสู้

ผู้ใช้เปิดรับการสุ่มดรอป/กาชาในคำขอแรก แต่แผนเสนอเลื่อนกาชาเสียเงินหลังพิสูจน์วงจรหลัก การนำกลับมาทำต้องตัดสินใจใหม่และตรวจข้อกำหนดที่ใช้ในเวลาพัฒนา ไม่ถือว่าการขอออกแบบคืออนุมัติขายแล้ว

ติดตามการกลับมาเล่นและความเข้าใจร่วมกับรายได้ ไม่ใช้ยอดซื้ออย่างเดียวเป็นเกณฑ์ความสำเร็จ
