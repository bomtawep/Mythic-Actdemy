# เช็กลิสต์ก่อนปิดงาน/เปิดทดสอบ

รายการยังไม่ได้ติ๊กผ่าน เป็นเกณฑ์ตรวจจากแผนเดิมและการจัดระเบียบในชุดส่งต่อนี้

Step 39 ตรวจ routing โล่หลายผู้เล่นผ่านบริการจริงบน doubles แล้ว แต่เงื่อนไข network/latency/Input/visual ทั้งหมดยังไม่ติ๊กผ่าน

Step 22 ตรวจ callback/lifecycle ของ preview controller ผ่านบน Instance doubles แต่ภาพ/ข้อความ/อินพุตจริงยังไม่ผ่านการตรวจ ไม่ใช้ผลนี้ติ๊ก visual QA

Step 20 full persistence stack ของหอพักผ่านบน API doubles รวมออกระหว่างโหลดและ shutdown แต่ไม่ติ๊กเกมจริง/บริการจริง/ภาพผ่านจากผลนี้

Step 17 DormService สองผู้เล่น/API doubles ผ่านเรื่องสิทธิ์และ lifecycle แต่ยังไม่ตรวจห้อง/ตำแหน่ง/rotation/ภาพในเกมจริงหรือเซฟโหลดห้อง ไม่ติ๊กเกณฑ์หอพักผลิตจริงผ่าน

Step 12 ทดสอบ flow ตัวบริการจริงด้วย API doubles ผ่าน 25 assertions รวมทั้งหมด 247 แต่ยังไม่ตรวจ client/physics/เครือข่าย/DataStore จริง จึงไม่ติ๊กเกณฑ์เกมจริงจากผลนี้

Step 10 ทดสอบกฎ encounter ผ่าน แต่ข้อความ/พื้นที่เตือน latency และความเสียหายใน Roblox ยังไม่ตรวจ ห้ามติ๊กเกณฑ์อ่านท่า/มือถือผ่านจาก unit tests

Step 06: pet policy tests ผ่าน แต่ภาพคู่หู/การตาม/ตายเกิดใหม่/หลายคนยังไม่ได้ตรวจ runtime จึงไม่ติ๊กเกณฑ์คู่หูผ่าน

ตาม D16 ไม่เปิด Studio เพื่อตรวจ งานล่าสุด Step 05 ตรวจ compiler/mocks/build แล้ว แต่ไม่ติ๊กผ่านภาพ/Play/มือถือจากผลเหล่านี้

Step 03 เพิ่มชุดทดสอบ schema และแผนทดสอบ persistence ใน STEP_03.md แล้ว แต่ยังไม่ได้รัน Studio/บริการจริง ห้ามใช้ผล Rojo build แทนผลตรวจบันทึก/โหลดและรับรางวัลซ้ำ

Step 04 รัน compiler และ mock tests ผ่านแล้วตาม STEP_04.md (8 ไฟล์, 84 assertions) รายการตรวจเกม/ภาพ/บริการจริงด้านล่างยังคงไม่ติ๊กผ่าน
