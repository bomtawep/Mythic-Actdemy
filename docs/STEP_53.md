# Step 53 — ตรวจ Studio ส่วนที่เหลือ

ต่อจาก Step 52 วิธีเดียวกัน (ภาพหน้าจอ, command bar, ปุ่มจริง, log) เพิ่ม Device Simulator (Test → Device Simulator, iPhone XR แนวนอน) สถานะที่ตั้งผ่าน command bar ฝั่ง server มีผลเฉพาะ session Play

## ผล

| เรื่อง | ผล |
|---|---|
| คู่หู | ตามตัว ปุ่ม เก็บ/เล่นด้วย/เปลี่ยนชื่อ ขึ้น; ป้ายชื่อและหูมีปัญหา (แก้แล้ว ดูด้านล่าง) |
| ห้อง 1 | ผังตรง ประตู/ปริศนา/จุดเริ่ม/ทางออก HUD "ห้อง 1/3 ยกผลึก…" ถูก |
| ห้อง 3 | ผังตรง แท่นจบ/checkpoint/ทางออก; HUD ยังพูดถึงเงา (แก้แล้ว) |
| หอพัก | กด E ที่ประตูจริง → เข้าห้อง แผงจัดเฟอร์นิเจอร์ครบ ความผูกพัน "พาเข้าหอพัก" บันทึก; ห้องอยู่กลางโรงเรียน (แก้แล้ว) |
| มือถือจำลอง | จอยสติ๊ก/ปุ่มกระโดดของ Roblox ทำงาน; ปุ่มคู่หูทับปุ่มกระโดด (แก้แล้ว) |
| พฤติกรรมที่ถูกต้อง | ตั้ง LessonStage เองแล้วเปลี่ยนชื่อคู่หู → ProgressService เซฟแล้ว sync ค่าจริงกลับ คู่หูถูกเก็บ (server เชื่อข้อมูลที่บันทึก) |

## พบและแก้

1. ป้ายชื่อคู่หูสูง 40px ตัดขั้นความผูกพันบรรทัดสองทิ้ง → 240×64
2. หูใบไม้ใช้ทรง Ball ทำให้เหลือจุดกลม → แผ่น Block แบน; test double เพิ่ม Block และ assert ทรงหู
3. สถานะ Reward ใช้ทั้ง "ผ่านห้อง 2 แต่ยังอยู่ห้อง 2" และ "อยู่ห้อง 3" ทำให้ห้อง 3 พูดถึงเงา และห้อง 2 อาจขึ้น "ห้อง 3/3" → DungeonService ตั้ง `DungeonRoom` ทุกครั้งที่วาร์ป HUD/สมุดใช้ค่านี้ (+3 checks view model, +1 ต่อรอบ service flow)
4. slot หอพักเริ่มที่ (−200, 0, 80k) ซึ่งหลังผัง Step 51 อยู่กลางโรงเรียน ห้องที่ 2 ทับสนามฝึก → x=−1200 นอกแผนที่ (test ปรับพิกัด −198→−1198, −192→−1192)
5. ปุ่มเล่นด้วย/เปลี่ยนชื่อเรียงต่อลงมาทับปุ่มกระโดดบนจอมือถือ → ตาราง 2×2 มุมขวาบน (+1 check) ยืนยันใน simulator แล้ว
- เพิ่ม: เข้าห้องหอพักแล้วขึ้น "อยู่ในห้องของคุณ…" แทนข้อความเดิม "เข้าห้องเพื่อโหลด…"

check_luau ผ่าน 90 ไฟล์ 1234 assertions; Rojo build/sourcemap, check_placeholders ผ่าน; Studio คืนสภาพ (หยุด Play ปิด simulator)

## ข้อสังเกตที่ยังไม่แก้

- บนจอมือถือ กล่องเป้าหมาย + ปุ่ม 4 ปุ่มกินครึ่งบนของจอและบังป้ายชื่อคู่หูบางส่วน ควรทำเมนูคู่หูพับเก็บได้
- ปุ่มยังแสดง [B]/[P] บนอุปกรณ์สัมผัส
- ตัวอักษรไทยในกล่องเป้าหมายเล็กบนจอโทรศัพท์ ต้องดูบนเครื่องจริง

อุปกรณ์จริง (Android อ้างอิง), หลายผู้เล่นพร้อมกัน (Server & Clients), เวลาเดินของคนจริง
