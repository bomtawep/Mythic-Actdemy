# ออกแบบฉาก Vertical slice

สถานะ: ผังนี้สร้างเป็น blockout ในไฟล์ฉากแล้วใน Step 51 (D60 ใช้คำตอบที่แนะนำของข้อ 7) ยังไม่ตรวจภาพหรือเวลาเดินจริงใน Studio อิง S04 (สัดส่วน/เวลาเดิน), S05 (ดันเจียนเรือนกระจก), S07 (ลานแกนแสง/ห้องเรียนส่งผลนอกห้อง) และขอบเขต slice ที่ล็อกใน D55–D59 ชื่อสถานที่ทั้งหมดเป็นชื่อทำงาน

ฉากที่มีตอนนี้เป็น blockout เพื่อทดสอบระบบ (ลาน 100×180 แท่นกล่องสี ดันเจียนกล่อง 3 ห้อง) เอกสารนี้คือผังที่ blockout รอบถัดไปและงานภาพจริงจะยึด

## 1. หลักที่ใช้

| หลัก | ที่มา | ผลต่อผัง |

| ห้องเรียนต้องส่งผลนอกห้อง | S07 | กลไกสีฟ้าอยู่ลานนอกห้องเรียนแรงลอยตัว |

ความเร็วเดินอ้างอิง 16 studs/วินาที (S04) เวลาในตารางคิดระยะตรง × 1.2 สำหรับทางเลี้ยว

## 2. ผัง Academy slice

กรอบเล่นได้ 800×800 studs ตาม S04 "เริ่มทำพื้นที่เล่นให้สมบูรณ์ประมาณ 800×800" ทิศเหนือ = −Z

```
                    เหนือ (−Z)
   x=-400 ┌────────────────────────────────────────┐ x=+400   z=-400
          │                                  X     │
          │        L1        R        L2      \    │
          │                                    \   │
          │                 M                   G  │
          │   D       ┌───────────────┐   ─────/   │
          │           │       P       │            │
          │           │   (แกนแสง)    │            │
          │           └───────────────┘            │
          │                   S                    │
          │     T                                  │
          │ ~~~~~~~~~~~~ ทะเลสาบ (ฉากหลัง) ~~~~~~~~ │
          └────────────────────────────────────────┘          z=+400
                    ใต้ (+Z)
```

| ป้าย | สถานที่ (ชื่อทำงาน) | ตำแหน่งเสนอ (x, z) | ขนาด | ของที่ย้ายมาจาก blockout เดิม |
|---|---|---|---|---|
| S | จุดเกิด ประตูใต้ของลาน | (0, 140) | 24×24 | `PH_Spawn` |
| P | ลานแกนแสง + หอแกนแสงกลาง | (0, 0) | 220×220, หอสูง ~120 | `PH_Floor`/`PH_Path` |
| L1 | ห้องเรียนแรงลอยตัว (ห้องปฏิบัติ) | (−60, −185) | 110×140 | `Lesson`, `PH_LessonCrystal` |
| M | กลไกสีฟ้านอกห้องเรียน | (−80, −70) ขอบลาน | 20×20 | `Puzzle`, `PH_PuzzleCrystal` |
| R | โถงหน้าห้องเรียน แท่นบันทึก | (0, −150) | 40×30 | `Reward` |
| L2 | ห้องเรียนแสงนำทาง | (60, −175) แท่นเริ่ม (60, −150) | 70×90 | `LightLesson`, `LightRune1–3` |
| G | สวนอักขระ (ทางผ่านไปดันเจียน) | (260, −60) | 120×120 | `LightExploreStart`, `ExploreRune1–3` |
| X | ซากวิหาร ประตูดันเจียน | (330, −330) | 60×60 ลานปลอดภัย | `DungeonEntry`, `PH_DungeonReturn` |
| D | ประตูหอพัก | (−250, −20) | 30×20 | `DormEntry` |
| T | สนามฝึกม่านคุ้มกัน | (−230, 190) | 120×150 (ย่อจาก 240×300 ของ S04) | `ShieldLesson` |

ทางหลักกว้าง 30 (S04: 24–36): S→P→R, P→D, P→G→X ทางรองกว้าง 16 (S04: 14–20): P→T, R→L1/L2 สนาม T และสวน G ใช้ขอบธรรมชาติ (แนวไม้/รั้วหิน) แทนกำแพงกล่อง

### เวลาเดินที่คาด

| เส้นทาง | ระยะ ×1.2 | เวลา | เป้า S04 | เป้าเสนอสำหรับ slice |
|---|---:|---:|---:|---:|
| S → L1 (บทเรียนแรก) | ~395 | ~25 วิ | 15–25 | 15–25 ✓ |
| L1 → M → R (วงบทเรียนแรก) | ~275 | ~17 วิ | 15–35 (ห้องต่อห้อง) | ✓ |

| P → T สนามฝึก | ~360 | ~22 วิ | 35–60 | 20–40 |

สวนและดันเจียนสั้นกว่าเป้า S04 เพราะ S04 คิดจากโลก 1,600 studs ผังนี้ใช้เป้าของ slice แทน (ต้องตัดสิน ดูข้อ 7) ตัวเลขคำนวณซ้ำจากพิกัดในไฟล์ฉากหลังสร้าง (Step 51) และวัดจริงใน Studio ด้วย MoveTo เส้นตรงใน Step 52: 20.5 / 13.3 / 15.4 / 18.0 / 16.2 / 38.4 วิ (เร็วกว่าการคำนวณเพราะไม่บวก 20% ทางเลี้ยว) ค่าทั้งหมดต้องวัดจริงใน Studio ก่อนถือว่าผ่าน เสาแกนแสงอยู่กลางทางหลัก S→R ผู้เล่นต้องอ้อม ต้องตรวจว่ารบกวนหรือไม่

## 3. ดันเจียน: เรือนกระจกแห่งเสียงสะท้อน (3 ห้อง)

ใช้ธีม S05: โดมกระจกแตกใต้ดิน รากไม้ยักษ์โอบโครงโลหะ ละอองเกสรเรืองแสง สีหลักเขียวอมฟ้า + ทองอุ่น **ม่วงเข้ม = บริเวณผิดปกติ/อันตราย** เลือกห้อง S05 ที่ตรงกับการเล่นที่มีอยู่ ห้อง S05 อื่น (เพาะเสียง ทางน้ำ รังสัตว์ จุดพัก บอส) อยู่หลัง slice

| ห้อง slice | ห้อง S05 ที่ใช้ภาพ | การเล่นที่มีแล้ว | ขนาดเสนอ (เดิม) |
|---|---|---|---|
| 1 | "ประตูรากไม้" — ส่งพลังให้เมล็ดแสงเปิดทาง | ยกผลึก (= เมล็ดแสง) ถึงระดับ 11 เปิดประตูราก | 70×90 (64×100) |
| 2 | "สวนสะท้อน" — เปลี่ยนทิศแสงพร้อมรับมือศัตรู | ผู้เฝ้า + ผู้ยิง + เงา, อักขระแสงเผยเงา | 90×120 (64×100) |
| 3 | "สวนฟื้นคืน" — รับรางวัลและถ่ายรูป | แท่นจบ + checkpoint | 60×70 (64×60) |

ห้อง 2 ขยายเพราะต้องมีที่หลบแนวยิง (แนว ±3 studs) ทั้งสองข้างของผู้เฝ้า

### ห้อง 2 (มองจากบน เหนือ = ประตูหลัก)

```
   ┌──────────────[ประตูหลัก]──────────────[ประตูข้าง]┐   ← ผนังเหนือ: ผู้ยิง (กลาง)
   │                 เงา                              │
   │                                      อักขระแสง   │
   │   แท่นควบคุม     ┌─────────┐                    │
   │                  │ ผู้เฝ้า  │  ← โซนเตือน 16×16   │
   │                  └─────────┘                    │
   │        ║ แนวยิง (ล็อกตามตำแหน่งผู้เล่น) ║          │
   │                                                 │
   │                   จุดเกิดห้อง 2                  │
   └──────────────────[จาก ห้อง 1]──────────────────┘
```

| สิ่งที่อ่าน | รูปทรง | สี | ข้อความ |
|---|---|---|---|
| โซนผู้เฝ้า | สี่เหลี่ยมพื้นขอบหนา | ส้ม | "กำลังโจมตี! ออกจากพื้นที่สี่เหลี่ยม" |
| แนวยิง | แถบยาวจากผู้ยิงถึงผนังใต้ | ม่วง (ผิดปกติ) | "ผู้ยิงเล็งแนวของคุณ" |
| เงา | รูปทรงสั่นไหวโปร่ง ไม่ใช่กล่อง | ม่วงเข้มเกือบดำ | "เงาขวางประตู" |
| ทางปลอดภัย/ทางอ้อม | ทางเดินรากไม้ยกสูงไปประตูข้าง | ทองอุ่น | ป้าย "ทางอ้อม" |

ห้ามละอองเกสร/หมอกในรัศมีโซนผู้เฝ้าและแนวยิง ตามหลัก S05 "เอฟเฟกต์ไม่บดบังพื้นที่อันตราย"

ห้อง 3: เมื่อเข้าห้อง ฉากเปลี่ยนจากม่วงผิดปกติเป็นแสงอุ่น รากคลายตัว (S05 รางวัลทางภาพ) ทำเป็น client-side ต่อผู้เล่นเพราะสถานะรันแยกรายคน

## 5. โทนภาพต่อโซน

| โซน | อารมณ์ | สีหลัก | วัสดุ | แสง |
|---|---|---|---|---|
| ลานแกนแสง | ปลอดภัย อบอุ่น จุดนัดพบ | หินครีม, น้ำเงิน–ทองที่แกนแสง | หินขัด ไม้ | บ่ายแก่ แสงอุ่นจากแกน |
| ห้องเรียน | ตั้งใจ ชัดเจน | งาช้าง ไม้ ทองเรียบ | ไม้ ผ้า กระจก | สว่างทั่วห้อง ไม่มีเงาบังสถานี |
| สวนอักขระ | สงสัย ค่อยลึกลับ | เขียว ฟ้าอมเขียว | หิน มอส ใบไม้ | ร่มไม้เป็นช่วง อักขระสว่างชัด |

| สนามฝึก | คล่องตัว | หญ้า ทราย ธงสีอ่อน | ดิน ไม้ | กลางแจ้งสว่าง |

## 7. ต้องตัดสินใจ

1. **เป้าเวลาเดิน slice** สั้นกว่า S04 (ข้อ 2) เพราะพื้นที่ 800×800 ยอมรับหรือขยายกรอบ
2. **ดันเจียนเดินต่อเนื่องหรือวาร์ป:** S04 ให้เดินต่อเนื่องระหว่างห้อง แต่ D56 ใช้ประตูวาร์ปเพราะห้องร่วมกันและสถานะแยกรายคน ทางเลือก: คงวาร์ป / ทางเดินต่อเนื่องที่มีประตูกั้นเฉพาะ client
3. **ขนาดห้องหอพัก** 28×32 (S06) หรือ 60×70 (S04)
4. **ชื่อ "เรือนกระจก":** DECISIONS ยังไม่ยืนยันว่า "เรือนกระจกที่ลืมฤดู" กับ "แห่งเสียงสะท้อน" เป็นที่เดียวกัน ผังนี้ใช้ชื่อหลังกับดันเจียนเท่านั้น
5. **เวลาในเกม** บ่ายแก่คงที่ หรือมีรอบวัน
