# Step 01 — วงจรแรงลอยตัวแบบ blockout

ขอบเขตทดลองที่เลือกจาก PLAYER_SYSTEMS: จุดเกิด → แท่นฝึก → ใช้เวทกับกลไก → บันทึกนักเรียน ไม่ใช่บทเรียนฉบับผลิตจริง การกด prompt ให้ผลึกยกเป็นการพิสูจน์ลำดับเบื้องต้น ยังไม่ใช่ระบบยก/หมุน/วางวัตถุอิสระ

บันทึกนี้เป็นขั้นเดิม: พฤติกรรม prompt ผ่านทันทีถูกแทนด้วยบทฝึกควบคุมระดับใน [Step 02](STEP_02.md) แล้ว ใช้เกณฑ์ทดสอบใน Step 02 สำหรับโค้ดปัจจุบัน

## ไฟล์และวิธีทดสอบ

1. `mkdir -p build` แล้ว `rojo build -o build/MythicAcademy.rbxlx`
2. เปิดไฟล์ใน Studio ตรวจเห็นพื้น ทางเดิน จุดเกิด แท่นและผลึกก่อน Play
3. กด Play เดินจากจุดเกิดไปแท่นม่วง กด E หรือ prompt สัมผัส → ผลึกยกและขั้นเปลี่ยนเป็น 1/3
4. ไปแท่นฟ้า → ผลึกยกและขั้น 2/3 จากนั้นแท่นทอง → 3/3 และ `LessonRecord=true`
5. ลองข้ามบทเรียน รับซ้ำ ตาย/เกิดใหม่ และทดสอบ 2 ผู้เล่น ต้องไม่ข้ามขั้นหรือแจกซ้ำ ความก้าวหน้าแต่ละคนแยกกัน ผลึกเป็นภาพร่วม
6. ออกจากเกมแล้วเข้าใหม่: เริ่มใหม่ตามขอบเขต session-only ยังไม่มี DataStore
7. ตรวจมือถือข้อความไทยไม่ตัด ไม่ทับปุ่ม และวัดเวลาเดิน/กล้องจริงก่อนปรับขนาดฉาก

## หลักฐานปัจจุบัน

Rojo 7.7.1 build และ sourcemap ผ่าน ตรวจ XML พบฉากถาวร จุดเกิด แท่น ผลึก และ ProximityPrompt 3 จุดครบ นี่เป็นการตรวจ export/โครงสร้าง ไม่ตรวจไวยากรณ์ Luau หรือรับรอง runtime

ยังไม่ตรวจภาพและ Play: Computer Use ไม่ได้รับสิทธิ์บนเครื่องนี้ ห้ามติ๊ก QA เกมผ่านจากผล build

## ขั้นต่อไปตามลำดับ

- ตรวจ Studio ตามรายการข้างบน แก้ระยะเดิน กล้อง UI และ runtime ที่พบ
- เปลี่ยน prompt สาธิตเป็นบทฝึกควบคุมแรงลอยตัวที่ลองผิดและลองใหม่ได้
- แยกบริการความก้าวหน้า/รางวัล เพิ่มบันทึกและโหลดพร้อมกรณีล้มเหลวก่อนเพิ่มของสะสมจริง
- ขยายเป็น vertical slice สัตว์หนึ่งตัวและดันเจียนสั้น แล้วค่อยเพิ่มระบบหลัก/คอนเทนต์/สังคมและร้านตาม ROADMAP

ยังไม่เปิดเผยแพร่ ไม่มีสินทรัพย์ภายนอกเพิ่ม และไม่ได้นำโมเดลพ่อมดเข้า Roblox
