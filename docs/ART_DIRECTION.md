# ภาพ โมเดล และ Aura

## ทิศทางภาพ

แฟนตาซีโรงเรียนเวทมนตร์ที่มีเอกลักษณ์ของตนเอง ใช้ภาพอ้างอิงเพื่อกำหนดรูปทรง วัสดุและอารมณ์ แต่ต้องบันทึกสิทธิ์ งาน chibi น้ำเงิน–ทองกับพ่อมดเครายาวม่วง–ทองเป็นคนละงานต้นแบบ ไม่ควรรวมเป็นตัวละครเดียวโดยไม่ได้ตัดสินใจ [S17, S20, S16]

ผู้ใช้ต้องการรูปทรงเป็นธรรมชาติและอนุญาตใช้ mesh ปรับผิว งานต้องแก้ silhouette/ใบหน้า/เครา/ไหล่/มือก่อนเพิ่มเส้นและลาย [S15, S21]

## Aura ฉบับแก้ล่าสุด [S03]

| Rarity | รูปลักษณ์ฐาน |
|---|---|
| Common | ไม่มี Aura |
| Uncommon | ขอบสีอ่อนเมื่อชี้/เลือก |
| Rare | ขอบฟ้าบาง ไม่มีประกายลอย |
| Epic | ขอบม่วง แสงไหลบนผิวเป็นครั้งคราว |
| Legendary | ขอบทอง แสงหายใจเบา ไม่มีวงแหวนรอบตัว |
| Mythic | ขอบขาวมุก ลายเวทบนผิวสั้น ๆ เมื่อใช้ |

หนึ่งชิ้นใช้สีหลักเดียวและเอฟเฟกต์เด่นอย่างเดียว แสงชิดวัตถุ ใส่หลายชิ้นให้เด่นเพียงชิ้นที่เลือก ของดรอปใช้วงพื้นบางและชื่อเมื่อเข้าใกล้ ความแรร์เพิ่มความประณีต ไม่เพิ่มขนาดและความสว่างจนบังเกม

ข้อเสนอเดิมเรื่องวงแหวน อักขระและดาวหลายชั้นถูกทิศทางฉบับนี้แทนแล้ว ห้ามอ่านต้นทางช่วงแรกแล้วนำกลับมาโดยข้ามคำแก้ผู้ใช้

## ขั้นตอนโมเดล

ภาพหลายมุม → blockout → ตรวจ silhouette รอบตัว → ผิวต่อเนื่องและวัสดุ → rig/weight → pose stress test → คลิปเคลื่อนไหวและ loop → export/re-import → ตรวจภาพส่งมอบ

แยกการตรวจไวยากรณ์, รัน Blender, เรนเดอร์, rig deformation และ export ไม่อ้าง game-ready หากยังขาดการทดสอบปลายทาง งานพ่อมดล่าสุดหยุดขอบเขตนำเข้า Roblox ตามคำสั่งผู้ใช้ แต่ยังเก็บโมเดล/วัสดุ/rig/animation ต่อได้

เกณฑ์ภาพ: หน้าไม่เป็นก้อนแปะ เคราช่อใหญ่เล็กไหลซ้อน ไหล่สัมพันธ์แขนและผ้า นิ้วกำไม้เท้าเป็นธรรมชาติ หมวกมีจังหวะโค้ง ท่าไม่ทะลุเครา/เสื้อ และไม่เพิ่มรายละเอียดเพื่อซ่อนปัญหารูปทรง
