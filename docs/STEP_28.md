# Step 28 — audit เส้นทางผู้เล่นใหม่และเอกสารปัจจุบัน

เพิ่ม flow บริการจริงบน doubles เริ่ม Stage 0: ปฏิเสธเข้า dungeon/รับบันทึกก่อนเวลา ยกเลิกแล้วเริ่มใหม่ วางผิด/ลองใหม่ ผ่านแท่นม่วง ปลดเวท ใช้กลไก รับบันทึกครั้งเดียว และจบดันเจียนตาม flow เดิม ข้อมูลอีกคนไม่เปลี่ยน

ProgressService ใน flow นี้เป็น stand-in ที่เปลี่ยนขั้นตามกฎ; storage ของ progress มีชุดทดสอบแยก เช่นเดียวกับหอพัก v2 มี flow แยก ไม่อ้างว่าเป็นการเล่นทั้งเกมแบบ end-to-end หนึ่ง session จริง
