# โลก พื้นที่ และการเดินทาง

ฐานแผน: S04–S07 ทุกขนาดเป็นค่าทดลอง blockout ไม่ใช่แบบก่อสร้างที่ล็อกแล้ว

## Academy

ผังฉากของ Vertical slice (ข้อเสนอ ตำแหน่ง/ขนาด/เวลาเดิน/ธีมดันเจียน 3 ห้อง/โทนภาพ) อยู่ที่ [SCENE_DESIGN_SLICE.md](SCENE_DESIGN_SLICE.md)

โครงสร้างสามระดับ: เรือนยอด (หอดูดาว/สวนลอยฟ้า), ชีวิตนักเรียน (ลาน ห้องเรียน กิจกรรม), ฐานรากเก่า (ระบบพลังงาน ห้องลับ) จุดสำคัญต้องมีเกมเพลย์ให้ใช้จริง

| สัดส่วนพื้นดิน | ร้อยละ |
|---|---:|
| อาคารเรียนและหอสมุด | 22 |
| ลานกลางและทางเข้า | 10 |
| สวนและเรือนกระจก | 14 |
| ป่าและซากโบราณ | 20 |
| ทะเลสาบและท่าเรือเหาะ | 12 |
| ตลาดและลานสังคม | 8 |
| สนามฝึก | 8 |
| ทางเชื่อมและพื้นที่กันชน | 6 |

ลานใช้งาน 220×220 studs; โถง 160×220; ห้องเรียน 70×90; ห้องภาคปฏิบัติ 110×140; ทางหลักกว้าง 24–36 และทางรอง 14–20 studs เป็นตัวอย่างจาก S04 ขอบเขตโซนใหญ่กับพื้นที่ใช้งานจริงเป็นคนละค่า อย่านำมาแทนกัน

เป้าเดินจากจุดเกิดถึงบทเรียนแรก 15–25 วินาที; ตลาด/หอพักจากลาน 20–40 วินาที; ประตูดันเจียนครั้งแรก 60–90 วินาที ให้ทดสอบการเดินและกล้องก่อนขยายฉาก

## Dorm

Implementation Step 16: ห้อง template 28×32 สร้างแยกตำแหน่งต่อผู้เล่นใน server มีม้านั่งวางแบบ grid หนึ่งชิ้นและ prompt กลับโรงเรียน ยังไม่บันทึกข้าม server ไม่มีเชิญแขก/สิทธิ์เข้าห้องเชิงกายภาพหรือหอพักหลายชั้น ดู STEP_16.md

ข้อเสนอคือหอพักรอบต้นไม้เก็บความทรงจำ มีโถงรวม พื้นที่กิจกรรม ห้องส่วนตัว และพื้นที่สัตว์เลี้ยง ขนาดรวมตั้งต้น 500×500 studs / 3–4 ชั้น; ห้องส่วนตัวในแผนละเอียดประมาณ 28×32 studs เพดาน 16 studs ต้องตรวจกล้องและอวตารหลายขนาด

วาง/ย้าย/หมุน/เก็บของ ตรวจขอบเขตและสิทธิ์ บันทึกแล้วกลับมาเหมือนเดิม การขยายห้องไม่บังคับยอดไลก์หรือคนเยี่ยม ไม่ใช้การกลับห้องเป็นงานบ้านลงโทษผู้เล่น

## Dungeon

Step 08 เพิ่มจุด checkpoint ใกล้แท่นจบในห้องทดลอง ตายแล้วรันพักอยู่ กลับเข้าประตูที่โรงเรียนเพื่อไปต่อจากสถานะเดิมได้ เฉพาะ server/รอบเล่นเดียวกัน ไม่ใช่ checkpoint ถาวรหรือ party recovery

Implementation Step 47 (D55): ดันเจียน 3 ห้องตายตัวใน Place เดียว ห้อง 1 ปริศนา (x=200, 64×100) → ห้อง 2 ผู้เฝ้า (x=300, 64×100) → ห้อง 3 ห้องจบ (x=400, 64×60) เชื่อมด้วย prompt วาร์ปที่เปิดตามสถานะรายคน ทุกห้องมีประตูกลับ ยังเป็น blockout ไม่ใช่ “เรือนกระจก” ตามแผน

Implementation Step 07: ห้องทดลองแรงลอยตัว 64×100 studs ใน Place เดียว เข้าหลังจบบทเรียน มีประตูกลับตลอดรัน สถานะแยกต่อผู้เล่นแต่ห้องร่วม ไม่มีศัตรู/บอส/party หรือรางวัลถาวร รายละเอียด STEP_07.md ขนาดและเนื้อหานี้เป็น blockout ทดลอง ไม่แทนขนาด/คอนเทนต์ MVP ด้านล่าง

Hub ภาคสนามมีโต๊ะภารกิจ รวมทีม เตรียมเวท และทางกลับ แยกรอบของทีมจากพื้นที่ส่วนกลาง Dungeon แรกที่เสนอคือ “เรือนกระจกแห่งเสียงสะท้อน” บอส “ผู้พิทักษ์แก่นสะท้อน” เน้นช่วยแก้ความผิดปกติของระบบนิเวศ

แผนละเอียด S05 เสนอห้องหลัก 6 แบบ ห้องเสริม 2 และห้องบอส 1, เส้นทางตรวจแล้ว 2 แบบ, ศัตรู 3 บทบาท, บอส 3 ช่วง และปริศนาแสง น้ำ ลำดับเสียง ตัวเลข “แบบห้อง” ไม่ได้หมายถึงทุกห้องต้องอยู่ในทุกรัน

S04 เสนอขอบเขตดันเจียนประมาณ 600×900 studs ต่อรอบ และ 6–8 ห้องหลัก ต้องรวมแผนผังกับ S05 ก่อนล็อก

## การเดินทาง

แยกวาร์ปภายใน Place กับการไป Place อื่น จุดเดินทางใน Academy ได้แก่กลาง สวน สนามฝึก ท่าเรือ และซากวิหาร บางจุดเปิดหลังสำรวจหรือภารกิจแนะนำ

ทดสอบไป–กลับ ชื่อปลายทาง จุดเกิด ทีมที่หลุด วาร์ปไม่สำเร็จ และเส้นทางออกจากห้องลับ ห้ามเควสต์/วาร์ปส่งเข้าโซนที่ปิดอยู่

เกาะเล็ก 600×600, เกาะใหญ่ 1,000×1,000 และสนามแข่งขัน 400×600 studs เป็นแนวขยาย ไม่ได้รวมใน MVP โดยอัตโนมัติ ตารางตำแหน่งและเงื่อนไขฉบับเต็มอยู่ใน S04
