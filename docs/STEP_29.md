# Step 29 — เวทแสงนำทางและปริศนาอักขระ

เพิ่มบททดลองที่สองหลัง Stage 3: LightLesson ฝั่งซ้ายลานเริ่มเวทและรีเซ็ตโจทย์ แล้วร่ายที่อักขระ I/II/III ให้เป้าหมาย 1สว่าง 2ดับ 3สว่าง

- I สลับ 1+2, II สลับทั้งสาม, III สลับ 2+3 จากจุดเริ่มดับทั้งหมด คิดลำดับ/ลองแก้ต่อได้ ไม่ใช่ยกความสูงผลึกแบบเดิม
- server ตรวจข้อมูลพร้อม/Stage 3/ระยะ/ชีวิต/ไม่อยู่หอพักหรือรันอื่น/throttle ก่อนเริ่มและร่าย State แยกต่อผู้เล่น ไม่เพิ่ม RemoteEvent
- เรียนแล้วใช้เวทผ่าน prompt ที่อักขระในต้นแบบนี้ ยังไม่ใช่เล็งร่ายอิสระ ไม่เพิ่มระบบโจมตีหรือเวททั้ง 12 แบบของ MVP
- HUD แสดงเป้า/คำใบ้; PointLight และป้ายสถานะรายคนใช้แสงชิดแท่นและข้อความ ไม่เพิ่ม Aura วงแหวนหรือประกาย
- ตาย ออกพื้นที่ หรือเริ่มกิจกรรมอื่นหยุด trial กลับมาเริ่มใหม่ที่แท่นได้ LightUnlocked/LightCompleted เก็บเฉพาะรอบเล่น ไม่เปลี่ยน ProgressSchema หรือแจกของถาวร
