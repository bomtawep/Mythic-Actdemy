# Step 55 — blockout รอบ 2

ผู้ใช้สั่งทำ "blockout รอบ 2" ให้ฉากอ่านเป็นสถานที่ได้ ยังเป็นชิ้นพื้นฐาน/วัสดุของ Roblox ไม่ใช่งานภาพจริง ทุกชิ้นลงทะเบียนดัมมี่ สคริปต์สร้าง `scripts/blockout_round2.py` (รันซ้ำได้ ลบผลเดิมก่อน)

## เปลี่ยน

- วัสดุ/สีตาม SCENE_DESIGN_SLICE §5 บนชิ้นเดิมโดยไม่เปลี่ยนชื่อ: หญ้ารอบนอก, ลาน Slate, ทาง Cobblestone, ขอบแผนที่แนวพุ่ม LeafyGrass, ทะเลสาบกระจกฟ้า, พื้นไม้ห้องเรียน/โถง, ทรายสนามฝึก, ซากวิหาร Slate, ดันเจียนพื้นดิน+ผนังโลหะ
- `Academy.PH_Decor` (Folder ไม่ชนชื่อที่ระบบค้นหา และ test อ่านพิกัดเฉพาะชั้นบนสุด):
  - ห้องเรียนแรงลอยตัว: ผนัง x −115..−20 (หดจากแผ่นพื้นเพื่อไม่ทับทางหลักกว้าง 30) ประตูกว้าง 30 ด้านใต้ หลังคา
  - ห้องเรียนแสง: ผนัง x 25..95 ประตูกว้าง 24 ด้านใต้ หลังคา
  - ยอดผลึก Neon บนหอแกนแสง, เสาหัก 6 ต้น + ซุ้มเหนือประตูดันเจียน, แนวพุ่มด้านตะวันออก/ใต้ของสวน (เปิดฝั่งลานและทางขึ้นซากวิหาร), ป้ายบอกทาง 5 จุด (BillboardGui)
- `PH_DungeonCeiling` เพดานกระจกเขียวอมฟ้าโปร่ง 0.55 บน 3 ห้องดันเจียน (ปิดท้องฟ้าตามธีมใต้ดิน)

## ผลตรวจ

- check_luau ผ่าน 91 ไฟล์ 1236 assertions เท่าเดิม; Rojo build (วัสดุ/UDim2 ในไฟล์ฉากผ่าน) และ check_placeholders 86 แถวผ่าน
- Studio (เปิด build ใหม่): มุมบนเห็นห้องเรียนผนังงาช้าง หลังคากระเบื้อง ประตูหันลาน ลานหิน หญ้า ทางหินกรวด ผลึกเรืองแสง; ระดับสายตาจากจุดเกิดเห็นห้องเรียนและแท่นข้างในผ่านประตู ป้าย "↑ ลานแกนแสง • ห้องเรียน" แสดง; แสงบ่ายแก่ (ClockTime 16.5) แสดงเมื่อเปิดไฟล์ build ใหม่
