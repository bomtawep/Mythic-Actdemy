# Step 07 — ห้องดันเจียนปริศนาสั้น

อัปเดต Step 08: พฤติกรรมตายล้างรันในบันทึกนี้ถูกแทนด้วยพักรันและกู้คืน checkpoint ภายใน server เดิม ดู STEP_08.md

ขอบเขตทดลอง: จบบทเรียน Stage 3 → ประตูข้างแท่นบันทึก → ห้องปริศนาแรงลอยตัวเป้า 11 → รับผลทดลอง → กลับโรงเรียน เป็นการเริ่มพิสูจน์วงจรดันเจียน ไม่ใช่ดันเจียน MVP เต็มหรือชื่อเรือนกระจกที่ล็อกแล้ว

- ฉากถาวรอยู่ใน `src/world/Academy.model.json` ห้อง 64×100 studs มีพื้น กำแพง ประตูกลับ แท่นปริศนาและแท่นจบ อยู่บริเวณ x=200 แยกจากลาน
- DungeonService ตรวจระยะ/ผู้เล่นมีชีวิต/สิทธิ์ Stage 3 ก่อนเข้า ย้ายภายใน Place เดียว ไม่ใช้ TeleportService
- DungeonRules กำหนด Idle → Puzzle → Reward → Complete; ข้ามขั้นหรือรับผลซ้ำในรันเดิมไม่ได้ กลับออกได้ทุกขั้นโดยไม่ต้องแก้ปริศนา
- สถานะรันแยกต่อคน แต่ใช้ห้องกายภาพร่วมกัน ยังไม่ใช่ private instance หรือ party session ภาพผลึกส่วนตัวใช้ระบบเวทเดิม
- ผลจบคือ attribute `DungeonCompleted=true` เฉพาะรอบเล่น ไม่แจกเงิน/ไอเทมและไม่เปลี่ยน schema เซฟ เริ่มรันใหม่ได้หลังออก; เครื่องหมายเคยจบคงอยู่จนออกเกม
- ตายยกเลิกรันและเกิดที่โรงเรียน ออกจากเกมล้างสถานะ ไม่บันทึก checkpoint; การกลับระหว่างฝึกยกเลิก session เวทด้วยการตรวจ station/ระยะ
- คู่หูใช้ระบบตามเดิม เมื่อระยะห่างมากจะย้ายกลับใกล้เจ้าของ ยังไม่ตรวจภาพการผ่านประตูจริง

## ผลตรวจ

Luau compiler 19 ไฟล์ผ่าน; tests 84 progress + 28 journal + 28 pet + 21 dungeon = 161 assertions ผ่าน Rojo build/sourcemap และโครงสร้าง XML ผ่าน ไม่เปิด Studio ตาม D16 ยังไม่ตรวจ physics/ระยะใช้งานจริง/ภาพ/วาร์ป/หลายคนหรือ runtime Roblox

ไม่มีศัตรู บอส ประตูล็อก รางวัลถาวร party หรือระบบกู้คืนรัน เพิ่มภายหลังเมื่อแยก reward/session model เหมาะสม ไม่ยัดลง Stage บทเรียน

## งานถัดไป

เพิ่ม checkpoint/การกู้คืนและแยกบริการบทเรียนออกจาก Main ก่อนขยาย encounter แล้วเลือกศัตรูหนึ่งพฤติกรรมสำหรับทดลอง ตามขอบเขตใน DECISIONS ไม่รวมจำนวนศัตรูจากทุกแผนอัตโนมัติ
