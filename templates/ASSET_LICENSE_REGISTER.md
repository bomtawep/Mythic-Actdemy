# ทะเบียนที่มาและสิทธิ์สินทรัพย์

แบบฟอร์มเพื่อทำตามกฎผู้ใช้ S11 ไม่ใช่หลักฐานว่า asset ใดได้รับสิทธิ์แล้ว

|---|---|---|---|---|---|---|---|---|---|
| รอกรอก | | | | | ยังไม่ตรวจ | ยังไม่ตรวจ | | | ยังไม่ตรวจ |

ครอบคลุมโมเดล ภาพ texture เพลง เสียง ฟอนต์ โค้ด และภาพอ้างอิง ตรวจเงื่อนไขตามวิธีใช้งานจริง เก็บหลักฐานไว้กับรายการ ชื่อเกมและเครื่องหมายเป็นงานตรวจแยก อย่าทำเครื่องหมายผ่านจากคำว่า “AI generated”

ภูมิทัศน์ D63: geometry สร้างจากโค้ด `scripts/landscape_academy.py` ภายในโครงการ ไม่มีภาพอ้างอิง/โมเดล/texture ดาวน์โหลด ใช้วัสดุ built-in Roblox; ไม่อ้างสิทธิ์เชิงพาณิชย์อัตโนมัติจากการใช้ AI ต้องตรวจตามเงื่อนไขแพลตฟอร์มก่อนเผยแพร่ สถานะ: งานศึกษา ยังไม่ตรวจสิทธิ์ขั้นเผยแพร่
