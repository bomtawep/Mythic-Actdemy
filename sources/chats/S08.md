### ผู้ใช้

ลองออกแบบ สำรวจและแก้ปริศนา ห้องลับ ทางเดินเปลี่ยนตำแหน่ง เกาะลับ

### ผู้ช่วย — ข้อเสนอ/รายงานในเวลานั้น

สำหรับ **Mythic Academy** ผมอยากให้การสำรวจทำให้ผู้เล่นรู้สึกว่า **“โรงเรียนนี้มีความลับที่เราเรียนรู้และเข้าใจได้จริง”** เช่น เห็นหน้าต่างจากลานด้านนอก แต่เดินเข้าอาคารแล้วกลับไม่มีห้องนั้น หรือได้ยินระฆังจากเกาะที่ไม่ปรากฏบนแผนที่

ระบบนี้จะเชื่อมกับ **การเรียนวิชา คัมภีร์ สัตว์เลี้ยง บันทึกโลก และการเข้าสังคม** โดยความก้าวหน้ามาจากการสังเกตและทดลอง ส่วนของขายเป็นของแต่งตัวและของตกแต่งที่ได้แรงบันดาลใจจากการสำรวจ

ชื่อ สถานที่ และตำนานต่อไปนี้เป็นแนวคิดตั้งต้นสำหรับโลกของเกมเราเอง

**1. วงจรการเล่นหลัก: สงสัย → ทดลอง → ค้นพบ → เข้าใจโลกมากขึ้น**

ตัวอย่างการเล่นหนึ่งรอบ:

1. ผู้เล่นเห็นเงาของต้นไม้ชี้ไปคนละทิศกับแสง
2. ใช้วิชาอ่านร่องรอย ตรวจพบว่าเงานี้เป็นข้อความ
3. ตามเงาไปยังสวนที่ไม่มีบนแผนที่
4. แก้ปริศนาเพื่อเปิดห้องเก็บเมล็ดพันธุ์
5. พบของสะสมและบันทึกเกี่ยวกับสวนลอยฟ้าที่สูญหาย
6. บันทึกนั้นกลายเป็นเบาะแสสำหรับการเดินทางไปเกาะลับ

แต่ละการค้นพบควรให้รางวัลอย่างน้อยสองอย่าง ได้แก่ **ของที่ใช้หรือแสดงได้ทันที** และ **ข้อมูลที่เปลี่ยนวิธีมองสถานที่เดิม**

กำหนดขนาดกิจกรรมไว้สามระดับ:

| ขนาด | เวลาเป้าหมาย | ตัวอย่าง |
|---|---:|---|
| ความลับเล็ก | 2–5 นาที | เปิดช่องซ่อนในโต๊ะ เรียงวัตถุให้ตรงกับเงา |
| การสำรวจหลัก | 10–20 นาที | ห้องลับหลายขั้น ทางเดินเปลี่ยนตำแหน่ง |
| ปริศนาระยะยาว | แบ่งเล่นหลายครั้ง | รวบรวมพิกัดเพื่อค้นพบเกาะลับ |

เวลาเหล่านี้เป็นเป้าหมายออกแบบเบื้องต้น ต้องปรับจากการทดสอบจริง

**2. เครื่องมือสำรวจ: ใช้ความรู้จากห้องเรียนได้จริง**

ไม่ควรมีปุ่มเดียวที่สแกนแล้วบอกทุกคำตอบ แต่ให้แต่ละวิชาเผยข้อมูลคนละชนิด

| วิชา/เครื่องมือ | ทำอะไรได้ | ตัวอย่างการใช้ |
|---|---|---|
| อ่านร่องรอย | เห็นร่องรอยเวทมนตร์ในอดีต | เห็นว่าตู้เคยถูกย้ายไปตรงไหน |
| หักเหแสง | เปลี่ยนทิศแสงหรือแยกชั้นภาพ | ส่องสัญลักษณ์ที่ซ้อนกันบนผนัง |
| สะท้อนเสียง | ฟังเสียงที่ติดค้างในวัตถุ | ได้ยินลำดับระฆังที่เคยใช้เปิดประตู |
| เชื่อมพลัง | ต่อวงจรเวทมนตร์ชั่วคราว | จ่ายพลังให้สะพานหรือกลไก |
| สนทนาธรรมชาติ | อ่านสัญญาณจากพืชและสัตว์ | เรียนรู้ว่าเส้นทางใดถูกน้ำท่วม |
| สมุดสำรวจ | เก็บเบาะแสและข้อสังเกต | เปรียบเทียบภาพก่อนและหลังห้องเปลี่ยน |

**วิชาพื้นฐานที่จำเป็นต่อการสำรวจต้องเรียนได้แน่นอน** ไม่ผูกไว้กับการสุ่มดรอป ส่วนคัมภีร์หายากเพิ่มวิธีแก้ทางเลือกหรือรูปแบบเอฟเฟกต์ได้

ตัวอย่าง ประตูที่ต้องส่งพลังข้ามช่องว่างอาจแก้ด้วยการหมุนกระจกตามบทเรียนพื้นฐาน หรือใช้วิชาขั้นสูงสร้างตัวนำเพิ่ม แต่ทั้งสองทางได้รางวัลหลักเท่ากัน

**3. ห้องลับ: แต่ละห้องต้องมีเหตุผลที่ถูกซ่อน**

ห้องลับไม่ควรเป็นเพียงกำแพงปลอมและหีบ ให้มีเจ้าของเดิม หน้าที่ และสิ่งที่เกิดขึ้นในนั้น

**ห้องที่หนึ่ง — หอจดหมายเหตุเงา**

- **เบาะแส:** จากลานโรงเรียนมองเห็นหน้าต่างเจ็ดบาน แต่ภายในมีเพียงหกห้อง
- **ทางเข้า:** จุดโคมไฟให้เงากรอบหน้าต่างทับกับแนวประตูที่หายไป
- **ปริศนา:** จัดแสงให้เห็นข้อความสามชุดบนผนังเดียวกัน
- **จุดค้นพบ:** ข้อความแต่ละชุดถูกเขียนโดยคนต่างยุคและมีข้อมูลขัดแย้งกัน
- **รางวัล:** หน้าบันทึกโลก กรอบภาพเงา และเบาะแสของห้องถัดไป

ผู้เล่นต้องสังเกตโครงสร้างอาคารก่อน แล้วจึงใช้วิชาช่วยพิสูจน์ข้อสงสัย

**ห้องที่สอง — เรือนเพาะฤดูหลงทาง**

ห้องทดลองที่แต่ละมุมติดอยู่ในฤดูต่างกัน

- ย้ายเมล็ดพันธุ์ผ่านพื้นที่ชื้น หนาว และอบอุ่นตามลำดับการเติบโต
- อ่านภาพวงจรชีวิตของพืชเพื่อเข้าใจลำดับ ไม่ต้องเดาสุ่ม
- พืชที่โตแล้วสร้างสะพานเถาวัลย์ไปยังชั้นบน
- ทดลองผิดแล้วพืชกลับเป็นเมล็ดทันที พร้อมแสดงว่าขาดเงื่อนไขใด

รางวัลเป็นกระถางตกแต่งหอพัก บันทึกพืช และท่าทางดูแลสวนสำหรับสัตว์เลี้ยง

**ห้องที่สาม — ห้องเสียงที่ยังไม่จบ**

เครื่องดนตรีเวทมนตร์เล่นเพลงค้างไว้ เพราะเสียงสุดท้ายหายไป

- สำรวจวัตถุในห้องเพื่อฟังเสียงที่สะสมอยู่
- จับคู่เสียงกับรูปคลื่นและสัญลักษณ์
- นำเสียงกลับไปวางในลำดับที่ถูกต้อง
- เมื่อเล่นครบ ห้องจะฉายเหตุการณ์ในอดีตผ่านภาพและเสียง

ต้องมีรูปคลื่น จังหวะกระพริบ และคำบรรยายให้แก้ได้โดยไม่เปิดเสียง

**ห้องที่สี่ — ห้องทดลองแรงลอยตัว**

- เปลี่ยนทิศแรงดึงของวัตถุเฉพาะชิ้น
- ทำให้แท่นลอยเรียงเป็นทางเดิน
- ใช้น้ำหนักถ่วงเพื่อค้างกลไก
- มีจุดรีเซ็ตใกล้มือและไม่มีการสูญเสียของเมื่อพลาด

ห้องนี้เน้นการทดลองเชิงกายภาพ เหมาะกับผู้เล่นที่ไม่ชอบอ่านข้อความยาว

**กฎร่วมของห้องลับ**

- มีเบาะแสอย่างน้อยสองช่องทาง เช่น ภาพกับเสียง หรือบทสนทนากับสภาพแวดล้อม
- เปิดแล้วบันทึกลงสมุด ไม่ต้องแก้ทางเข้าเดิมทุกครั้ง
- ปริศนาที่ทำสำเร็จเปิดทางลัดถาวรให้ผู้เล่นคนนั้น
- การลองผิดไม่กินไอเทมหายาก
- ห้องโบนัสซ่อนได้ลึก แต่เส้นทางหลักต้องไม่ติดเพราะหาของจุดเล็กมากไม่เจอ

**4. ทางเดินเปลี่ยนตำแหน่ง: เปลี่ยนอย่างมีกฎให้เรียนรู้ได้**

เสนอพื้นที่ชื่อ **“โถงวงโคจร”** เป็นปีกอาคารที่ห้องต่าง ๆ เคลื่อนรอบแกนกลาง เมื่อระฆังดัง ประตูเดิมอาจเชื่อมกับห้องใหม่

ความสนุกคือผู้เล่นค่อย ๆ เข้าใจว่าอาคารทำงานอย่างไร

กำหนดสามสถานะ:

| สถานะ | สิ่งที่สังเกตได้ | การเชื่อมต่อเด่น |
|---|---|---|
| รุ่งอรุณ | เส้นแสงสีทองและสัญลักษณ์ดวงอาทิตย์ | ห้องเรียนเชื่อมกับเรือนกระจก |
| สนธยา | โคมสีม่วงและสัญลักษณ์ขอบฟ้า | เรือนกระจกเชื่อมกับหอจดหมายเหตุ |
| ราตรี | แสงสีฟ้าและสัญลักษณ์ดาว | หอจดหมายเหตุเชื่อมกับหอดูดาว |

ใช้ทั้งสี รูปร่าง และชื่อสถานะ ไม่ใช้สีอย่างเดียว

**ตัวอย่างปริศนา**

เป้าหมายคือขน “แสงดาวที่หลับอยู่” จากเรือนกระจกไปหอดูดาว

1. เข้าสู่เรือนกระจกในสถานะรุ่งอรุณ
2. นำแสงไปฝากไว้ที่แท่นซึ่งไม่เคลื่อนตามอาคาร
3. เปลี่ยนโถงเป็นสนธยาเพื่อเข้าถึงกลไกอีกด้าน
4. เปิดช่องส่งแสงเข้าสู่หอจดหมายเหตุ
5. เปลี่ยนเป็นราตรีแล้วพาแสงไปปลุกแผนที่ดาว

ผู้เล่นจึงต้องคิดทั้งเรื่อง **ตำแหน่ง เส้นทาง และสิ่งที่คงอยู่หลังการเปลี่ยนสถานะ**

**ป้องกันความหงุดหงิด**

- มีโถงกลางที่ไม่เปลี่ยนตำแหน่งและกลับถึงได้เสมอ
- แจ้งเตือนก่อนเปลี่ยน พร้อมป้ายบอกสถานะถัดไป
- ห้องปริศนาสำคัญให้ผู้เล่นสั่งเปลี่ยนเองได้
- ไม่ย้ายพื้นใต้เท้าหรือปิดประตูหนีบผู้เล่น
- มีคำสั่งกลับจุดปลอดภัยโดยไม่เสียรางวัล
- แผนที่บันทึกเฉพาะเส้นทางที่ค้นพบแล้ว พร้อมสลับดูแต่ละสถานะ

สำหรับพื้นที่สาธารณะ ใช้การเปลี่ยนตามรอบเพื่อสร้างบรรยากาศ ส่วนปริศนาหลายขั้นให้แยกเป็นพื้นที่ของคนเดียวหรือปาร์ตี้ เพื่อไม่ให้ผู้เล่นอื่นกดเปลี่ยนสถานะขัดจังหวะ

**5. เกาะลับ: การค้นพบที่ต่อยอดจากชีวิตในโรงเรียน**

เกาะลับควรเป็นบทสรุปของเบาะแสที่พบกระจัดกระจาย และแต่ละเกาะควรมีกฎเฉพาะที่จำได้ทันที

**เกาะที่หนึ่ง — เกาะน้ำขึ้นฟ้า**

น้ำบนเกาะไหลขึ้นสู่ท้องฟ้าแล้วกลั่นตัวเป็นทะเลสาบลอยอยู่เหนือพื้นดิน

**การค้นพบ**

- เรียนเรื่องกระแสเวทมนตร์เพื่อรู้จักสัญลักษณ์ทิศทาง
- พบภาพทะเลกลับด้านในห้องลับ
- ซ่อมเครื่องวัดกระแสบนหอดูดาว
- ใช้ข้อมูลทั้งสามส่วนสร้างเส้นทางเดินทาง

**กิจกรรมบนเกาะ**

- สลับทิศการไหลเพื่อหมุนกังหันและเปิดทาง
- ใช้ฟองน้ำขนาดใหญ่เป็นลิฟต์
- อ่านข้อความที่ปรากฏเฉพาะในเงาสะท้อน
- ฟื้นฟูต้นกำเนิดกระแสน้ำเป็นปริศนาสุดท้าย

**รางวัล**

เครื่องประดับหยดน้ำ เอฟเฟกต์รอยเท้า ของตกแต่งหอพัก และบันทึกสิ่งมีชีวิตของเกาะ

**เกาะที่สอง — สวนแห่งเสียงสะท้อน**

ภูมิประเทศตอบสนองต่อเสียง บางสะพานปรากฏเมื่อเสียงจากหอระฆังสองแห่งตรงกัน

- คนเดียวใช้เครื่องบันทึกเสียงเวทมนตร์เก็บเสียงแล้วนำไปเล่น
- เล่นกลุ่มสามารถแยกกันเปิดหอระฆัง
- เสียงทั้งหมดมีสัญลักษณ์และแถบจังหวะประกอบ
- ปริศนาหลักคือคืนเสียงประจำถิ่นให้สิ่งมีชีวิตบนเกาะ

การเล่นหลายคนสะดวกและสนุกขึ้น แต่คนเดียวจบเนื้อหาหลักได้ครบ

**เกาะที่สาม — เกาะที่ถูกลบจากแผนที่**

เกาะไม่ได้ล่องหน แต่เครื่องมือแผนที่ของโรงเรียนไม่สามารถบันทึกมันได้

- ผู้เล่นพบคำบรรยายเส้นทางจากนักสำรวจหลายคน
- ต้องอ้างอิงจุดสังเกต เช่น ดาว ภูเขา และซากสะพาน
- เมื่อไปถึง สมุดยังว่างจนกว่าจะสำรวจจุดหลักครบ
- ผู้เล่นค่อย ๆ ประกอบแผนที่ด้วยภาพที่ค้นพบ

ปริศนาท้ายเกาะเปิดเผยว่าเหตุใดสถานที่นี้จึงถูกซ่อน และให้ผู้เล่นเลือกวิธีนำเสนอเรื่องราวในนิทรรศการของตนเอง โดยไม่เปลี่ยนสภาพโลกส่วนกลางให้ขัดกับผู้เล่นอื่น

**เมื่อค้นพบเกาะแล้วควรกลับไปได้ง่าย** เปิดเส้นทางถาวรจากท่าเรือหรือแผนที่ ไม่ต้องรอช่วงเวลาหายากซ้ำทุกครั้ง

**6. ทำให้ปริศนาสนุกทั้งคนเดียวและกับเพื่อน**

แบ่งบทบาทตามสิ่งที่กำลังทำ ไม่ล็อกตามอาชีพ:

| บทบาทชั่วคราว | หน้าที่ |
|---|---|
| ผู้สังเกต | อ่านร่องรอยและหาข้อมูล |
| ผู้ควบคุม | หมุนกลไก เปลี่ยนสถานะ |
| ผู้เดินทาง | ข้ามเส้นทางหรือนำวัตถุไปยังเป้าหมาย |

ผู้เล่นเปลี่ยนหน้าที่กันได้ตลอด

ตัวอย่างปริศนาเพื่อนช่วยเพื่อน: คนหนึ่งอยู่ห้องแผนที่ เห็นตำแหน่งดาว อีกคนอยู่ห้องกลไก ต้องจัดดาวให้ตรงกัน มีปุ่มส่งสัญลักษณ์สำเร็จรูปเพื่อสื่อสารได้โดยไม่ต้องใช้แชตเสียง

โหมดคนเดียวเปิดหน้าต่างดูข้อมูลหรือใช้เครื่องบันทึกภาพแทน ไม่เพิ่มขั้นตอนเดินกลับไปกลับมาจนเหนื่อย

**สัตว์เลี้ยงช่วยสร้างบุคลิกในการสำรวจ**

- มองตามเสียงหรือร่องรอยที่ผู้เล่นผ่านใกล้ ๆ
- มีท่าทางตอบสนองต่อวัตถุประหลาด
- ช่วยแสดงเบาะแสที่ผู้เล่นตรวจพบแล้ว

ความสามารถพื้นฐานนี้ควรเข้าถึงได้ฟรี และไม่มีปริศนาเนื้อหาหลักที่ต้องซื้อสัตว์เลี้ยงเฉพาะตัวเพื่อผ่าน

**7. รางวัลที่ทำให้ผู้เล่นอยากเล่าเรื่องการค้นพบ**

| สิ่งที่ทำสำเร็จ | รางวัลที่เหมาะสม |
|---|---|
| พบห้องลับครั้งแรก | หน้าบันทึกโลกและของตกแต่งชิ้นเล็ก |
| เข้าใจกฎของโถงวงโคจร | ทางลัดและตรานักสำรวจ |
| สำรวจเกาะครบ | ชุดแต่งตัวหรือเครื่องประดับประจำเกาะ |
| พบเรื่องราวเสริม | ภาพสะสมและบทสนทนาเพิ่มเติม |
| ช่วยเพื่อนสำรวจ | ความคืบหน้ากิจกรรมร่วมกันและของที่ระลึกตามเกณฑ์ที่ชัดเจน |

**ของสำคัญได้แน่นอนเมื่อทำสำเร็จครั้งแรก** ส่วนการเล่นซ้ำอาจให้วัสดุตกแต่งหรือชิ้นส่วนแลกของ เพื่อไม่ต้องแก้ปริศนาเดิมหลายสิบรอบเพราะสุ่มไม่ออก

เชื่อมกับระบบเข้าสังคมโดยให้ผู้เล่นจัด **มุมบันทึกการเดินทางในหอพัก** แสดงภาพเกาะ ของที่ค้นพบ และตราสำรวจ เพื่อนกดดูได้ว่าของนั้นมาจากการผจญภัยแบบไหน โดยไม่เปิดเผยคำตอบปริศนา

ของขายเหมาะกับกรอบสมุด รูปแบบโต๊ะจัดแสดง ชุดนักสำรวจ และท่าถ่ายภาพ ส่วนทางเข้าเกาะ คำใบ้จำเป็น และพลังแก้ปริศนาไม่ควรขาย

**8. ระบบช่วยเมื่อคิดไม่ออก**

ให้ผู้เล่นขอคำใบ้ฟรีเป็นขั้น ๆ:

| ระดับ | ตัวอย่าง |
|---|---|
| ชวนสังเกต | “เงาของโคมหนึ่งดวงดูต่างจากดวงอื่น” |
| ชี้ความสัมพันธ์ | “ทิศของเงาเปลี่ยนตามตำแหน่งกระจก” |
| แนะนำขั้นตอน | “ลองหันกระจกบานซ้ายให้แสงผ่านสัญลักษณ์ใบไม้” |

ไม่แสดงคำใบ้อัตโนมัติถี่จนเสียความรู้สึกค้นพบ และไม่ลดรางวัลเพราะขอความช่วยเหลือ

เมื่อออกเกม ให้บันทึกเบาะแสและขั้นที่ทำสำเร็จ ส่วนวัตถุที่กำลังถือสามารถกลับไปวางที่แท่นปลอดภัยเมื่อกลับเข้าเล่น พร้อมข้อความบอกตำแหน่ง

**9. ขอบเขตที่ควรสร้างก่อนใน Roblox**

ผมแนะนำให้เริ่มด้วย **เส้นทางสำรวจหนึ่งชุดที่จบได้จริง**:

> พบหน้าต่างที่หายไป → เปิดหอจดหมายเหตุเงา → ได้ข้อมูลโถงวงโคจร → ปลุกแผนที่ดาว → เดินทางไปเกาะน้ำขึ้นฟ้า

ขอบเขตเริ่มต้น:

| ส่วน | จำนวน |
|---|---:|
| พื้นที่โรงเรียนสำหรับสำรวจ | 1 ปีกอาคาร |
| ห้องลับ | 3 ห้อง |
| สถานะโถงวงโคจร | 3 สถานะ |
| เกาะลับ | 1 เกาะขนาดเล็ก |
| วิชาที่ใช้แก้ปริศนา | 3 วิชา |
| ปริศนาหลัก | 5–6 ชุด |
| เรื่องราวการค้นพบ | 1 เรื่องที่มีบทสรุป |

ด้านการทำงานของเกม ให้เซิร์ฟเวอร์ตรวจขั้นปริศนา การเปิดพื้นที่ และการรับรางวัล ส่วนภาพเคลื่อนไหว แสง และเสียงแสดงบนเครื่องผู้เล่น การเปลี่ยนทางเดินควรใช้ห้องที่เตรียมไว้และสลับการเชื่อมต่อ พร้อมแอนิเมชันบังช่วงเปลี่ยน เพื่อควบคุมเส้นทางและป้องกันการติดฉากได้ง่าย

ก่อนขยาย ต้องทดสอบให้ตอบได้ว่า:

- ผู้เล่นสังเกตเบาะแสแรกได้เองหรือไม่
- เมื่อทดลองผิด เข้าใจหรือไม่ว่าควรลองอะไรต่อ
- คนเดียวและกลุ่มเล่นจบได้โดยไม่ค้าง
- ออกจากเกมแล้วกลับมาทำต่อได้
- มือถือควบคุมกลไกและอ่านข้อความได้สะดวก
- หลังจบ ผู้เล่นเล่าได้หรือไม่ว่าค้นพบอะไรเกี่ยวกับโรงเรียน

**จุดขายที่ควรได้จากชุดแรกคือ: “ฉันเห็นสิ่งผิดปกติ ใช้สิ่งที่เรียนมาแก้มัน แล้วพบสถานที่ที่ไม่เคยรู้ว่ามีอยู่”** ถ้าความรู้สึกนี้เกิดขึ้นจริง ระบบสำรวจจะช่วยให้ทั้งการเรียน การสะสม และการเล่นกับเพื่อนมีความหมายขึ้นพร้อมกันครับ
