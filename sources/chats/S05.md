### ผู้ใช้

### ผู้ช่วย — ข้อเสนอ/รายงานในเวลานั้น

สำหรับ **Mythic Academy** ผมเสนอให้ Dungeon Place เป็น **“พื้นที่สำรวจรอยแยกเวทมนตร์”** ที่นักเรียนออกภาคสนามเพื่อแก้ความผิดปกติของโลก ใช้สิ่งที่เรียนมาแก้ปริศนา ช่วยเหลือสิ่งมีชีวิต และต่อสู้กับผู้พิทักษ์

จุดเด่นคือ **วิชาที่เรียนต้องเปลี่ยนวิธีผ่านดันเจียนได้จริง** เช่น คนเรียนพฤกษาเปิดทางด้วยรากไม้ คนเรียนอักขระอ่านกลไกโบราณ คนเรียนดวงดาวปรับเส้นทางแรงโน้มถ่วง แต่ทีมไม่ควรติดเพราะขาดวิชาใดวิชาหนึ่ง

รายละเอียดด้านล่างเป็นข้อเสนอการออกแบบ โดยชื่อและตัวเลขทั้งหมดเป็นค่าเริ่มต้นสำหรับทำต้นแบบและทดสอบ

**1. บทบาทของ Dungeon Place ในเกม**

พื้นที่นี้ควรตอบโจทย์ผู้เล่นหลายแบบพร้อมกัน

| ผู้เล่น | สิ่งที่ได้รับจากดันเจียน |
|---|---|
| ชอบต่อสู้ | บอสที่อ่านจังหวะได้ การหลบ การช่วยทีม |
| ชอบสำรวจ | ห้องลับ เส้นทางรอง เรื่องราวของโลก |
| ชอบเรียนวิชา | ได้ใช้เวทจากบทเรียนแก้สถานการณ์จริง |
| ชอบสะสม | คัมภีร์ การ์ดภาพ บันทึกโลก ของแต่งหอ |
| ชอบสัตว์เลี้ยง | พบสัตว์ใหม่ ช่วยเหลือสัตว์ และเก็บของตกแต่ง |
| ชอบเข้าสังคม | ภารกิจทีม ท่าแสดงร่วมกัน ภาพถ่ายหลังจบ |

**วงจรการเล่นหลัก**

เรียนวิชา → เตรียมชุดเวท → เลือกภารกิจ → สำรวจและแก้ปัญหา → พบผู้พิทักษ์ → รับรางวัล → นำสิ่งที่ค้นพบกลับไปใช้ในโรงเรียน

ดันเจียนควรทำให้ผู้เล่นรู้สึกว่า “วันนี้ได้ออกผจญภัยกับเพื่อน” มากกว่า “ต้องลงซ้ำเพื่อเพิ่มพลังให้ทันคนอื่น”

**2. โครงสร้างพื้นที่: ศูนย์ภาคสนาม + ดันเจียนเฉพาะทีม**

แยกประสบการณ์เป็นสองส่วน

| ส่วน | หน้าที่ | บรรยากาศ |
|---|---|---|
| Field Expedition Hub | รวมทีม เลือกภารกิจ ฝึกกลไก เตรียมตัว | ปลอดภัย คึกคัก เป็นพื้นที่สังคม |
| Dungeon Instance | การผจญภัยของผู้เล่น 1–4 คน | มีความเสี่ยง มีเรื่องราวและเป้าหมายชัดเจน |

ในมุมระบบเกม **Hub และดันเจียนเป็นพื้นที่เชิงออกแบบ** ส่วนจะใช้ Roblox Place แยกกี่แห่งค่อยตัดสินตามการทดสอบโหลดและการดูแลคอนเทนต์ ไม่จำเป็นต้องทำหนึ่ง Place ต่อหนึ่งดันเจียนตั้งแต่แรก

**ภาพรวม Hub**

ตั้งอยู่ใต้โรงเรียนในโถงสถานีสำรวจขนาดใหญ่ กลางโถงมีเครื่องฉายแผนที่รอยแยก รอบด้านเป็นระเบียง ห้องวิจัย และประตูเดินทาง

องค์ประกอบสำคัญ:

- วงแหวนแผนที่ลอยอยู่เหนือพื้น แสดงตำแหน่งความผิดปกติ
- ลิฟต์ขนส่งอุปกรณ์ที่เคลื่อนผ่านโถงเป็นระยะ
- หน้าต่างเห็นชั้นหินและกระแสเวทใต้โรงเรียน
- นักวิจัย NPC ตรวจตัวอย่างที่ทีมสำรวจนำกลับมา
- ชั้นจัดแสดงสิ่งของที่ผู้เล่นช่วยค้นพบในเนื้อเรื่อง

ใช้รูปทรง สัญลักษณ์ เครื่องแบบ และเรื่องราวที่ออกแบบเองให้เป็นเอกลักษณ์ของ Mythic Academy

จากจุดเกิดควรมองเห็นโต๊ะภารกิจ ประตูดันเจียน และจุดรวมทีมได้ในมุมเดียว ส่วนพื้นที่สวยงามสำหรับเดินเล่นอยู่ด้านข้าง เพื่อไม่ให้ความยิ่งใหญ่ทำให้การใช้งานยุ่งยาก

**4. รูปแบบการลงดันเจียน**

| รูปแบบ | จำนวนคน | เวลาเป้าหมาย | จุดประสงค์ |
|---|---:|---:|---|
| Field Introduction | 1–4 | 8–12 นาที | สอนการสำรวจและการช่วยทีม |
| Standard Expedition | 1–4 | 18–25 นาที | รูปแบบหลัก เล่นจบเป็นรอบ |
| Advanced Expedition | 1–4 | 25–35 นาที | เพิ่มกลไกและทางเลือก |
| Weekly Anomaly | 1–4 | 20–30 นาที | กติกาพิเศษหมุนเวียน |
| Story Expedition | 1–4 | ตามตอน | เหตุการณ์สำคัญของโลก |

เริ่มเปิดเกมด้วย **Field Introduction และ Standard Expedition** ก่อน รูปแบบอื่นเพิ่มเมื่อระบบหลักสนุกและเสถียรแล้ว

**การรองรับ Solo**

- กลไกที่ต้องยืนสองจุดให้ใช้แท่นบันทึกเวทช่วยทำซ้ำการกระทำ
- ลดจำนวนศัตรูพร้อมกันและความซับซ้อนของเป้าหมาย
- ผู้ช่วย NPC ทำหน้าที่ถือกลไกพื้นฐาน ไม่เล่นแทนผู้เล่น
- รางวัลแกนหลักไม่ควรถูกลดเพียงเพราะเล่นคนเดียว

จำนวนคนควรเปลี่ยนรูปแบบการประสานงาน มากกว่าทำให้ศัตรูมีเลือดเพิ่มอย่างเดียว

**5. โครงสร้างดันเจียนหนึ่งรอบ**

ใช้ **ห้องที่ออกแบบด้วยมือ แล้วสลับการเชื่อมต่อภายใต้กฎ** เพื่อรักษาคุณภาพฉากและควบคุมปริศนา

| ช่วง | เวลาโดยประมาณ | ประสบการณ์ |
|---|---:|---|
| ทางเข้าและเหตุการณ์เปิด | 2 นาที | เข้าใจปัญหาและเห็นเป้าหมาย |
| ห้องสอนกลไก | 3 นาที | ทดลองระบบหลักในพื้นที่ปลอดภัย |
| ทางแยกสำรวจ | 4 นาที | เลือกเส้นทางหรือหาห้องลับ |
| ห้องทดสอบร่วมมือ | 4 นาที | ผสมกลไกกับศัตรู |
| จุดพักและการตัดสินใจ | 2 นาที | เตรียมตัว เลือกความเสี่ยงเพิ่ม |
| ผู้พิทักษ์ | 5 นาที | ใช้สิ่งที่เรียนมาทั้งหมด |
| บทสรุปและกลับ | 2 นาที | เห็นผลของการกระทำและรับรางวัล |

จังหวะควรสลับ **ตื่นเต้น → สงบ → สงสัย → ร่วมมือ → ปลดปล่อย** ไม่ใช่ต่อสู้ทุกห้องติดต่อกัน

**กฎสำหรับเส้นทาง**

- มีเส้นทางหลักที่ผ่านได้เสมอ
- มีทางเลือกสำคัญอย่างน้อยหนึ่งครั้ง
- มีห้องเสริม 0–2 ห้องต่อรอบ
- สอนกลไกก่อนใช้ในสถานการณ์อันตราย
- ไม่วางปริศนาแบบเดิมซ้ำติดกัน
- ห้องเสริมต้องมีทางกลับและไม่ขังผู้เล่น
- จุดจบไม่ควรบังคับเดินย้อนผ่านฉากว่างทั้งหมด

**6. ดันเจียนแรก: “เรือนกระจกแห่งเสียงสะท้อน”**

ผมแนะนำให้เริ่มด้วยดันเจียนนี้ เพราะเชื่อม **วิชาเรียน สัตว์เลี้ยง ปริศนา และของแต่ง Dorm** ได้ในพื้นที่เดียว

**เรื่องราว**

เรือนกระจกวิจัยเก่าเคยเพาะต้นไม้ที่เก็บเสียงและความทรงจำ แต่ระบบควบคุมเสียหาย ทำให้รากไม้ดูดซับพลังเวทและเลียนแบบคำสั่งของนักวิจัย

ผู้เล่นได้รับภารกิจเข้าไป:

1. ตามหาทีมสำรวจที่ขาดการติดต่อ
2. ฟื้นระบบน้ำและแสง
3. ตรวจว่าผู้พิทักษ์กำลังปกป้องอะไร
4. คืนสมดุลให้เรือนกระจก

**ภาพจำ**

โดมกระจกแตกร้าวอยู่ใต้ดิน รากไม้ยักษ์โอบโครงโลหะ ละอองเกสรเรืองแสงลอยกลางอากาศ และมีต้นไม้กลางพื้นที่ที่เต้นเป็นจังหวะคล้ายการหายใจ

ใช้สีเขียวอมฟ้าและทองอุ่นเป็นหลัก สีม่วงเข้มบอกบริเวณผิดปกติ พร้อมรูปทรงและเสียงประกอบเพื่อไม่ให้ผู้เล่นต้องพึ่งสีเพียงอย่างเดียว

**ลำดับห้อง**

| ห้อง | การเล่น | สิ่งที่สอน |
|---|---|---|
| 1. ประตูรากไม้ | ส่งพลังให้เมล็ดแสงเปิดทาง | การโต้ตอบและการอ่านสถานะ |
| 2. ห้องเพาะเสียง | ฟังและทำซ้ำลำดับสัญญาณ | ปริศนาเสียงที่มีสัญลักษณ์ภาพคู่กัน |
| 3. ทางน้ำแตกแขนง | เลือกซ่อมทางน้ำหรือเปิดทางบนเรือนยอด | ทางเลือกในการสำรวจ |
| 4. สวนสะท้อน | เปลี่ยนทิศแสงพร้อมรับมือศัตรู | ใช้ฉากช่วยต่อสู้ |
| 5. รังสัตว์หลงทาง | ภารกิจเสริมช่วยสัตว์ | สังเกตและแก้ปัญหาโดยไม่โจมตี |
| 6. จุดพักนักวิจัย | อ่านบันทึกและเตรียมตัว | เข้าใจเหตุผลของผู้พิทักษ์ |
| 7. หัวใจเรือนกระจก | เผชิญหน้าบอส | รวมกลไกแสง น้ำ และรากไม้ |
| 8. สวนฟื้นคืน | รับรางวัลและถ่ายรูป | แสดงผลสำเร็จผ่านฉาก |

**ทางเลือกห้องที่ 3**

- **เส้นทางทางน้ำ:** เน้นซ่อมกลไกและปริศนา เมื่อจบจะเปิดระบบน้ำช่วยลดพื้นที่อันตรายในห้องบอส
- **เส้นทางเรือนยอด:** เน้นการเดินทางและต่อสู้ เมื่อจบจะเปิดแท่นสะท้อนแสงเสริมในห้องบอส

ทั้งสองทางให้รางวัลหลักเท่ากัน และมีระดับประโยชน์ใกล้กัน แต่เปลี่ยนวิธีเล่นช่วงท้าย

**7. บอสแรก: “ผู้พิทักษ์แก่นสะท้อน”**

รูปร่างเป็นสิ่งมีชีวิตจากลำต้นโปร่ง โครงกิ่งไม้ไม่สมมาตร และวงแหวนเมล็ดแสงที่หมุนรอบแกนกลาง การเคลื่อนไหวควรรู้สึกเป็นต้นไม้ที่มีชีวิต มีการบิด ยืด และถ่ายน้ำหนัก

**เป้าหมายการต่อสู้:** คลายพลังงานที่พันแกนกลางและทำให้ผู้พิทักษ์สงบลง

| ช่วง | พฤติกรรม | สิ่งที่ทีมต้องทำ |
|---|---|---|
| ช่วง 1: ป้องกันตัว | รากไม้กวาดพื้นและยิงเมล็ดพลังงาน | อ่านสัญญาณ หลบ และปรับแท่นแสง |
| ช่วง 2: ความทรงจำแตก | สร้างร่างสะท้อนและปิดทางบางส่วน | แยกร่างจริงจากจังหวะเสียงและสัญลักษณ์ |
| ช่วง 3: คืนสมดุล | พลังงานรั่วไหลและพื้นบางส่วนไม่ปลอดภัย | เปิดระบบน้ำ นำพลังกลับสู่แกน และปกป้องกัน |

**ท่าหลัก**

- **Root Sweep:** รากยกตัวก่อนกวาด มีทั้งภาพและเสียงเตือน
- **Echo Seed:** เมล็ดพลังงานเคลื่อนเข้าหาแท่น ผู้เล่นช่วยเปลี่ยนทิศได้
- **Memory Bloom:** ดอกไม้ฉายลำดับสัญลักษณ์ให้ทำซ้ำ
- **Overgrowth:** รากปิดพื้นที่ชั่วคราว ทำให้ทีมต้องเปลี่ยนตำแหน่ง

เมื่อทำกลไกสำเร็จ บอสเปิดช่วงให้ปลดพลังงานด้วยเวทโจมตี ส่วนการโจมตีตามปกติยังช่วยให้คืบหน้าได้ แต่กลไกควรเป็นวิธีที่มีประสิทธิภาพชัดเจน

**สิ่งที่ต้องหลีกเลี่ยง**

- เพิ่มความยากด้วยเลือดจำนวนมากอย่างเดียว
- การโจมตีที่ไม่มีสัญญาณอ่านได้
- ให้คนหนึ่งพลาดแล้วทีมแพ้ทันที
- บังคับยืนรอโดยไม่มีอะไรทำ
- เอฟเฟกต์เวทบดบังพื้นที่อันตราย

เมื่อชนะ ฉากค่อย ๆ เปลี่ยนจากสีผิดปกติเป็นแสงอุ่น รากคลายตัว และสัตว์ในเรือนกระจกกลับออกมา เป็นรางวัลทางภาพที่รู้สึกได้ทันที

**8. ระบบวิชาเรียนที่ใช้ได้จริง**

วิชาให้ **วิธีแก้ปัญหาเพิ่มเติม** โดยทุกเส้นทางหลักมีเครื่องมือพื้นฐานรองรับ

| วิชา | การใช้งาน | วิธีพื้นฐานเมื่อไม่มีวิชา |
|---|---|---|
| พฤกษาเวท | สั่งรากไม้สร้างสะพาน | ฟื้นเครื่องยกสะพาน |
| อักขระ | อ่านคำใบ้และปรับวงจร | เทียบสัญลักษณ์จากบันทึกในห้อง |
| แสงและภาพลวง | เผยวัตถุซ่อนและเปลี่ยนทิศแสง | เคลื่อนกระจกหรือใช้โคมสำรวจ |
| ดวงดาว | ปรับแรงโน้มถ่วงของแท่น | เดินเส้นทางกลไกข้างห้อง |
| ปรุงยา | สร้างสารช่วยควบคุมพื้นที่ | ใช้พืชและอุปกรณ์ที่มีในฉาก |
| ดูแลสัตว์เวท | ทำให้สัตว์สงบและเข้าใจพฤติกรรม | สังเกตร่องรอยและจัดสิ่งแวดล้อมให้เหมาะสม |

ตัวอย่าง: ผู้เรียนพฤกษาอาจเปิดสะพานได้เร็ว แต่ผู้เล่นทั่วไปยังผ่านได้ด้วยการซ่อมกลไกสั้น ๆ จึงรู้สึกว่าการเรียนมีคุณค่าโดยไม่ถูกกีดกัน

**ชุดเวทก่อนลง**

ค่าเริ่มต้นสำหรับทดสอบ:

- เวทใช้งาน 3 ช่อง
- เครื่องมือสำรวจ 1 ช่อง
- สัตว์เลี้ยง 1 ตัว
- ท่าหลบและปฏิสัมพันธ์เป็นคำสั่งพื้นฐาน

การโจมตีพื้นฐานควรใช้ได้เสมอ แม้เลือกเวทสนับสนุนมาทั้งชุด และเปลี่ยนชุดเวทได้ที่จุดพัก

**9. การต่อสู้และบทบาทในทีม**

ใช้บทบาทแบบยืดหยุ่น ไม่บังคับให้ต้องมี Tank / Healer / DPS ครบ

| แนวการเล่น | ตัวอย่างหน้าที่ |
|---|---|
| ผู้ปกป้อง | สร้างที่กำบัง ช่วยเปิดพื้นที่ชุบเพื่อน |
| ผู้ควบคุม | หยุดศัตรู เปลี่ยนทิศพลังงาน |
| ผู้ฟื้นฟู | ฟื้นเกราะเวท ลดผลสถานะ |
| ผู้โจมตี | จัดการเป้าหมายและทำลายจุดอ่อน |
| ผู้สำรวจ | เปิดทาง หาเบาะแส และอ่านกลไก |

ผู้เล่นคนเดียวทำได้หลายหน้าที่ผ่านชุดเวท

**คอมโบที่ควรมี**

- เวทน้ำทำให้เถาวัลย์เติบโต → เวทพฤกษาจัดเป็นที่กำบัง
- เวทแสงเผยจุดอ่อน → เพื่อนใช้เวทโจมตีปลดพลังงาน
- เวทแรงลมเคลื่อนละอองเกสร → เปิดพื้นที่ปลอดภัย

คอมโบต้องสื่อสารผ่านภาพและผลลัพธ์ชัดเจน และไม่อนุญาตให้ผู้เล่นใช้เวทผลักเพื่อนตกฉาก

**เมื่อผู้เล่นล้ม**

- เข้าสถานะรอช่วยชั่วคราว
- ยังส่ง Ping ขอความช่วยเหลือได้
- หากช่วยไม่ทัน กลับมาที่จุดพักเมื่อทีมผ่านห้องหรือเริ่มการเผชิญหน้าใหม่
- ถ้าล้มทั้งทีม เริ่มใหม่จากจุดตรวจล่าสุด
- ไม่ขายการคืนชีพด้วย Robux ระหว่างการต่อสู้

**10. ปริศนาและห้องลับ**

ปริศนาควรมีคำตอบที่อนุมานได้จากสิ่งรอบตัว และมีคำใบ้เป็นขั้นเมื่อทีมติดนาน

| ประเภท | ตัวอย่าง | สิ่งที่ต้องระวัง |
|---|---|---|
| สังเกต | ดูต้นไม้ที่สะท้อนต่างจากต้นอื่น | อย่าซ่อนละเอียดจนมองไม่เห็นบนมือถือ |
| ลำดับ | ทำซ้ำจังหวะแสงและเสียง | ต้องมีทางอ่านได้โดยไม่เปิดเสียง |
| จัดตำแหน่ง | หมุนกระจกและแท่นพลังงาน | แสดงทิศทางผลลัพธ์ชัดเจน |
| ร่วมมือ | คนหนึ่งเปิดทาง อีกคนขนแกน | มีรูปแบบ Solo ที่ครบถ้วน |
| ความรู้โลก | เชื่อมสัญลักษณ์กับบันทึก | ข้อมูลที่จำเป็นอยู่ภายในรอบ |
| ทดลอง | เปลี่ยนสภาพพืชด้วยเวท | ทดลองผิดได้โดยไม่เสียทรัพยากรถาวร |

**ห้องลับสามระดับ**

1. **พบง่าย:** มีร่องรอยชัด ให้รางวัลการสังเกต
2. **ต้องเชื่อมเบาะแส:** ใช้ข้อมูลจากสองห้อง
3. **ปริศนาระยะยาว:** เชื่อมบันทึกหลายรอบ ปลดเรื่องราวและของสะสมพิเศษ

ห้องลับไม่ควรเป็นข้อบังคับสำหรับความก้าวหน้าหลัก และการค้นพบต้องแชร์ให้สมาชิกทีมที่เข้าร่วมรอบนั้น ไม่ใช่ให้เฉพาะคนกดก่อน

**11. สัตว์เลี้ยงในดันเจียน**

สัตว์เลี้ยงช่วยสร้างบุคลิกและความผูกพัน โดยไม่เป็นตัวคูณความเก่งจากการจ่ายเงิน

**พฤติกรรมที่เหมาะสม**

- แสดงท่าทีเมื่ออยู่ใกล้จุดน่าสนใจที่ผู้เล่นสังเกตเองได้
- ตอบสนองต่อบรรยากาศ เช่น กลัวเสียงก้องหรือชอบดอกไม้
- รออย่างปลอดภัยระหว่างกลไกที่มีพื้นที่แคบ
- มีท่าฉลองและภาพถ่ายหลังจบ
- เปิดบทสนทนาหรือเรื่องราวเสริมที่ไม่กีดกันรางวัลหลัก

หากมีความสามารถช่วยเล่น ให้ใช้ชุดความสามารถพื้นฐานที่ทุกคนเข้าถึงได้ และเลือกติดตั้งแยกจากรูปลักษณ์สัตว์

**ภารกิจช่วยสัตว์**

ตัวอย่าง “ตัวอ่อนโคมใบไม้” ติดอยู่ในรังที่รับแสงมากเกินไป ผู้เล่นต้องลดแสงและย้ายน้ำ ไม่ใช่โจมตีรัง เมื่อช่วยสำเร็จจะได้รับความคืบหน้าการศึกษาสัตว์ ซึ่งสะสมเพื่อปลดสัตว์หรือของแต่งที่เกี่ยวข้องได้แน่นอน

**12. รางวัลและความก้าวหน้า**

แบ่งรางวัลเป็นสามชั้นเพื่อให้ทุกรอบมีคุณค่า

| ชั้น | ตัวอย่าง | วิธีได้รับ |
|---|---|---|
| ได้แน่นอน | เหรียญวิจัย วัสดุพื้นฐาน ความคืบหน้าบันทึก | ผ่านเป้าหมายที่ระบุ |
| เลือกได้ | ชิ้นส่วนของแต่งหรือหัวข้อวิจัย | เลือกหลังจบรอบ |
| โอกาสพิเศษ | การ์ดภาพ รูปลักษณ์หายาก แบบตกแต่ง | สุ่มจากการเล่น พร้อมทางสะสมแลก |

**ตัวอย่างรางวัลเรือนกระจก**

- โคมเมล็ดแสงสำหรับ Dorm
- เสื้อคลุมลายเส้นใบไม้
- การ์ดภาพสวนก่อนเกิดเหตุ
- บันทึกนักพฤกษาเวท
- ท่ายืนอ่านตัวอย่างพืช
- รูปลักษณ์เครื่องรางเถาวัลย์
- ของแต่งสัตว์เลี้ยงรูปดอกไม้

**ป้องกันความรู้สึกเสียเวลา**

- ของซ้ำเปลี่ยนเป็นวัสดุแลกของในชุดเดียวกัน
- ของเด่นมีเงื่อนไขปลดแบบแน่นอนควบคู่กับโอกาสดรอป
- ออกจากรอบหลังผ่านจุดตรวจยังเก็บรางวัลส่วนที่ยืนยันแล้ว
- รางวัลบอสให้เมื่อจบการเผชิญหน้าเท่านั้น
- ไม่แย่งของกัน สมาชิกแต่ละคนมีรางวัลของตัวเอง

**ความก้าวหน้าระยะยาว**

ให้ “ระดับใบอนุญาตภาคสนาม” ปลดเนื้อหาและความซับซ้อนใหม่ ส่วนอุปกรณ์เน้นตัวเลือกการเล่น เช่น เปลี่ยนพื้นที่เวท ระยะเวลา หรือจังหวะใช้งาน โดยมีข้อแลกเปลี่ยน แทนการเพิ่มพลังแบบไม่สิ้นสุด

**13. ความยากและการกลับมาเล่นซ้ำ**

ความยากสูงขึ้นควรเพิ่ม **การตัดสินใจ** มากกว่าลดเวลาตอบสนองจนเล่นบนมือถือไม่ได้

| ระดับ | การเปลี่ยนแปลง |
|---|---|
| Introduction | สัญญาณเตือนชัด คำใบ้อัตโนมัติ กลไกแยกทีละอย่าง |
| Standard | ผสมกลไก มีทางแยกและศัตรูหลายหน้าที่ |
| Advanced | มีลำดับกลไกใหม่ ต้องเลือกจัดการภัยก่อนหลัง |
| Weekly Anomaly | เพิ่มกติกาพิเศษที่เปลี่ยนวิธีเล่น |

ตัวอย่างกติกาหมุนเวียน:

- **แสงเคลื่อน:** ตำแหน่งลำแสงเปลี่ยนระหว่างการต่อสู้
- **ความทรงจำย้อน:** กลไกบางชนิดทำงานย้อนลำดับ
- **แขกหลงทาง:** มีสัตว์ให้ช่วยระหว่างเส้นทาง
- **รากตอบสนอง:** การใช้เวทบางชนิดเปลี่ยนเส้นทางเสริม

ไม่ควรรวมตัวแปรทุกชนิดพร้อมกัน เริ่มจากรูปแบบที่ออกแบบและตรวจสอบไว้ก่อน เพื่อไม่สร้างรอบที่แก้ไม่ได้

กิจกรรมหมุนเวียนควรกลับมาอีก และไม่ผูกพลังจำเป็นกับการเข้าเล่นทุกวัน

**14. ระบบทีมและการลดปัญหาผู้เล่นก่อกวน**

ก่อนจับทีม ผู้เล่นเลือกความตั้งใจได้:

- **ครั้งแรก:** ยินดีดูเนื้อเรื่องและรับคำแนะนำ
- **สำรวจ:** เน้นห้องลับและเก็บบันทึก
- **เล่นเร็ว:** เน้นผ่านเส้นทางหลัก

ใช้เป็นความต้องการในการจับคู่ โดยไม่แยกคิวจนหาทีมยากในช่วงผู้เล่นน้อย

**กติกาภายในรอบ**

- กลไกสำคัญไม่มีผู้เล่นคนเดียวถือกุญแจแล้วขังทีมได้
- ของภารกิจที่หล่นหรือผู้ถือออกจากเกมจะกลับจุดที่เข้าถึงได้
- เมื่อผู้เล่นออก ปรับกลไกตามจำนวนคนที่จุดปลอดภัย
- ผู้เล่นใหม่เข้ารอบกลางทางได้เฉพาะก่อนจุดที่กำหนด
- เริ่มบอสด้วยการพร้อมของทีม พร้อมกระบวนการรองรับคน AFK
- ไม่เปิด PvP หรือเวทผลักเพื่อนในดันเจียนทั่วไป

**หน้าสรุปผล**

แสดงผลงานหลายด้าน เช่น ช่วยเพื่อน สำรวจ ซ่อมกลไก และผ่านเป้าหมาย พร้อมไฮไลต์ร่วมของทีม แทนการจัดอันดับด้วยดาเมจเพียงค่าเดียว

**15. UI และการเล่นบนมือถือ**

ระหว่างเล่นควรเห็นข้อมูลสำคัญเพียงพอโดยไม่บังฉาก

**16. การสร้างรายได้ที่เข้ากับดันเจียน**

- ไม่ขายความได้เปรียบในการมองเบาะแส
- เอฟเฟกต์ที่ซื้อไม่ลดความชัดเจนของสนามต่อสู้

สำหรับเวอร์ชันแรก ใช้ร้านขายตรงที่เห็นสินค้าชัดเจน จะวางระบบและสื่อสารคุณค่าได้ง่ายกว่าเพิ่มการสุ่มแบบเสียเงิน

---

**17. ขอบเขตระบบสำหรับทีมพัฒนา**

แยกความรับผิดชอบให้สามารถเพิ่มดันเจียนใหม่โดยใช้ระบบเดิม

| ระบบ | หน้าที่ |
|---|---|
| Expedition Session | สถานะรอบ สมาชิก จุดตรวจ และการจบภารกิจ |
| Dungeon Layout | เลือกห้องและตรวจความถูกต้องของเส้นทาง |
| Encounter | ศัตรู คลื่นการต่อสู้ และบอส |
| Puzzle | สถานะกลไก เงื่อนไขผ่าน และการรีเซ็ต |
| Objective | เป้าหมายหลัก ภารกิจเสริม และความคืบหน้า |
| Reward | คำนวณรางวัลและป้องกันการรับซ้ำ |
| Recovery | การหลุด การกลับเข้า และของภารกิจสูญหาย |
| Presentation | เสียง แสง กล้อง และเอฟเฟกต์ |
| Analytics | เวลาเล่น จุดที่ติด และสาเหตุออกจากรอบ |

**หลักสำคัญ**

ฝั่งเซิร์ฟเวอร์ต้องเป็นผู้ยืนยันความเสียหาย การผ่านกลไก และรางวัล ส่วนฝั่งผู้เล่นรับผิดชอบการแสดงผลและส่งคำขอการกระทำ

รางวัลแต่ละชุดต้องมีรหัสอ้างอิงรอบและเหตุการณ์ เพื่อให้การลองบันทึกซ้ำหลังเครือข่ายผิดพลาดไม่สร้างของเพิ่ม

**ข้อมูลที่ควรเก็บถาวร**

- การปลดล็อกดันเจียนและเนื้อเรื่อง
- บันทึกที่ค้นพบ
- ความคืบหน้าการสะสมและการแลกของ
- รางวัลที่รับแล้ว
- สถิติการผ่านที่จำเป็น
- ชุดเวทที่เลือกใช้

ตำแหน่งศัตรู กระสุน และสถานะกลไกทุกเฟรมเป็นข้อมูลชั่วคราวของรอบ ไม่ต้องบันทึกทั้งหมดลงโปรไฟล์ผู้เล่น

**18. ขอบเขตเวอร์ชันแรกที่ทำออกมาเล่นได้จริง**

เริ่มด้วย **ดันเจียนหนึ่งแห่งที่มีวงจรครบ** ตามขอบเขตนี้

| หมวด | ขอบเขตแรก |
|---|---|
| Hub | โต๊ะภารกิจ จุดรวมทีม จุดเตรียมตัว จุดกลับ |
| ดันเจียน | เรือนกระจกแห่งเสียงสะท้อน |
| ห้อง | ห้องหลัก 6 แบบ ห้องเสริม 2 แบบ ห้องบอส 1 แบบ |
| เส้นทาง | รูปแบบที่ตรวจแล้ว 2 แบบ |
| ศัตรู | 3 บทบาทที่ทำงานต่างกัน |
| บอส | 1 ตัว พร้อมกลไก 3 ช่วง |
| ปริศนา | แสง น้ำ และลำดับเสียง |
| ผู้เล่น | Solo และทีมสูงสุด 4 คน |
| รางวัล | ของสะสม ของแต่ง และการแลกของซ้ำ |
| ระบบพื้นฐาน | จุดตรวจ การล้ม การออกจากทีม และป้องกันรับรางวัลซ้ำ |

**ลำดับการทำงาน**

1. **ทำห้องทดสอบ:** เดิน หลบ ใช้เวท เปิดกลไก และช่วยเพื่อนให้รู้สึกดี
2. **ทำเส้นทางสั้นครบวงจร:** ห้องสอน → ห้องผสม → บอส → รางวัล
3. **ทดสอบ Solo และ 4 คน:** ตรวจว่ากลไกไม่ติดและทุกคนมีส่วนร่วม
4. **เพิ่มทางแยกและห้องเสริม:** สร้างเหตุผลให้กลับมาเล่น
5. **ทำฉาก แสง เสียง และแอนิเมชัน:** รักษาความชัดเจนระหว่างเล่น
6. **เพิ่มการบันทึกและการกู้คืน:** ทดสอบหลุด ออกกลางทาง และรับรางวัล
7. **ทดสอบกับผู้เล่นที่ไม่เคยเห็นเกม:** ปรับคำใบ้ เวลา และความยากก่อนขยาย

**เกณฑ์ก่อนเพิ่มดันเจียนแห่งที่สอง**

- ผู้เล่นใหม่เข้าใจเป้าหมายโดยไม่ต้องมีคนอธิบายตลอด
- เล่น Solo และทีมผ่านได้จริง
- ไม่มีเส้นทางหรือกลไกที่ทำให้ติดถาวร
- ลองซ้ำหลังแพ้ได้รวดเร็ว
- การหลุดและกลับเข้าไม่ทำให้รางวัลซ้ำ
- เล่นบนอุปกรณ์มือถือเป้าหมายได้ลื่นพอ
- ผู้เล่นอยากลงรอบสองเพราะประสบการณ์และสิ่งที่ยังไม่ค้นพบ

**19. ทิศทางดันเจียนแห่งต่อไป**

แต่ละแห่งควรมี “กริยาหลัก” และอารมณ์ของตัวเอง เพื่อไม่ให้เป็นแค่การเปลี่ยนฉาก

| ดันเจียน | กลไกหลัก | อารมณ์ | เชื่อมวิชา |
|---|---|---|---|
| เรือนกระจกแห่งเสียงสะท้อน | ฟื้นฟูและจัดทิศทางพลังงาน | มหัศจรรย์ อบอุ่นปนลึกลับ | พฤกษา แสง สัตว์ |
| หอจดหมายเหตุที่ลืมชื่อ | ประกอบความทรงจำและอ่านเบาะแส | สงสัย ค่อย ๆ เข้าใจ | อักขระ ภาพลวง |
| โรงหลอมกระแสดาว | ปรับแรงโน้มถ่วงและเคลื่อนแกนพลังงาน | ยิ่งใหญ่ เคลื่อนไหวสูง | ดวงดาว การแปรสภาพ |
| อ่างเก็บฝนกลับทิศ | เปลี่ยนระดับน้ำและเส้นทาง | เงียบงาม เหนือจริง | น้ำ ลม ปรุงยา |
| เกาะใต้เงาจันทร์ | สำรวจระบบนิเวศและตามร่องรอย | โดดเดี่ยวก่อนพบความมีชีวิต | สัตว์ พฤกษา การสำรวจ |

**สิ่งที่ควรพิสูจน์เป็นอย่างแรกคือห้องเล็กหนึ่งห้องที่ “ใช้เวทจากวิชาเรียน + แก้ปริศนากับเพื่อน + เห็นฉากเปลี่ยนตามการกระทำ” แล้วสนุกจริง** เมื่อจุดนี้ทำได้ เรือนกระจกทั้งแห่งจะมีแกนการเล่นที่ชัด และระบบเดิมจะต่อยอดไปยังดันเจียนอื่นได้อย่างมีเหตุผล
