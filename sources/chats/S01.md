### ผู้ใช้

การพัฒนา Roblox ผ่าน rojo ทำให้เห็น object ใน Roblox studio ไม่ได้หรอ

### ผู้ช่วย — ข้อเสนอ/รายงานในเวลานั้น

**เห็น Object ใน Roblox Studio ได้ครับ ไม่จำเป็นต้องกด Play** ขึ้นอยู่กับว่าเราสร้าง Object ด้วยวิธีไหน

| วิธีสร้าง | เห็นตอนแก้ไขใน Studio หรือไม่ |
|---|---|
| วาง Part / Model ลงใน Workspace ผ่าน Studio | ✅ เห็นทันที |
| ให้ Rojo ซิงก์ Part / Model จาก `.model.json`, `.rbxmx` หรือ project tree เข้า Workspace | ✅ เห็นหลังซิงก์ |
| เขียน Script ให้สร้างด้วย `Instance.new()` ตอนเกมทำงาน | ⏵ เห็นเมื่อกด Play / Run |
| เก็บ Model ไว้ใน `ServerStorage` / `ReplicatedStorage` | มีใน Explorer แต่ยังไม่ปรากฏในฉาก 3D |

Rojo รองรับการซิงก์ทั้ง Script และ Object ครับ แต่ข้อมูลบางประเภท เช่น Terrain, CSG และการแก้ `MeshPart.MeshId` มีข้อจำกัดในการซิงก์สด :chatgpt-content-reference{index="0"}

**ถ้าตอนนี้ฉากของคุณโผล่เฉพาะตอนกด Play** อาจเป็นเพราะโค้ดลักษณะนี้:

```lua
local part = Instance.new("Part")
part.Anchored = true
part.Parent = workspace
```

Rojo ส่ง **ตัว Script** เข้า Studio แต่ไม่ได้รันคำสั่งนั้นระหว่างแก้ไขฉาก เมื่อหยุดเกม Object ที่สร้างระหว่างรันก็จะหายไป

สำหรับเกมโรงเรียนเวทมนตร์ที่ต้องจัดอาคาร ห้อง ทางเดิน และตำแหน่งของตกแต่ง ผมแนะนำให้แบ่งดังนี้:

- **ฉากถาวร:** เป็น Part / Model จริงใน Workspace เพื่อเห็นและปรับตำแหน่งได้ก่อนกด Play
- **ระบบเกม:** ใช้ Rojo จัดการโค้ด เช่น เรียนวิชา ประตู เควสต์ และดันเจียน
- **สิ่งที่เกิดระหว่างเล่น:** ใช้ Script สร้าง เช่น มอนสเตอร์ เอฟเฟกต์ และของดรอป

**ใช้ Rojo แล้วต้องสร้างฉากทั้งหมดผ่าน Script ไม่ใช่ข้อบังคับครับ** เราสามารถออกแบบให้เห็นฉากและแต่งฉากใน Studio ได้ตามปกติ
