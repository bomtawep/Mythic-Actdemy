### ผู้ใช้

วางระบบแต่งตัวและเข้าสังคมแบบละเอียดให้หน่อย

### ผู้ช่วย — ข้อเสนอ/รายงานในเวลานั้น

สำหรับ **Mythic Academy** ผมเสนอให้ระบบแต่งตัวและเข้าสังคมเป็นอีกหนึ่งเส้นทางหลักของเกม ผู้เล่นควรรู้สึกว่า **“ฉันมีตัวตน มีพื้นที่ของตัวเอง และมีคนที่อยากกลับมาเจอ”** แม้วันนั้นจะไม่ได้ลงดันเจียนหรือเรียนวิชาเลยก็ตาม

ระบบนี้จะเชื่อมกับการเรียน สัตว์เลี้ยง การสะสม และการสำรวจ โดยใช้หลักว่า **ความสวยงาม ความคิดสร้างสรรค์ และความสัมพันธ์เป็นรางวัลที่มีคุณค่าได้ โดยไม่จำเป็นต้องเพิ่มพลังต่อสู้**

รายละเอียดด้านล่างเป็นข้อเสนอสำหรับออกแบบเกม ส่วนจำนวนช่อง ราคา และระยะเวลาต่าง ๆ เป็นค่าเริ่มต้นสำหรับทดลองกับผู้เล่นจริง

**1. ภาพรวม: ระบบ 5 ส่วนที่ทำงานร่วมกัน**

| ระบบ | ผู้เล่นทำอะไร | เหตุผลที่อยากกลับมาเล่น |
|---|---|---|
| ตัวละครและตู้เสื้อผ้า | แต่งตัว ย้อมสี บันทึกชุด | สร้างตัวตนและสะสมรูปลักษณ์ |
| พื้นที่สังคม | พบคน คุย เล่นกิจกรรม ถ่ายรูป | มีสถานที่ประจำและเจอเพื่อน |
| ชมรมและความสัมพันธ์ | ทำกิจกรรมร่วมกัน ตั้งกลุ่ม | รู้สึกเป็นส่วนหนึ่งของโรงเรียน |
| หอพักและห้องส่วนตัว | ตกแต่ง เชิญเพื่อน จัดงาน | มีพื้นที่แสดงความเป็นตัวเอง |
| กิจกรรมแฟชั่นและงานโรงเรียน | เดินแบบ นิทรรศการ เทศกาล | มีเหตุผลใช้ชุดและของสะสม |

ตัวอย่างวงจรการเล่น:

> เรียนวิชาพฤกษา → ได้สูตรย้อมสีใบไม้เรืองแสง → แต่งชุดนักสำรวจ → ชวนเพื่อนไปถ่ายรูปในเรือนกระจก → นำภาพกลับมาตกแต่งห้อง → เปิดห้องจัดงานเล็ก ๆ ให้ชมรม

จุดสำคัญคือทุกระบบส่งต่อเหตุผลให้ผู้เล่นไปทำกิจกรรมอื่น ไม่แยกเป็นเมนูสะสมที่เปิดดูแล้วจบ

**2. การสร้างตัวละคร: เริ่มง่าย แต่มีรายละเอียดให้พัฒนาต่อ**

ผู้เล่นใหม่ควรสร้างตัวละครเบื้องต้นได้ในประมาณ **2–3 นาที** แล้วกลับมาแก้ไขภายหลังได้

ขั้นตอนเริ่มเกม:

1. เลือกรูปลักษณ์พื้นฐาน เช่น สีผิว ใบหน้า ทรงผม และสีผม
2. เลือกชุดนักเรียนเริ่มต้นจาก 3–4 แบบที่มีคุณภาพใกล้เคียงกัน
3. เลือกสีหลักของชุดจากพาเลตเริ่มต้น
4. เลือกเครื่องประดับชิ้นเล็กหนึ่งชิ้น
5. ดูตัวอย่างขณะยืน เดิน และถือคัมภีร์
6. เข้าเกมทันที โดยมีปุ่ม “แต่งเพิ่มภายหลัง”

**ไม่ผูกเสื้อผ้ากับเพศ** ให้ผู้เล่นเลือกชิ้นส่วนที่ต้องการได้โดยตรง และอย่าทำให้ชุดฟรีเริ่มต้นดูด้อยจนรู้สึกว่าต้องจ่ายเงินจึงจะดูดี

สำหรับเวอร์ชันแรก ควรกำหนดสัดส่วนตัวละครที่เกมรองรับให้แคบพอที่จะตรวจเสื้อผ้าและแอนิเมชันได้ทั่วถึง ก่อนขยายตัวเลือกสัดส่วนเพิ่มเติม

**3. โครงสร้างช่องแต่งตัว**

แยกชิ้นส่วนเพื่อให้ผสมชุดได้จริง แต่ไม่เปิดช่องมากจนผลิตของและแก้การทะลุกันไม่ไหว

| กลุ่ม | ช่องแต่งตัว | ตัวอย่าง |
|---|---|---|
| รูปลักษณ์พื้นฐาน | ผม ใบหน้า สีผิว สีผม | ผมสั้นหยักศก ดวงตาสีอำพัน |
| เสื้อผ้าหลัก | เสื้อ กางเกง/กระโปรง รองเท้า | เสื้อเรียน เสื้อเดินทาง รองเท้าบูต |
| เสื้อคลุม | เสื้อคลุมหรือแจ็กเก็ต | ผ้าคลุมสั้น เสื้อคลุมพิธีการ |
| ศีรษะ | หมวกหรือเครื่องประดับผม | หมวกนักสำรวจ กิ๊บคริสตัล |
| ใบหน้า | แว่นหรือหน้ากาก | แว่นปรุงยา หน้ากากงานเทศกาล |
| เครื่องประดับ | เข็มกลัด ถุงมือ เข็มขัด | ตราวิชา ถุงมือทำสวน |
| ด้านหลัง | กระเป๋าหรือของประดับหลัง | กระเป๋าหนัง กล่องอุปกรณ์ |
| อุปกรณ์เวท | รูปลักษณ์คัมภีร์และอุปกรณ์ร่ายเวท | ปกคัมภีร์ไม้แกะสลัก |
| การแสดงออก | ท่ายืน ท่าเดิน อีโมต | ถือหนังสือ เดินอย่างมั่นใจ |
| เอฟเฟกต์ | ออร่าและรอยเท้า | ละอองหมึก ใบไม้จาง ๆ |

**กติกาการสวมใส่**

- ชุดเต็มตัวอาจใช้ช่องเสื้อและท่อนล่างพร้อมกัน โดย UI ต้องแจ้งก่อนสวม
- เสื้อคลุมบางทรงต้องซ่อนกระเป๋าหลังหรือเปลี่ยนเป็นรุ่นที่เข้ากันได้
- หมวกควรมีรูปแบบรองรับทรงผม ไม่ใช้วิธีซ่อนผมทั้งหมดทุกครั้ง
- ของที่มีขนาดใหญ่ต้องมีขอบเขต เพื่อไม่บดบังผู้เล่นอื่น
- เอฟเฟกต์ของชุดต้องไม่ทำให้ศัตรูอ่านท่าโจมตียากขึ้น

**แยกค่าพลังออกจากรูปลักษณ์อย่างชัดเจน** เปลี่ยนชุดได้โดยไม่เสียประสิทธิภาพในการเล่น ส่วนอุปกรณ์ที่มีค่าพลังให้เปลี่ยนหน้าตาผ่านระบบรูปลักษณ์แยกต่างหาก

**4. ตู้เสื้อผ้า: ต้องทำให้การแต่งตัวสนุกในตัวเอง**

หน้าตู้เสื้อผ้าควรประกอบด้วย:

- ตัวละครขนาดใหญ่ หมุนดูและซูมได้
- หมวดไอเทมที่กรองตามสี ธีม แหล่งที่มา และของที่เป็นเจ้าของได้
- รายการชิ้นส่วนที่กำลังใส่
- ปุ่มลองชุด บันทึก ย้อนกลับ และคืนค่าชุดก่อนแก้ไข
- ฉากทดลองแสง เช่น กลางวัน กลางคืน และแสงในอาคาร
- ท่าทดสอบ เช่น เดิน นั่ง ร่ายเวท และกอดสัตว์เลี้ยง

**ฟังก์ชันที่ควรมีตั้งแต่แรก**

| ฟังก์ชัน | รายละเอียด |
|---|---|
| ชุดที่บันทึกไว้ | เริ่มต้นฟรี 6 ชุด พร้อมตั้งชื่อ |
| รายการโปรด | ปักหมุดไอเทมที่ใช้บ่อย |
| ประวัติชุดล่าสุด | ย้อนกลับไปใช้ชุดก่อนหน้าได้ |
| ลองก่อนซื้อ | ทดลองหลายชิ้นพร้อมกันและแสดงยอดรวม |
| ดูแหล่งที่มา | บอกว่าได้จากวิชา เควสต์ ร้านค้า หรือกิจกรรมใด |
| ซ่อนเอฟเฟกต์ | ดูรูปลักษณ์พื้นฐานของชุดได้ |
| แชร์ชุด | สร้างรหัสชุดให้เพื่อนนำไปลองได้ |

เมื่อใช้รหัสชุดของเพื่อน หากไม่มีบางชิ้น ให้แสดงเป็น **โหมดทดลอง** พร้อมทางไปหาไอเทม ผู้เล่นต้องไม่ถูกซื้อของอัตโนมัติ

หากขายช่องบันทึกเพิ่ม ควรเป็นความสะดวกสำหรับคนสะสมจำนวนมาก โดยช่องฟรีต้องเพียงพอต่อการเล่นปกติ

**5. ระบบย้อมสีและปรับรายละเอียด**

แทนที่จะผลิตชุดใหม่ทุกสี ให้ไอเทมหนึ่งชิ้นมีพื้นที่ย้อมสีที่กำหนดไว้ เช่น:

| พื้นที่ | ตัวอย่างเสื้อคลุม |
|---|---|
| สีหลัก | ผ้าด้านนอก |
| สีรอง | ผ้าซับใน |
| สีขอบ | ลายปักและขอบแขน |
| สีตกแต่ง | อัญมณีหรือประกายเล็ก ๆ |

เริ่มต้นด้วยพาเลตสีที่ออกแบบไว้ประมาณ 12–16 สี เพื่อให้ชุดผสมกันแล้วดูดี จากนั้นปลดล็อกพาเลตพิเศษผ่านกิจกรรม

ตัวอย่าง:

- วิชาพฤกษา → สีเขียวมอสและลายใบไม้
- วิชาดาราศาสตร์ → สีน้ำเงินกลางคืนและลายกลุ่มดาวที่ออกแบบเอง
- วิชาปรุงยา → สีเหลือบและรอยเปื้อนตกแต่ง
- สำรวจซากโบราณ → สีดินเผาและลายสลัก
- เลี้ยงสัตว์ → ลายอุ้งเท้าหรือขนนุ่ม

**ข้อเสนอ:** เมื่อปลดล็อกสีพื้นฐานแล้ว ให้ใช้ซ้ำได้โดยไม่เสียของทุกครั้ง เพื่อสนับสนุนการทดลองแต่งตัว ส่วนวัสดุพิเศษใช้สำหรับปลดล็อกสูตรหรือลายใหม่ครั้งแรก

ความหายากควรสะท้อนความพิเศษของงานออกแบบและวิธีได้มา ไม่ใช่เพิ่มความสว่างหรือจำนวนเอฟเฟกต์ทุกระดับ

**6. วิธีได้ชุด: ให้กิจกรรมในโรงเรียนมีเอกลักษณ์**

| แหล่งที่มา | รางวัล | สิ่งที่ชุดสื่อถึง |
|---|---|---|
| เรียนวิชา | เครื่องแต่งกายและอุปกรณ์ประจำวิชา | ความสนใจ |
| สอบภาคปฏิบัติ | เข็มกลัดและรายละเอียดลายปัก | ความชำนาญ |
| สำรวจ | ชุดเดินทางและของประดับจากพื้นที่ | ประสบการณ์ |
| ดันเจียน | รูปลักษณ์จากธีมสถานที่ | ความสำเร็จ |
| ดูแลสัตว์เลี้ยง | เครื่องประดับคู่กับสัตว์เลี้ยง | ความผูกพัน |
| งานโรงเรียน | ชุดเทศกาลและอีโมต | การมีส่วนร่วม |
| คราฟต์ | ชุดผสมวัสดุและลวดลาย | ความคิดสร้างสรรค์ |
| ร้านค้า | ชุดแฟชั่นและธีมตกแต่ง | รสนิยม |

ของที่แสดงความสำเร็จ เช่น เข็มกลัดผ่านบททดสอบ ต้องได้จากการเล่น ส่วนร้านค้าสามารถขายชุดคนละรูปแบบที่มีคุณภาพงานเทียบเท่ากันได้

**ไม่ขายตราที่ทำให้คนเข้าใจว่าผู้ซื้อผ่านความสำเร็จนั้นแล้ว**

สำหรับชุดประจำฤดูกาล ควรมีเส้นทางกลับมาให้สะสมภายหลัง เช่น ร้านคลังเทศกาล โดยอาจคงตราระบุปีไว้เป็นของที่ระลึกสำหรับผู้ร่วมงานครั้งแรก

**7. พื้นที่เข้าสังคม: แต่ละที่ต้องมีสิ่งให้ทำร่วมกัน**

ไม่ควรสร้างลานกว้างแล้วหวังว่าผู้เล่นจะคุยกันเอง ทุกพื้นที่ควรมี “เหตุผลที่จะหยุดอยู่” และ “กิจกรรมที่เริ่มร่วมกันได้ง่าย”

| พื้นที่ | กิจกรรม | วิธีช่วยให้คนเริ่มรู้จักกัน |
|---|---|---|
| ลานกลางโรงเรียน | ชมงานแสดง นัดหมาย ถ่ายรูป | บอร์ดกิจกรรมที่กำลังจะเริ่ม |
| คาเฟ่เวทมนตร์ | ผสมเครื่องดื่มและเล่นเกมบนโต๊ะ | โต๊ะกิจกรรมรับคนเพิ่ม |
| ห้องสมุด | อ่านบันทึกและแก้ปริศนา | ปริศนาที่แต่ละคนเห็นคำใบ้ต่างกัน |
| เรือนกระจก | ดูแลต้นไม้และแต่งมุมสวน | งานร่วมกันระยะสั้น |
| ลานสัตว์เลี้ยง | เล่นของเล่นและโชว์ท่าฝึก | กิจกรรมสัตว์เลี้ยงแบบกลุ่ม |
| หอดูดาว | ดูปรากฏการณ์และถ่ายภาพ | งานตามเวลา พร้อมประกาศล่วงหน้า |
| หอพัก | เยี่ยมห้องและร่วมงานเล็ก ๆ | รายการห้องที่เปิดรับแขก |
| เวทีโรงเรียน | แฟชั่น การแสดง นิทรรศการ | สมัครเข้าร่วมโดยสมัครใจ |

เริ่มต้นทดสอบด้วยจำนวนผู้เล่นต่อพื้นที่ที่ทำให้ดูมีชีวิตแต่ไม่แน่นเกินไป แล้วปรับจากความลื่นไหลและอัตราที่ผู้เล่นได้ทำกิจกรรมร่วมกันจริง

**กิจกรรมสังคมควรเริ่มง่าย ใช้ประมาณ 2–5 นาที และออกกลางทางได้โดยไม่ทำให้คนอื่นเสียรางวัลทั้งหมด**

**8. เครื่องมือสื่อสาร: คนไม่อยากพิมพ์ก็เล่นกับคนอื่นได้**

มีคำพูดสำเร็จรูปที่ปรับตามสถานการณ์ เช่น:

- “ขอร่วมโต๊ะด้วยได้ไหม?”
- “ไปเรียนด้วยกันไหม?”
- “ขาดอีก 1 คน”
- “ชุดสวยมาก!”
- “ถ่ายรูปด้วยกันไหม?”
- “ขอเล่นเงียบ ๆ นะ”
- “ขอบคุณที่ช่วย”

เพิ่มสถานะที่ผู้เล่นเลือกเปิดเอง:

| สถานะ | ความหมาย |
|---|---|
| พร้อมทำกิจกรรม | รับคำชวนทั่วไป |
| หาเพื่อนเรียน | ต้องการเข้ากลุ่มเรียน |
| หาเพื่อนสำรวจ | ต้องการปาร์ตี้ |
| แต่งตัว/ถ่ายรูป | สนใจกิจกรรมแฟชั่น |
| ขอเล่นคนเดียว | ไม่รับคำเชิญทั่วไป |

สถานะควรรีเซ็ตหรือให้ยืนยันใหม่เมื่อเข้าเกมครั้งถัดไป เพื่อไม่แสดงความต้องการเก่าโดยไม่ตั้งใจ

**อีโมตแบบร่วมกันต้องขอรับก่อน** เช่น ไฮไฟว์ ชนแก้ว โพสคู่ และจับมือเต้น หากปฏิเสธหรือหมดเวลาให้จบอย่างเงียบ ๆ พร้อมจำกัดการส่งซ้ำ

**9. ความสัมพันธ์: ให้เกิดจากการเล่นร่วมกัน โดยไม่บังคับให้มีเพื่อน**

แยกระบบออกเป็นสามระดับ:

| ระดับ | ใช้ทำอะไร |
|---|---|
| กลุ่มชั่วคราว | เรียน สำรวจ ทำกิจกรรมครั้งนั้น |
| เพื่อนร่วมกิจกรรม | แสดงความทรงจำและกิจกรรมที่เคยทำร่วมกัน |
| ชมรม | มีพื้นที่และเป้าหมายร่วมระยะยาว |

สำหรับความสัมพันธ์รายคู่ เสนอเป็น **“สมุดความทรงจำ”** แทนการให้คะแนนความสนิทแบบแข่งขัน

ตัวอย่างหน้าความทรงจำ:

- แก้ปริศนาห้องสมุดร่วมกันครั้งแรก
- ผ่านบทเรียนคู่
- เข้าร่วมเทศกาลเดียวกัน
- ถ่ายรูปกลุ่มที่เรือนกระจก
- ช่วยกันดูแลสวนชมรม

รางวัลอาจเป็นกรอบรูป ท่าโพสคู่ หรือของตกแต่งที่ระลึก โดย:

- ไม่ลดความสัมพันธ์เมื่อไม่ได้เข้าเกม
- ไม่มีโบนัสพลังที่ทำให้ต้องเล่นกับคนเดิม
- ไม่จัดอันดับจำนวนเพื่อน
- ไม่ให้รางวัลจากการส่งข้อความจำนวนมาก
- มีทางเล่นคนเดียวหรือจับกลุ่มชั่วคราวสำหรับเนื้อหาหลัก

ข้อมูลความทรงจำรายคู่ควรเป็นส่วนตัวโดยค่าเริ่มต้น และผู้เล่นเลือกซ่อนหรือยุติการเชื่อมโยงได้

**10. ระบบชมรม: ให้ผู้เล่นสร้างชุมชนของตัวเอง**

ชมรมควรเป็นกลุ่มตามความสนใจ ไม่ผูกกับบ้านหรือฝ่ายถาวรของตัวละคร

ตัวอย่างชมรม:

- นักสำรวจโบราณสถาน
- ผู้ดูแลสัตว์เวท
- แฟชั่นและงานออกแบบ
- นักปรุงชา
- นักสะสมบันทึกโลก
- นักดาราศาสตร์
- การแสดงและดนตรี

**ขอบเขตเริ่มต้นที่เสนอ**

- ชมรมละประมาณ 20 สมาชิก
- ผู้เล่นเข้าร่วมได้ 2 ชมรม
- สร้างชมรมด้วยเงินจากการเล่นและผ่านบทนำของเกม
- มีบทบาทหัวหน้า ผู้จัดกิจกรรม ผู้ตกแต่ง และสมาชิก
- สมาชิกออกได้โดยไม่เสียค่าปรับ

สิ่งที่ชมรมมี:

| องค์ประกอบ | รายละเอียด |
|---|---|
| ห้องชมรม | พื้นที่ร่วมและมุมแสดงผลงาน |
| ตราสัญลักษณ์ | ประกอบจากรูปทรงที่เกมเตรียมไว้ |
| บอร์ดกิจกรรม | กำหนดเวลาและจำนวนผู้เข้าร่วม |
| เป้าหมายประจำสัปดาห์ | เลือกกิจกรรมจากหลายประเภท |
| สมุดผลงาน | บันทึกความสำเร็จของชมรม |
| ของตกแต่งร่วม | ปลดล็อกจากกิจกรรมชมรม |

ควรจำกัดอิทธิพลจากการทำซ้ำของคนเดียว เพื่อให้เป้าหมายสะท้อนการมีส่วนร่วมหลายคน แต่ไม่กำหนดโควตารายบุคคลจนกลายเป็นภาระ

**ของส่วนตัวไม่ควรฝากไว้ในคลังที่หัวหน้าสามารถยึดได้** ของตกแต่งชมรมใช้ระบบสิทธิ์ของชมรมแยกจากทรัพย์สินผู้เล่น และกำหนดกติกาการเปลี่ยนหัวหน้าก่อนเปิดใช้จริง

**11. หอพักและห้องส่วนตัว**

ผู้เล่นทุกคนควรได้ห้องพื้นฐานฟรีตั้งแต่ช่วงต้นเกม ห้องนี้เป็นจุดเชื่อมระหว่างแฟชั่น การสะสม และสังคม

โซนสำคัญ:

- เตียงและพื้นที่พัก
- กระจกแต่งตัว
- โต๊ะเรียน
- ชั้นคัมภีร์
- มุมสัตว์เลี้ยง
- ผนังภาพและการ์ดสะสม
- มุมรับแขก

ของสะสมควรวางแสดงได้ เช่น เสื้อคลุมบนหุ่น คัมภีร์บนชั้น และของที่ระลึกจากดันเจียน

**ระบบตกแต่ง**

- วางแบบติดกริดหรือปรับละเอียด
- หมุน ย้าย เก็บคืน และย้อนการแก้ไข
- บันทึกแบบห้อง
- แสดงงบจำนวนวัตถุและเอฟเฟกต์ที่เหลือ
- ตรวจไม่ให้เฟอร์นิเจอร์ปิดทางเข้าหรือจุดเกิด
- ทดลองวางก่อนซื้อ

**สิทธิ์การเข้าห้อง**

| โหมด | ใครเข้าได้ |
|---|---|
| ส่วนตัว | เจ้าของ |
| เชิญเท่านั้น | ผู้ที่รับคำเชิญ |
| เพื่อน | เพื่อนที่ได้รับอนุญาต |
| ชมรม | สมาชิกชมรม |
| เปิดบ้าน | ผู้เล่นทั่วไปตามจำนวนที่กำหนด |

ค่าเริ่มต้นควรเป็นส่วนตัวหรือเชิญเท่านั้น เจ้าของปิดห้อง เชิญออก และห้ามผู้เล่นบางคนกลับเข้าได้ แขกไม่มีสิทธิ์แก้ไขของโดยอัตโนมัติ

ธีมห้องแบบขายเพิ่มควรขายบรรยากาศและรูปแบบตกแต่ง ส่วนพื้นที่พื้นฐานต้องเพียงพอให้จัดห้องสวยได้จริง

**12. ระบบถ่ายภาพและโปรไฟล์**

นี่คือเครื่องมือสำคัญที่จะทำให้ผู้เล่นอยากสะสมชุด เพราะมีที่ใช้แสดงรูปลักษณ์ของตนเอง

**โหมดถ่ายภาพ**

- ซ่อน UI
- เลือกมุมกล้องภายในขอบเขตที่กำหนด
- เลือกท่าโพสและสีหน้า
- ตั้งเวลาถ่าย
- ชวนผู้เล่นอื่นเข้าโหมดโพสกลุ่ม
- เลือกกรอบและสติกเกอร์ของเกม
- ตั้งว่าจะให้ชื่อผู้เล่นปรากฏหรือไม่

เวอร์ชันแรกควรใช้ **ภาพจัดฉากจากข้อมูลตัวละคร ชุด ท่า และฉาก** สำหรับแสดงในโปรไฟล์หรือกรอบรูปภายในเกม เพื่อลดขอบเขตงานเรื่องการรับและจัดเก็บภาพอัปโหลด ส่วนภาพหน้าจอที่ผู้เล่นบันทึกเองเป็นอีกระบบหนึ่ง

**โปรไฟล์นักเรียน**

| ส่วน | ตัวอย่าง |
|---|---|
| รูปลักษณ์ปัจจุบัน | ตัวละครกับสัตว์เลี้ยง |
| ความสนใจ | ปรุงยา แฟชั่น สำรวจ |
| ผลงานที่เลือกแสดง | เข็มกลัดสูงสุด 3 ชิ้น |
| ชุดโปรด | ชุดที่เจ้าของเผยแพร่ |
| ชมรม | แสดงตามการตั้งค่า |
| สมุดภาพ | ภาพจัดฉากที่เลือกเผยแพร่ |
| ปุ่มกิจกรรม | ชวนเรียน ชวนปาร์ตี้ ดูชุด |

ไม่แสดงยอดใช้จ่ายและไม่ทำอันดับความนิยมรวมทั้งโรงเรียน การให้ผู้เล่นเลือกสิ่งที่อยากนำเสนอเองจะสร้างตัวตนได้ดีกว่าคะแนนสถานะเดียว

**13. กิจกรรมแฟชั่น: สนุกได้โดยไม่ต้องซื้อชุดแพง**

เสนอให้มีสองรูปแบบแยกกัน

| รูปแบบ | กติกา | จุดประสงค์ |
|---|---|---|
| โชว์สไตล์ส่วนตัว | ใช้ของที่ผู้เล่นมี ไม่มีอันดับหลัก | แสดงตัวตน |
| โจทย์สร้างสรรค์ | ทุกคนใช้ตู้เสื้อผ้าทดลองชุดเดียวกัน | แข่งขันด้านการแต่งตัวอย่างเท่าเทียม |

ตัวอย่างโจทย์:

- นักพฤกษาศาสตร์ในคืนฝนตก
- ผู้ดูแลห้องสมุดต้องห้าม
- ชุดเดินทางไปเกาะลอยฟ้า
- งานเลี้ยงแสงจันทร์
- แต่งให้เข้ากับสัตว์เลี้ยง

รอบกิจกรรมอาจใช้ประมาณ 8–10 นาที:

1. ประกาศโจทย์
2. แต่งตัว
3. แสดงชุดทีละคนหรือเป็นกลุ่มเล็ก
4. โหวตตามหัวข้อ
5. รับของที่ระลึกและชมผลงาน

**ลดการโหวตตามฐานะและกลุ่มเพื่อน**

- ซ่อนชื่อและชมรมในช่วงประเมิน
- สุ่มลำดับแสดง
- ใช้หัวข้อประเมิน เช่น ตรงธีม จับคู่สี และความคิดสร้างสรรค์
- ไม่ขายคะแนนโหวตหรือสิทธิ์ชนะ
- จำกัดน้ำหนักรางวัลอันดับ
- ให้รางวัลจากการเข้าร่วมอย่างมีความหมาย
- ตรวจรูปแบบลงคะแนนผิดปกติ โดยไม่ถือว่ามาตรการเหล่านี้ป้องกันการฮั้วได้ทั้งหมด

ช่วงแรกควรเปิดเป็นกิจกรรมสนุกพร้อมคำชมหลายประเภทก่อนเพิ่มการแข่งขันจริงจัง

**14. การให้ของและการแลกเปลี่ยน**

**ไม่แนะนำให้เปิดการซื้อขายระหว่างผู้เล่นตั้งแต่เวอร์ชันแรก** เพราะจะเพิ่มงานด้านเศรษฐกิจ การหลอกลวง และการกู้คืนของอย่างมาก

เริ่มจากสิ่งที่ควบคุมง่ายกว่า:

- ส่งการ์ดข้อความจากรายการที่เตรียมไว้
- แจกเครื่องดื่มที่ใช้ได้ในกิจกรรม
- มอบของที่ระลึกมูลค่าต่ำที่เกมกำหนด
- ของซ้ำเปลี่ยนเป็นวัสดุสำหรับสะสมของตนเอง

หากเปิดแลกเปลี่ยนภายหลัง ต้องกำหนดให้ชัดเจนว่าอะไรโอนได้ พร้อมหน้าสรุปสองฝ่าย การยืนยันใหม่เมื่อมีการเปลี่ยนของ บันทึกธุรกรรม และการป้องกันของซ้ำจากคำขอที่ส่งซ้ำ

หลีกเลี่ยงการทำให้ของแฟชั่นกลายเป็นตลาดเก็งกำไรเป็นเป้าหมายหลักของระบบสังคม

**15. ความเป็นส่วนตัวและการดูแลชุมชน**

ระบบสังคมต้องมีเครื่องมือป้องกันการรบกวนตั้งแต่รุ่นแรก ไม่รอให้เกิดปัญหาก่อน

| สถานการณ์ | สิ่งที่ระบบควรรองรับ |
|---|---|
| ส่งคำเชิญซ้ำ | คูลดาวน์ จำกัดจำนวน และปิดรับคำเชิญ |
| ตามเข้าห้อง | สิทธิ์เข้าห้องและรายการห้ามเข้า |
| ก่อกวนในกิจกรรม | ออกจากกลุ่ม ปิดเสียง บล็อก และรายงาน |
| ใช้ชื่อหรือข้อความไม่เหมาะสม | ใช้ระบบกรองและตรวจเนื้อหาที่รองรับ |
| เอาชื่อหรือชุดไปล้อเลียน | รายงานผู้เล่นได้จากโปรไฟล์และจุดเกิดเหตุ |
| โพสคู่โดยไม่ยินยอม | ต้องรับคำเชิญและออกจากท่าได้ทันที |
| แสงเอฟเฟกต์รบกวน | ลดเอฟเฟกต์ ซ่อนออร่า และลดการเคลื่อนไหว |

ควรใช้ระบบสื่อสารและข้อจำกัดบัญชีที่แพลตฟอร์มรองรับเป็นฐาน และตรวจเอกสาร Roblox ฉบับปัจจุบันก่อนลงมือพัฒนาส่วนแชต เสียง การซื้อ และการเผยแพร่เนื้อหา

ระบบหลักต้องเล่นได้โดยไม่ใช้เสียง และไม่ขอข้อมูลส่วนตัวเพื่อเข้าชมรมหรือร่วมกิจกรรม

**16. รายได้ที่เหมาะกับระบบนี้**

| สิ่งที่ขาย | คุณค่าที่ผู้เล่นได้รับ | ขอบเขตที่ควรรักษา |
|---|---|---|
| ชุดแฟชั่นแบบซื้อเลือก | รูปลักษณ์ที่ต้องการ | ไม่มีค่าพลัง |
| ชุดธีมสัตว์เลี้ยง | แต่งคู่กับตัวละคร | ไม่เพิ่มประสิทธิภาพสัตว์เลี้ยง |
| ธีมห้องและเฟอร์นิเจอร์ | บรรยากาศเฉพาะตัว | ห้องฟรียังใช้งานได้ครบ |
| อีโมตและท่าโพส | การแสดงออก | ท่าทักทายพื้นฐานฟรี |
| กรอบภาพและอุปกรณ์ถ่ายรูป | จัดภาพได้หลากหลาย | กล้องพื้นฐานฟรี |
| ช่องบันทึกชุดเพิ่ม | สะดวกสำหรับนักสะสม | จำนวนฟรีเพียงพอ |
| เส้นทางรางวัลแฟชั่น | มีเป้าหมายสะสมเพิ่ม | ไม่ล็อกบทเรียนหรือเนื้อเรื่องหลัก |

ข้อเสนอสำหรับช่วงเปิดตัวคือ **ขายแบบเลือกซื้อโดยตรง** ผู้เล่นเห็นชัดว่าได้อะไร พร้อมลองทั้งชุดก่อนซื้อ

ไม่ควรขาย:

- ความสามารถส่งคำเชิญได้มากกว่าคนอื่น
- การขึ้นอันดับโปรไฟล์หรือชมรม
- คะแนนความสัมพันธ์
- คะแนนประกวด
- ตราผลงานจากการเรียน
- สิทธิ์ข้ามการตั้งค่าความเป็นส่วนตัวของคนอื่น

ร้านค้าควรเสนอธีมที่มีเรื่องราว เช่น “นักสำรวจฤดูฝน” หรือ “นักปรุงชากลางสวน” โดยสร้างชื่อ รูปทรง ลาย และสัญลักษณ์ต้นฉบับของ Mythic Academy พร้อมเก็บที่มาของทรัพยากรที่ใช้ผลิต

**17. โครงสร้างระบบสำหรับนำไปพัฒนา**

แยกบริการให้แต่ละส่วนมีหน้าที่ชัดเจน:

| ระบบ | หน้าที่ |
|---|---|
| `CosmeticCatalog` | นิยามไอเทม ช่องสวมใส่ สี และข้อจำกัด |
| `InventoryService` | ตรวจสิทธิ์ครอบครองและมอบไอเทม |
| `AppearanceService` | ตรวจชุดและนำไปแสดงบนตัวละคร |
| `OutfitService` | บันทึก โหลด และแชร์ชุด |
| `SocialSessionService` | กลุ่มชั่วคราว คำเชิญ และอีโมตร่วม |
| `ClubService` | สมาชิก บทบาท เป้าหมาย และห้องชมรม |
| `HousingService` | แบบห้อง เฟอร์นิเจอร์ และสิทธิ์เข้าห้อง |
| `ActivityService` | คาเฟ่ งานแฟชั่น และกิจกรรมโรงเรียน |
| `PrivacyService` | การเปิดเผยข้อมูลและการรับคำเชิญ |
| `RewardService` | มอบรางวัลโดยป้องกันการรับซ้ำ |

**หลักการข้อมูลสำคัญ**

- ฝั่งเซิร์ฟเวอร์ตรวจการเป็นเจ้าของไอเทมก่อนสวมและบันทึก
- ลูกค้าส่งคำขอเปลี่ยนชุด ไม่เป็นผู้ตัดสินสิทธิ์เอง
- ชุดบันทึกอ้างอิงรหัสไอเทม ไม่คัดลอกโมเดลทั้งหมด
- แยกข้อมูลส่วนตัวออกจากข้อมูลโปรไฟล์ที่เผยแพร่
- จำกัดความถี่คำเชิญและคำขอเปลี่ยนรูปลักษณ์
- บันทึกรางวัลและการซื้อแบบรองรับคำขอซ้ำโดยไม่มอบซ้ำ
- กำหนดวิธีจัดการเมื่อไอเทมถูกถอดออกหรือแก้ไขภายหลัง
- โหลดรายละเอียดตัวละครใกล้ตัวก่อน และลดเอฟเฟกต์ในพื้นที่คนหนาแน่น

ก่อนผลิตชุดจำนวนมาก ต้องมีตารางทดสอบการเข้ากันของหมวก ผม เสื้อคลุม กระเป๋า และท่านั่ง เพราะเป็นจุดที่ทำให้ภาพรวมดูขัดตาได้ง่ายที่สุด

**18. ลำดับทำงานที่แนะนำ**

| ระยะ | ขอบเขต | เกณฑ์ผ่าน |
|---|---|---|
| 1 — ต้นแบบแต่งตัว | ตัวละคร เสื้อผ้า 6 ช่อง ย้อมสี บันทึกชุด | เปลี่ยนชุดแล้วโหลดกลับได้ถูกต้อง และชิ้นส่วนหลักไม่ทะลุกันรุนแรง |
| 2 — สังคมพื้นฐาน | ลานกลาง กลุ่มชั่วคราว คำเชิญ อีโมต การบล็อก | ผู้เล่นเริ่มกิจกรรมร่วมกันและออกจากกลุ่มได้เอง |
| 3 — ห้องและการแสดงตัวตน | ห้องส่วนตัว โปรไฟล์ ถ่ายรูป แชร์ชุด | สิทธิ์ห้องถูกต้อง และเผยแพร่เฉพาะสิ่งที่เลือก |
| 4 — เชื่อมการเล่น | รางวัลวิชา สัตว์เลี้ยง และสำรวจ | ผู้เล่นรู้ว่าต้องไปทำอะไรเพื่อได้ของที่สนใจ |
| 5 — ชุมชน | ชมรม งานโรงเรียน กิจกรรมแฟชั่น | กลุ่มเล็กจัดกิจกรรมได้โดยไม่ต้องพึ่งผู้ดูแล |
| 6 — ร้านค้าและขยายคอนเทนต์ | ชุดธีม ของแต่งห้อง อีโมตเพิ่มเติม | ทดลอง ซื้อ และรับของได้ถูกต้อง ไม่มีผลต่อค่าพลัง |

**ขอบเขตเปิดตัวที่เหมาะสม**

- ธีมเสื้อผ้าประมาณ 6 ธีม ผสมกันได้
- ไอเทมสวมใส่รวมประมาณ 35–45 ชิ้น โดยนับสีแยกเป็นตัวเลือก ไม่เพิ่มจำนวนไอเทมหลอก ๆ
- ชุดเริ่มต้นฟรีที่ดูดีอย่างน้อย 3 แบบ
- อีโมตพื้นฐาน 8 แบบ และอีโมตร่วม 3 แบบ
- พื้นที่สังคมหลัก 2 แห่ง
- ห้องส่วนตัว 1 รูปแบบ พร้อมของตกแต่งพื้นฐาน
- กิจกรรมร่วมระยะสั้น 3 กิจกรรม
- กิจกรรมแฟชั่นแบบใช้ตู้เสื้อผ้าเท่ากัน 1 รูปแบบ
- ยังไม่เปิดตลาดแลกเปลี่ยนระหว่างผู้เล่น

ถ้าทีมเล็ก ให้เลื่อนชมรมเต็มรูปแบบไปหลังเปิดทดสอบ โดยทำ **แต่งตัว → พบเพื่อน → ทำกิจกรรม → ได้ของแต่งเพิ่ม → กลับมาจัดชุดและห้อง** ให้สนุกก่อน

**19. ตัวอย่างประสบการณ์ผู้เล่นหนึ่งวัน**

ผู้เล่นเข้าเกมแล้วเปลี่ยนเป็นชุดเรียนพฤกษาที่บันทึกไว้ เห็นเพื่อนเปิดสถานะ “หาเพื่อนเรียน” จึงกดเข้ากลุ่ม

หลังเรียน ทั้งคู่ได้ความคืบหน้าปลดล็อกลายใบไม้ และไปช่วยกันดูแลต้นไม้ในเรือนกระจกประมาณสามนาที จากนั้นลองสีใหม่กับเสื้อคลุมเดิม โดยไม่ต้องซื้อชุดเพิ่ม

เพื่อนชวนถ่ายภาพกับสัตว์เลี้ยง ผู้เล่นรับคำเชิญ เลือกท่า แล้วนำภาพจัดฉากกลับไปวางในห้อง ก่อนเปิดห้องให้เพื่อนอีกสองคนมาเยี่ยม

ก่อนออกเกม ผู้เล่นเห็นงานแฟชั่นหัวข้อ “นักสำรวจคืนฝนตก” ที่กำลังจะเริ่ม จึงเข้าร่วมด้วยชุดทดลองที่ทุกคนใช้ได้เท่ากัน และได้รับกรอบรูปเป็นของที่ระลึก

**เป้าหมายของระบบคือให้ผู้เล่นกลับมาเพราะอยากแต่งตัว อยากทำกิจกรรม และอยากเจอคนที่รู้จัก โดยการซื้อของเป็นทางเลือกในการแสดงตัวตน ไม่ใช่เงื่อนไขในการเข้าร่วมสังคมของโรงเรียน**
