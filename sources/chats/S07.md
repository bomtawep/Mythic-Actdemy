# S07 — ออกแบบ Academy Place

### ผู้ใช้

ลองออกแบบ Academy Place ที่ไม่ใช่แค่ moc

### ผู้ช่วย — ข้อเสนอ/รายงานในเวลานั้น

ได้ครับ ผมตีความว่า “ไม่ใช่แค่ moc” คือ **Academy Place ที่เป็นโรงเรียนให้ผู้เล่นใช้ชีวิตและเล่นได้จริง ไม่ใช่แค่ปราสาทสวย ๆ สำหรับเดินชม** สำหรับ Mythic Academy ผมจะออกแบบให้พื้นที่ การเรียน การเข้าสังคม และความลับทำงานร่วมกันตั้งแต่ต้น

**แนวคิดหลัก: โรงเรียนที่สร้างอยู่บนซากเครื่องจักรเวทมนตร์โบราณ**

โรงเรียนตั้งอยู่บนเกาะหินขนาดใหญ่ รอบแกนพลังงานที่ยังทำงานอยู่ อาคารจึงมีทั้งส่วนที่โรงเรียนสร้างขึ้นใหม่และโครงสร้างเก่าที่ไม่มีใครเข้าใจทั้งหมด

เอกลักษณ์ของภาพคือ **หินสีงาช้าง โลหะทองแดง กระจกสี และรากไม้เรืองแสง** อาคารบางส่วนกางตัวหรือเปลี่ยนทิศตามกระแสพลังงาน ช่วยให้มีภาพจำของตัวเองและรองรับระบบทางเดินเปลี่ยนตำแหน่งที่เราคุยกัน

ผู้เล่นต้องสัมผัสได้สามอย่าง:

- “ฉันมีที่อยู่และมีบทบาทในโรงเรียนนี้”
- “วิชาที่เรียนเอาไปใช้กับสถานที่จริงได้”
- “แม้จะเดินผ่านที่เดิม ก็ยังมีเรื่องใหม่ให้ค้นพบ”

**1. จัดพื้นที่เป็นวงรอบลานกลาง เพื่อให้จำทางได้ง่าย**

ใช้ **ลานแกนแสง** เป็นจุดกลาง มองเห็นหอพลังงานได้จากพื้นที่หลัก แล้วแบ่งโรงเรียนเป็นสามระดับ:

| ระดับ | ลักษณะพื้นที่ | ประสบการณ์หลัก |
|---|---|---|
| ชั้นบน: เรือนยอด | หอดูดาว สวนลอยฟ้า ทางเดินกระจก | สำรวจ ทดสอบเวทเคลื่อนที่ ดูปรากฏการณ์ |
| ชั้นกลาง: ชีวิตนักเรียน | ลานกลาง ห้องเรียน หอพัก โรงอาหาร | เรียน พบเพื่อน แต่งตัว ทำกิจกรรม |
| ชั้นล่าง: รากฐานเก่า | คลังเก็บของ ระบบพลังงาน ห้องปิดตาย | ไขปริศนา ค้นบันทึก เปิดเส้นทางลับ |

**เส้นทางประจำต้องคงที่ ส่วนเส้นทางลับจึงค่อยเปลี่ยนตำแหน่ง** ผู้เล่นจะได้ไม่หลงตอนต้องไปเรียน แต่ยังรู้สึกว่าโรงเรียนมีชีวิต

ตั้งเป้าสำหรับต้นแบบให้เดินจากลานกลางไปห้องเรียนหลักประมาณ 20–35 วินาที แล้วปรับจากการเล่นจริง ไม่สร้างแผนที่ใหญ่จนเวลาส่วนมากหมดไปกับการเดิน

**2. ทุกโซนต้องมีเหตุผลให้กลับมา**

| โซน | สิ่งที่เล่นได้จริง | สิ่งที่ทำให้กลับมา |
|---|---|---|
| **ลานแกนแสง** | พบเพื่อน ทดลองเวทร่วมกัน รับข่าวกิจกรรม | เหตุการณ์ส่วนกลางและสภาพพลังงานเปลี่ยน |
| **อาคารเรียนเวทประยุกต์** | เรียนการเคลื่อนย้าย ควบคุมแสง และประกอบอักขระ | แบบฝึกเปลี่ยนเงื่อนไข ใช้ทักษะแทนการกดรับรางวัล |
| **เรือนกระจกมีชีวิต** | ปลูกพืช เก็บวัตถุดิบ อ่านอาการพืชและดูแล | วงจรเติบโต สูตรทดลอง และสิ่งมีชีวิตที่มาเยือน |
| **หอจดหมายเหตุ** | ค้นข้อมูล ต่อชิ้นส่วนบันทึก แปลสัญลักษณ์ | ข้อมูลจากการสำรวจปลดล็อกเรื่องราวเพิ่มเติม |
| **โรงอาหารและลานชมรม** | ทำอาหารร่วมกัน นัดกลุ่ม จัดโชว์เล็ก ๆ | กิจกรรมชมรมและเมนูที่ผู้เล่นช่วยกันทำ |
| **หอพัก** | แต่งห้อง จัดของสะสม เชิญเพื่อน | แสดงความก้าวหน้าและตัวตนของผู้เล่น |
| **ลานสัตว์เวท** | ดูแล ฝึกคำสั่ง เล่นกับสัตว์เลี้ยง | ท่าทาง บุคลิก และกิจกรรมคู่กับเจ้าของ |
| **หอดูดาว** | ปรับเลนส์ อ่านตำแหน่งดาว หาเกาะที่ซ่อนอยู่ | เบาะแสสำหรับเส้นทางสำรวจ |
| **เขตฐานรากเก่า** | แก้ปริศนา เปิดทางลัด สำรวจเป็นกลุ่ม | ห้องลับและเรื่องราวของโรงเรียน |

ไม่จำเป็นต้องเปิดทุกโซนตั้งแต่วันแรก แต่โซนที่เปิดต้องมีระบบใช้งาน ไม่ใช่อาคารที่กดประตูแล้วขึ้นว่า “Coming Soon” เต็มโรงเรียน

**3. ห้องเรียนต้องส่งผลต่อการเล่นนอกห้อง**

ตัวอย่างวิชาแรก: **การสะท้อนแสงเวท**

ในห้องเรียน ผู้เล่นหมุนกระจกเพื่อส่งแสงผ่านสัญลักษณ์สามจุด ครูให้คำแนะนำจากสิ่งที่ผู้เล่นทำผิด เช่น มุมสะท้อนหรือสีของแสง

หลังเรียน ผู้เล่นนำความรู้นี้ไปใช้ได้ทันที:

- จุดโคมที่ดับในทางเดินเพื่ออ่านข้อความบนผนัง
- ส่องผ่านกระจกสีเพื่อเปิดช่องเก็บบันทึก
- ช่วยเพื่อนจัดแสงบนเวทีชมรม
- เปิดประตูห้องลับที่ใช้หลักการเดียวกัน แต่จัดวางซับซ้อนขึ้น

**รางวัลสำคัญคือการมองพื้นที่เดิมแล้วเห็นโอกาสใหม่** ไม่ใช่แค่ได้ค่า EXP เพิ่ม

วิชาอื่นก็ใช้แนวทางเดียวกัน เช่น เวทเคลื่อนย้ายใช้จัดสะพาน เวทพฤกษาใช้ปลุกรากไม้ และวิชาอักขระใช้ตีความเครื่องจักรใต้โรงเรียน

**4. ตัวอย่างการเล่น 20 นาทีแรก**

| เวลาโดยประมาณ | เหตุการณ์ | สิ่งที่ผู้เล่นได้เข้าใจ |
|---|---|---|
| นาที 0–3 | มาถึงท่าเทียบเรือ รับตรานักเรียน เลือกรูปลักษณ์เบื้องต้น | ตัวตนและเป้าหมายแรก |
| นาที 3–6 | เดินเข้าลานกลาง พบโคมพลังงานชำรุด ช่วย NPC ย้ายชิ้นส่วน | การควบคุมและการโต้ตอบ |
| นาที 6–11 | เข้าเรียนวิชาแสงเวทแบบสั้น | กลไกหลักผ่านการลงมือทำ |
| นาที 11–15 | ใช้สิ่งที่เรียนซ่อมโคมข้างหอพัก | วิชามีประโยชน์กับโลกจริง |
| นาที 15–18 | แสงเผยข้อความและช่องลับ ได้บันทึกชิ้นแรก | ระบบสำรวจและสะสม |
| นาที 18–20 | นำของกลับไปวางในห้อง เปิดตัวเลือกไปชมรมหรือสำรวจต่อ | มีบ้านและเลือกเส้นทางของตัวเอง |

ไม่ควรบังคับรอคาบเรียนตามเวลาจริงเพื่อผ่านช่วงแรก เมื่อผู้เล่นพร้อมต้องเริ่มบทเรียนพื้นฐานได้เลย ส่วนคาบรวมใช้เป็นกิจกรรมเสริม

**5. ให้โรงเรียนเปลี่ยนแปลงแบบที่ผู้เล่นเข้าใจได้**

ตัวอย่างเหตุการณ์ **“กระแสแสงไหลย้อน”**

ก่อนเกิดเหตุ โคมรอบโรงเรียนเริ่มเปลี่ยนสี เครื่องจักรมีเสียงผิดปกติ และ NPC พูดถึงอาการเดียวกัน จากนั้น:

- สะพานเสริมเคลื่อนมาเชื่อมระเบียงที่ปกติไปไม่ถึง
- พืชบางชนิดผลิบานและเผยสัญลักษณ์
- ประตูเก่าใต้หอจดหมายเหตุรับพลังงาน
- ผู้เล่นเลือกช่วยซ่อมระบบหรือไปสำรวจเส้นทางที่เปิดขึ้น

ผู้เล่นที่เพิ่งเข้ามาต้องดูสถานะปัจจุบันได้จากลานกลาง ไม่ต้องเดาจากสิ่งที่พลาดไปก่อนหน้า และของสำคัญควรกลับมาหาได้ในรอบถัดไป

สำหรับทางเดินเปลี่ยนตำแหน่ง ควรมีสัญญาณก่อนเปลี่ยนและจุดยืนปลอดภัย หลีกเลี่ยงการย้ายพื้นขณะผู้เล่นอยู่บนนั้นจนตกหรือติดฉาก

---

**6. ออกแบบการเข้าสังคมโดยไม่บังคับให้ต้องมีเพื่อน**

กิจกรรมพื้นฐานเล่นคนเดียวได้ ส่วนการเล่นร่วมกันเพิ่มทางเลือกและความสนุก เช่น:

- ปริศนาคนเดียวใช้แท่นค้างพลังงาน แต่หลายคนช่วยถือแสงคนละทิศได้
- ทำอาหารคนเดียวได้ แต่เล่นเป็นกลุ่มแบ่งหน้าที่เตรียมวัตถุดิบและจัดจานได้
- ผู้เล่นเปิดห้องพักให้เยี่ยมชม และกำหนดสิทธิ์ผู้เข้าห้องได้
- ชมรมจัดแสดงของสะสมหรือการแสดงเวท โดยมีพื้นที่และจำนวนเอฟเฟกต์จำกัด

การใช้เวทในพื้นที่สังคมต้องไม่ผลัก ล็อกทาง หรือทำให้ผู้เล่นอื่นเสียการควบคุมโดยไม่ได้เลือกเข้าร่วม

รายได้ที่เข้ากับพื้นที่นี้คือ **ชุดนักเรียน เฟอร์นิเจอร์ ธีมห้อง ท่าทาง และเอฟเฟกต์ตกแต่ง** ส่วนความสามารถเปิดห้องลับ ผ่านบทเรียน และเข้าถึงเนื้อเรื่องให้ได้จากการเล่น

**7. ขอบเขตเวอร์ชันแรกที่สร้างแล้วพิสูจน์ความสนุกได้**

ผมจะเริ่มจากโรงเรียนขนาดกะทัดรัดที่เปิดใช้งานจริงดังนี้:

| ส่วน | ขอบเขตเริ่มต้น |
|---|---|
| พื้นที่หลัก | ลานกลาง อาคารเรียน หอพัก และทางเดินเชื่อม |
| วิชา | แสงเวท 1 วิชา มีบทเรียนและโจทย์ประยุกต์ |
| การสำรวจ | ปริศนา 3 จุด ห้องลับ 1 ห้อง ทางลัด 1 เส้น |
| ชีวิตนักเรียน | ห้องพักส่วนตัว วางของและเชิญเพื่อนได้ |
| ของสะสม | บันทึก 5 ชิ้น ของตกแต่งจากการเล่น 3 ชิ้น |
| โลกที่เปลี่ยน | เหตุการณ์กระแสแสงไหลย้อน 1 แบบ |
| การเล่นร่วมกัน | ปริศนาที่รองรับทั้งคนเดียวและกลุ่มเล็ก |

ฝั่งระบบต้องมีการบันทึกความคืบหน้า ตรวจรางวัลและการปลดล็อกจากเซิร์ฟเวอร์ ป้องกันรับรางวัลซ้ำ และทดสอบเส้นทางกับการควบคุมบนมือถือด้วย ห้องพักส่วนตัวควรโหลดตามการใช้งาน แทนการสร้างห้องครบทุกคนไว้ในฉากตลอดเวลา

**เกณฑ์ว่าเป็น Academy Place ที่เล่นได้จริง:** ผู้เล่นใหม่เข้ามาแล้วเรียนวิชา ใช้วิชาค้นพบความลับ ได้ของกลับไปแต่งห้อง และชวนเพื่อนมาดูได้ครบวงจร โดยความคืบหน้ายังอยู่เมื่อกลับเข้าเกม

ผมจะให้วงจรนี้สมบูรณ์ก่อนขยายปราสาท เพราะมันเป็นฐานที่ทำให้ห้องเรียนใหม่ เกาะลับ สัตว์เลี้ยง และชมรมที่เพิ่มภายหลังเชื่อมเข้ากับเกมได้จริงครับ
