ควรนำโมเดลนี้ไปปรับใน Sculpt Mode โดยเฉพาะใบหน้า เครา รูปทรงหมวกและเสื้อคลุม จากนั้นทำ UV Texture และวาดลวดลายทองตามภาพอ้างอิงโดยตรง วิธีนี้จะให้ผลลัพธ์ใกล้เคียงภาพต้นฉบับมากกว่าการใช้รูปทรงพื้นฐานจากสคริปต์เพียงอย่างเดียว

หากเป้าหมายคือความเหมือนระดับงาน Character Artist สำหรับภาพยนตร์หรือเกม AAA ควรใช้โมเดลที่ผ่านการ Sculpt และ Texture ด้วยมือร่วมด้วย ไม่ควรพึ่งสคริปต์ Procedural อย่างเดียวครับ

## วิธีเปิดใน Blender

1. เปิด Blender → **Scripting**
2. เปิดไฟล์ `mythic_academy_chibi.py`
3. กด **Run Script**
4. กด `Numpad 0` เพื่อดูผ่านกล้อง
5. กด `F12` เพื่อ Render ภาพนิ่ง
6. กด `Ctrl + Shift + S` เพื่อบันทึกเป็น `.blend`

สำหรับภาพเคลื่อนไหวหมุน 360° ให้ใช้ **Render → Render Animation** หลังตั้งค่า Output
